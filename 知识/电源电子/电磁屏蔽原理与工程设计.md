# 电磁屏蔽原理与工程设计

## 一句话

**电磁屏蔽只做两件事：外面的电磁波进不来，里面的电磁噪声出不去——但频率不同，屏蔽的物理机制完全不同。**

## 三大屏蔽机制

| 频段 | 屏蔽机制 | 材料 |
|------|---------|------|
| 静电场/准静态 | 导体接地→等电位→无电力线穿越 | 任意金属 + 接地 |
| 低频磁场 | 高磁导率材料提供低磁阻旁路 | 坡莫合金、软磁铁镍合金 |
| 高频电磁场 | 反射 + 涡流吸收 + 趋肤效应 | 铜、铝等高导电金属 |

> [!important] 关键区分
> 静电屏蔽用**接地导体**，静磁屏蔽用**高磁导率材料**——两者物理机制完全不同。铜能完美屏蔽电场，对静磁场几乎透明。

## 静电屏蔽

### 基本原理

两个导体若处于同一电位，就不会形成电力线（无静电耦合）；电位不同→电力线连接→电容性耦合。

**屏蔽方法**：用导体包围被保护对象，将外层导体接地（电位固定为零）。

```
外部电场 → 电力线终止在外导体表面 → 内部无电场 ✅
内部电荷 → 电力线终止在外导体内侧 → 外部无感 ✅
```

### 法拉第笼

金属板/金属网构成的静电屏蔽结构。典型的电荷量测量仪：内部导体 + 外部容器接地 + 电位计 → 通过电容关系反推电荷量。

### 同轴电缆

细长圆柱形法拉第笼：
- 中心导体传输信号
- 外导体接地或作为返回路径
- 电场被限制在内外导体之间
- 理想情况外表面无电流 → 无对外辐射

> [!warning] 高频时外导体不再是理想等电位体
> 频率升高→表面电阻产生压降→屏蔽效果下降。趋肤效应进一步改变表面阻抗。

## 磁场屏蔽

### 低频/静磁屏蔽

**原理**：不是"挡住"磁场，而是提供磁阻更低的旁路——磁通优先从屏蔽层通过，内部磁通密度下降。

```
屏蔽效能 ∝ μr × t / R
  μr: 相对磁导率（坡莫合金可达 10^4）
  t:  材料厚度
  R:  被保护空间半径
```

> [!warning] 三个限制
> 1. **缝隙致命**——外壳不闭合，磁通从开口进入，屏蔽效果大幅下降
> 2. **磁饱和**——外部磁场太强→材料进入饱和→μr 骤降→屏蔽失效
> 3. **单层有限**——精密屏蔽用多层结构，层间留间隙逐级衰减

### 超导体迈斯纳效应

材料进入超导态后，外部磁场完全不能进入——**完全抗磁性**。用于极弱磁场测量、超导量子器件。

### 高频磁场屏蔽

变化磁场→金属表面感生涡流→涡流方向总是削弱原磁场变化→焦耳损耗转化为热能。

> **铜、铝等高导电非磁性金属也能有效屏蔽高频磁场**——依赖涡流损耗而非磁导率。

## 高频 EMI 屏蔽

### 谢昆诺夫（Schelkunoff）公式

总屏蔽效能 SE = **A**（吸收损耗）+ **R**（反射损耗）+ **B**（多重反射修正）

| 项 | 公式关系 | 工程含义 |
|----|---------|---------|
| **吸收 A** | ∝ t / δ（厚度/趋肤深度） | 材料越厚、频率越高，吸收越强 |
| **反射 R** | ∝ Zs 与 Z0 的阻抗差 | 铜/铝与空气阻抗差大→反射强 |
| **多重反射 B** | 电磁波在屏蔽层内部反复反射的修正 | 吸收大时可忽略 |

> [!warning] 平板公式≠真实机箱
> 谢昆诺夫公式假设无限大平板 + 理想平面波。实际机箱有折边/螺钉/缝隙/通风孔/线缆——必须用三维电磁场仿真。

## 工程实战

### 通风孔设计

功耗高的设备必须开散热孔，但孔会泄漏电磁波。

- **厚孔≈截止波导**：厚度从 60mil（~1.5mm）增到 200mil（~5.1mm）可改善 ~20dB
- 六角形通风孔阵列比圆孔面积利用率高

### 缝隙天线效应

细长缝隙不只是泄漏通道——当尺寸与波长形成比例关系时，成为**缝隙天线**主动辐射。

> 频率升高→波长变短→原本不起眼的机箱接缝、散热孔、PCB 地平面分割、回流路径不连续都可能成为泄漏路径。

### 空腔谐振

金属机箱内部是一个复杂谐振腔。内部尺寸与波长满足谐振条件→场强在某些位置显著增强→从缝隙处向外辐射。

### 仿真定位流程

```
表面电流分布 → 近场分布 → 远场方向图
  ↓               ↓            ↓
找到电流集中区域  找到近场热区   确认远场泄漏方向
  ↓
定位根源：是散热孔？连接器边缘？上盖接缝？内部线缆共模电流？
```

### 共模电流

同轴电缆（不平衡线）接平衡负载 → 外导体外表面产生共模电流 → **电缆像天线一样辐射**。

**抑制方法**：
- **1/4 波长套筒巴伦**：末端短路→输入端高阻抗→阻断外表面共模电流
- 实际制作需考虑介质缩短率（经验值 ~67%）
- 多套筒同轴天线（COCO 天线）——逆向利用此原理

> [!tip] 屏蔽与天线没有绝对界限
> 同轴裸露中心导体 = 1/4 波长单极子。结构突变、端接不当时，屏蔽电缆自己变成辐射源。

## EMC 设计原则

1. **从原理阶段考虑电磁场路径**——事后补屏蔽棉/铜箔/磁环只能局部缓解
2. **孔缝是泄漏主通道**——开孔尽量厚（截止波导效应）、缝隙用导电衬垫
3. **共模电流是隐蔽杀手**——注意平衡-不平衡转接处的巴伦设计
4. **仿真定位优于盲目试验**——3D EM 仿真找到泄漏源再对症下药
5. **接地是屏蔽的前提**——不接地的金属壳 = 没有静电屏蔽效果
