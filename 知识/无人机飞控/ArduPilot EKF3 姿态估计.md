# ArduPilot EKF3 姿态估计

ArduPilot 的姿态/位置估计是飞行控制的核心,采用 **Extended Kalman Filter(EKF)** 融合速率陀螺、加速度计、罗盘、GPS、空速、气压计,输出位置、速度与姿态。EKF3(AP_NavEKF3)是当前默认估计器(4.1 起,2021-10),1MB flash 板上仅保留 EKF3。

## 三代估计器演进

| 代 | 算法 | 状态 |
|----|------|------|
| DCM | William Premerlani 的方向余弦矩阵互补滤波(ArduIMU 时代遗产) | 后台继续运行,作备份 |
| EKF2 | AP_NavEKF2,24 态误差模型 | 可选(4.5 起从默认固件移除,可经 Custom Build Server 启用) |
| EKF3 | AP_NavEKF3,扩展传感器源 + lane 冗余 | 默认(2021-10 起) |

## EKF2 状态模型(24 态)

姿态(四元数)、速度 NED、位置 NED、陀螺偏置 XYZ、陀螺尺度因子 XYZ、Z 轴加速度计偏置、地磁场 NED、机体系磁场 XYZ、风速 NE。

技术要点:

- **误差旋转向量修正四元数**(Pittelkau 2003):以小的误差旋转向量做姿态修正,避免大角度下的线性化误差——与 [ESKF](../../知识/姿态解算/误差状态卡尔曼滤波.md) "误差状态"思想的同源做法。
- **延迟时间地平线融合**(Khosravian 2015 输出预测器):测量与状态/协方差在同一时间点对齐,消除传感器延迟误差。

## 预测-更新循环

```mermaid
flowchart LR
    IMU["IMU 采样(角速度+加速度)"] --> PRED["状态预测:四元数积分→速度→位置"]
    PRED --> COV["协方差传播"]
    COV --> CHK{"测量到达?"}
    CHK -->|"GPS/气压计/罗盘/空速/光流"| INNOV["新息计算 + 一致性门控"]
    INNOV --> KAL["卡尔曼增益修正状态与协方差"]
    KAL --> OUT["输出位置/速度/姿态到控制环"]
    CHK -->|否| OUT
```

- 新息(innovation)一致性检查:方差测试比 < 1 表示测量被采用,用于拒绝坏数据。
- 状态间的相关性使一次 GPS 修正能同时修正位置、速度、姿态与陀螺偏置。

## 多实例冗余:Lane + Affinity + 自动切换

EKF3 的核心工程创新是**传感器级容错**:

- **Lane**:每个启用的 IMU 实例一个 EKF 实例(`EK3_IMU_MASK` 位掩码,最多 6 个,受内存/算力限制);仅健康评分最优的核心输出给控制环,可用 `EK3_PRIMARY` 指定主实例。
- **Affinity**(`EK3_AFFINITY`):让各 lane 绑定非主实例的空速计/气压计/罗盘/GPS,形成不同的"传感器组合路径"。
- **Lane Switching**:某 lane 因传感器噪声/故障积累的误差超过 `EK3_ERR_THRESH` 阈值时,系统切换到表现更好的 lane —— 传感器故障 → lane 切换 → 避免事故,官方有 SITL 验证。

## 传感器源与降级

- **GPS 分级使用**(`EK3_GPS_TYPE`):0=3D 速度+2D 位置;1=2D 速度+2D 位置;2=仅 2D 位置;3=不用 GPS 用光流。
- **非 GPS 导航**:光流、测距仪、UWB 信标(Beacon)、视觉里程计(Visual Odometry)、轮式编码器(Wheel Encoders)——后四者是 EKF3 相对 EKF2 新增的传感器源。
- **GPS-for-Yaw**:双天线定向,替代罗盘航向。
- 支持 GPS 与非 GPS 导航在飞行中切换(`EK3_SRC1/2/3` 源选择)。

## 与姿态解算理论的关系

ArduPilot EKF 与知识库中姿态解算谱系(见 [姿态解算/IMU姿态解算算法演进](../../知识/姿态解算/IMU姿态解算算法演进.md))的关系:

- EKF2/3 是**四元数全状态 EKF**:姿态本身在状态向量中,以误差旋转向量做增量修正,可视为 ESKF 思想的工程变体([Solà 的 ESKF 框架](../../知识/姿态解算/误差状态卡尔曼滤波.md) 是严格意义上的误差状态公式化);[InEKF](../../知识/姿态解算/InEKF%20不变扩展卡尔曼滤波源码.md) 则更进一步用李群状态获得状态无关的雅可比。
- DCM 备份链路延续了互补滤波家族(与 [Madgwick](../../知识/姿态解算/Madgwick%20Fusion%20源码深度解析.md) 同属"重力/磁参考修正"思路),作为 EKF 发散时的兜底。
- 工程取舍上,ArduPilot 立场是**封装优于可调**:官方称"大多数用户不需要修改任何 EKF 参数",把冗余与源选择收敛为 lane/affinity 少数高层决策(与 PX4 摊开成参数矩阵形成对比,见 [无人机飞控/ArduPilot vs PX4](../../知识/无人机飞控/ArduPilot%20vs%20PX4.md))。
- 日志:`NKF1`–`NKF5` 数据包记录 EKF 状态、新息与健康度,是飞行数据复盘的主要依据。

## ⚠️ 存疑标注

- "EKF3 减少了调参负担"为社区共识,官方文档未直接量化对比 EKF2/EKF3 参数数量;
- EKF2 独有能力(陀螺尺度因子估计)与 EKF3 三轴加速度计偏置估计的取舍,官方仅定性描述。
