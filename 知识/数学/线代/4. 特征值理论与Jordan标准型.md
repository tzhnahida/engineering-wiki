# 特征值理论与 Jordan 标准型

> 特征值 = 线性变换沿特定方向的伸缩因子。对角化是理想情况，Jordan 标准型是普遍情况。

## 特征值与特征向量

**定义**：若 Av = λv（v ≠ 0），则 λ 是特征值，v 是特征向量。

**特征多项式**：p_A(λ) = det(A − λI)，特征值 = p_A(λ) = 0 的根。

**几何意义**：A 作用在特征向量上 = 纯伸缩（方向不变）。这使得分析 A 的幂 Aⁿ、指数 eᴬ 变得简单。

## 对角化

A 可对角化 ⇔ 存在可逆矩阵 P 使得 P⁻¹AP = diag(λ₁,...,λₙ)

等价条件：A 有 n 个线性无关的特征向量。

**对角化之后的超能力**：

```
Aⁿ = P · diag(λ₁ⁿ,...,λₙⁿ) · P⁻¹    （幂计算→标量幂）
eᴬ = P · diag(e^λ₁,...,e^λₙ) · P⁻¹  （指数→标量指数）
```

**不可对角化怎么办？** → Jordan 标准型。

## Cayley-Hamilton 定理

每个方阵满足自身的特征多项式：p_A(A) = 0。

**应用**：Aⁿ (n ≥ 矩阵阶数) 可表示为 I, A, A², ... 的线性组合。这对理论推导极有用（如证明 eᴬ 级数收敛）。

## Jordan 标准型

当 A 不可对角化时（特征向量不够 n 个），存在可逆矩阵 P 使：

```
P⁻¹AP = diag(J₁, J₂, ..., Jₖ)
```

其中每个 **Jordan 块**：

```
J(λ) = [λ  1  0 ... 0]
       [0  λ  1 ... 0]
       [0  0  λ ... 0]
       [   ...   1  ]
       [0  0  0 ... λ]
```

**幂零部分**：对角线上的 1 表示"该方向的广义特征向量需要迭代 λI−A 才能归零"。Jordan 块的大小 = 特征值的几何重数与代数重数之差。

**对特征的深层理解**：
- 代数重数 = λ 作为特征多项式根的重数
- 几何重数 = λ 的特征子空间维数 = λ 对应的 Jordan 块个数
- 代数重数 − 几何重数 = "缺失的"特征向量维度

## 根子空间

**广义特征向量** v 满足 (A−λI)ᵏv = 0（k 足够大）。

**根子空间** R(λ) = 所有属于 λ 的广义特征向量的集合。维数 = λ 的代数重数。

**空间分解**：V = ⊕ R(λ_i)——每个根子空间都是 A 的不变子空间。这是 Jordan 标准型存在性的理论保证。

## 矩阵指数 eᴬ

```
eᴬ = I + A + A²/2! + A³/3! + ...
```

**与特征值的关系**：eᴬ 的特征值 = e^{λ_i(A)}。

**与微分方程的关系**：dx/dt = Ax 的解 = x(t) = e^{tA}·x(0)。

对 Jordan 块 J(λ)，e^{tJ} 有闭式——当 J 严格对角时就是 e^{λt}·v₀；有幂零部分时出现多项式因子 tᵏe^{λt}/k!。

## 在姿态估计中的应用

**指数矩阵与 Rodrigues**：so(3) 中的反对称矩阵 ω^ 通过指数映射 → SO(3) 中的旋转矩阵。这是 e^{ω^} = Rodrigues(ω)，因为 ω^ 的特征值是 0, ±i‖ω‖，指数映射给出纯旋转。

**协方差传播**：ESKF 中 P_{k+1} = Φ P_k Φᵀ + Q。Φ 的特征值决定了误差的收敛/发散速度。如果 Φ 有一个 >1 的特征值，协方差会按指数发散——这就是需要 Jordan 分解来分析系统稳定性的原因。

**极小多项式**：A 满足的次数最低的多项式 m(A) = 0。m 的根 = A 的特征值。m 的次数 ≤ n（特征多项式）。如果 m 是一次的乘积 → A 可对角化。
