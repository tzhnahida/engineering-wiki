# 矩阵与线性方程组

> 第 2 章。矩阵运算是线性映射的代数化身，消元法是解方程组的核心算法，秩是矩阵结构的本质不变量。

## 矩阵的基本运算

**加法**：m×n 矩阵 A + B = (aᵢⱼ + bᵢⱼ)，分量相加。Mₘₓₙ 构成线性空间，dim = mn。

**乘法**：A (m×p) × B (p×n) = C (m×n)，其中

```
cᵢⱼ = Σₖ aᵢₖ bₖⱼ
```

"行·列"：C 的 (i,j) 分量 = A 的第 i 行 与 B 的第 j 列 点乘。乘法满足结合律 (AB)C = A(BC)，但不满足交换律。

**乘法 = 线性映射复合**（命题 2.1.5）：若 f: Rᵖ → Rᵐ 对应矩阵 A，g: Rⁿ → Rᵖ 对应矩阵 B，则 f∘g: Rⁿ → Rᵐ 对应矩阵 AB。这是矩阵乘法的几何本义。

**分块矩阵**：矩阵按块划分后，块乘法公式 Cᵢⱼ = Σₖ AᵢₖBₖⱼ 仍然成立，但块乘积的顺序不可交换（A 的块在左，B 的块在右）。

> **两种分块视角**：
> - 按列分块：B = [β₁ β₂ … βₙ] → AB = [Aβ₁ Aβ₂ … Aβₙ]（AB 第 j 列 = A 乘 B 第 j 列）
> - 按行分块：A = [α₁; α₂; …; αₘ] → AB = [α₁B; α₂B; …; αₘB]（AB 第 i 行 = A 第 i 行乘 B）

## 线性方程组

**矩阵形式**：Ax = b，其中 A (m×n) 为系数矩阵，[A|b] 为增广矩阵。

### 高斯消元法

三种**初等行变换**（不改变解集）：

| 变换 | 操作 |
|------|------|
| 交换两行 | (rᵢ) ↔ (rⱼ) |
| 某行乘非零常数 | (rᵢ) → λ(rᵢ) |
| 某行的 λ 倍加到另一行 | (rⱼ) → (rⱼ) + λ(rᵢ) |

通过初等行变换，增广矩阵化阶梯形。阶梯形最后几行若出现 `0 = b'ᵣ₊₁ ≠ 0` → 无解。

### 齐次 vs 非齐次

- **齐次方程** Ax = 0 总有零解。关心是否还有非零解。
- **通解关系**：非齐次通解 = 非齐次特解 + 齐次通解

## 矩阵的秩

**行秩** = 行向量张成空间的维数。**列秩** = 列向量张成空间的维数。

行秩、列秩在初等行变换下均不变。阶梯形中非零行数 = 行秩 = 列秩 = **矩阵的秩 (rank A)**。

## 解的结构定理

**齐次方程**（定理 2.3.8）：设 A 为 m×n 矩阵，rank A = r。
- r = n → 只有零解
- r < n → 有非零解，通解含 n−r 个自由参数

**非齐次方程**（定理 2.3.10）：
- 有解 ⇔ rank A = rank[A|b]（即 b 在 A 的列空间中）
- 有解时：r = n → 唯一解；r < n → 无穷多解，n−r 个自由参数

## 秩-零化度定理

设 f: V → W 为线性映射，则

```
dim im(f) + dim ker(f) = dim V
```

即：像的维数（rank）+ 核的维数（零化度）= 定义域维数。

**几何直观**：f 把 V "压缩"到 im(f)，被压缩掉的部分是 ker(f)。**行满秩 ⇔ 满射，列满秩 ⇔ 单射。**

## 在工程中的应用

**解的存在唯一性**：Kalman 滤波中量测方程 z = Hx + v，H 的秩决定哪些状态可观测。

**最小二乘**：当 Ax = b 无解时（b ∉ 列空间），转而求解 AᵀAx = Aᵀb（正规方程），把 b 投影到 A 的列空间——这直接用到解空间结构。
