# 矩阵群与 Lie 代数

> 旋转矩阵不是孤立的——它们构成群 SO(3)，有 Lie 代数 so(3)，有指数映射。这是 InEKF 和姿态估计的数学地基。

## 群的基本概念

**群**：集合 G + 二元运算 `·`，满足结合律、有单位元 e、每个元素有逆。

**矩阵群** = 可逆矩阵的子集，在矩阵乘法下封闭。

## 常见矩阵 Lie 群

| 群 | 记号 | 元素 | 维度 | 工程含义 |
|-----|------|------|------|----------|
| 一般线性群 | GL(n,ℝ) | det ≠ 0 的 n×n 矩阵 | n² | 所有可逆线性变换 |
| 特殊线性群 | SL(n,ℝ) | det = 1 的矩阵 | n²−1 | 保体积变换 |
| **正交群** | **O(n)** | QᵀQ = I | n(n−1)/2 | 反射+旋转 |
| **特殊正交群** | **SO(n)** | QᵀQ = I, det=1 | n(n−1)/2 | **纯旋转** |
| **特殊欧几里得群** | **SE(3)** | [R t; 0 1], R∈SO(3) | 6 | **刚体运动** |
| 辛群 | Sp(2n,ℝ) | 保辛形式 | n(2n+1) | Hamilton 力学 |

**SO(3)** 是姿态估计的核心：每个 3×3 旋转矩阵 ∈ SO(3)。两个旋转的复合 = 矩阵乘法。逆旋转 = 转置。

**SE(3)** 是 InEKF 的状态空间：编码了旋转 + 平移。InEKF 进一步扩展为 SE_2(3)：旋转 + 速度 + 位置。

## Lie 代数

每个矩阵 Lie 群 G 在单位元 I 处的**切空间**记为 𝔤 = Lie(G)。𝔤 是一个线性空间（对矩阵加法封闭），但带有额外的括号运算：

```
[X, Y] = XY − YX   (交换子)
```

**关键对应**：

| Lie 群 | Lie 代数 | 元素形式 |
|--------|----------|----------|
| SO(3) | so(3) | 3×3 反对称矩阵 |
| SE(3) | se(3) | 4×4 矩阵，含角速度和线速度 |

so(3) 的元素（反对称矩阵）可以写为：

```
ω^ = [  0   −ωz   ωy ]
     [  ωz   0   −ωx ]
     [ −ωy   ωx   0  ]
```

向量 ω = (ωx, ωy, ωz) 是**角速度**——这就是陀螺仪输出的物理量。

## 指数映射

指数映射 exp: 𝔤 → G 将 Lie 代数元素"推"到群上：

```
exp(A) = I + A + A²/2! + A³/3! + ...
```

**SO(3) 上的指数映射 = Rodrigues 公式**：

```
exp(φ^) = I + sinθ/θ · φ^ + (1−cosθ)/θ² · (φ^)²
```

其中 θ = ‖φ‖。这给出了绕轴 φ/θ 旋转 θ 角的旋转矩阵。

**SE(3) 上的指数映射**：角速度 + 线速度 → 刚体运动（旋转 + 平移）。

### 指数映射在姿态估计中的核心地位

1. **陀螺积分**：ω·dt → exp(ω^·dt) → 旋转矩阵更新。这正是 VQF 和 Madgwick 中 `q ⊗ exp(ω·dt/2)` 的群论解释。
2. **误差状态更新**：InEKF 中 X_new = exp(ξ^)·X——误差 ξ（在 Lie 代数中）通过指数映射回到群 SE_2(3)。
3. **插值**：SO(3) 上的线性插值 = exp(t·log(R₁R₀⁻¹))·R₀（而非简单的 R₀ + t(R₁−R₀)）。

## 对数映射

log: G → 𝔤 是指数映射的逆（在单位元附近）。用于从旋转矩阵恢复角速度向量：

```
log(R) = θ/(2sinθ) · (R − Rᵀ)    (θ = arccos((tr(R)−1)/2))
```

## Baker-Campbell-Hausdorff (BCH) 公式

两个 Lie 代数元素的指数乘积如何合并：

```
exp(X)·exp(Y) = exp(X + Y + ½[X,Y] + 高阶交换子)
```

在姿态估计中，这解释了为什么**角速度不能简单相加**——连续两次旋转的复合角速度 ≠ 两次角速度之和。差值 = 交换子修正项。

## InEKF 中的李群

InEKF 直接把状态放在 SE_2(3) 上（而不像 ESKF 放在 ℝ¹⁵ 上再投影回 SO(3)）：

- 预测步：在 Lie 代数中做 → exp → 回到群上
- 校正步：误差 ξ 在李代数中 → K·ξ 在李代数中 → exp → 作用在群上

这就是"不变"的含义——误差传播的线性化点在群的恒等元 I 处（固定），不依赖于当前状态估计，因此误差动力学与状态无关。
