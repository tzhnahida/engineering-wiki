# 量子论简介

> 第 10 章。量子力学的数学语言就是线性代数：量子态 = 复线性空间（Hilbert 空间）中的向量，观测量 = 厄米算符，复合系统 = 张量积，测量 = 特征值 + Born 概率诠释。

## 量子力学基本原理

### 量子态

量子系统的状态由完备的酉空间（Hilbert 空间）V 描述。核心原理：

**线性叠加原理**：λ₁|ψ₁⟩ + λ₂|ψ₂⟩ ∈ V 仍是量子态。这是量子干涉、纠缠等现象的数学根源。

**Dirac 符号**：
- |ψ⟩：ket（态向量）
- ⟨φ|：bra（对偶向量）
- ⟨φ|ψ⟩：bracket（厄米内积），满足 ⟨φ|λψ⟩ = λ⟨φ|ψ⟩，⟨λφ|ψ⟩ = λ̄⟨φ|ψ⟩，⟨φ|ψ⟩ = ⟨ψ|φ⟩

### 观测量与量子算符

物理观测量 = 线性算符 A: V→V。伴随算符 A† 满足 ⟨A†φ|ψ⟩ = ⟨φ|Aψ⟩。**自伴算符**（厄米算符）：A = A†。

**关键性质**：
- 厄米算符的特征值全为实数（命题 10.1.2）
- 不同特征值的特征向量正交（命题 10.1.3）

**有限维例子**：V = Cⁿ，内积 ⟨u|v⟩ = Σ z̄ᵢwᵢ，A† = Āᵀ（共轭转置）。

### 量子测量与 Born 规则

可观测量 A 的特征向量 {|ψₐ⟩} 构成标准正交基，A|ψₐ⟩ = λₐ|ψₐ⟩。

**展开**：|ψ⟩ = Σ cₐ|ψₐ⟩，cₐ = ⟨ψₐ|ψ⟩，归一化 Σ|cₐ|² = 1。

**Born 规则**：测量 A 得到 λ 的概率 = Σ_{λₐ=λ} |cₐ|²。测量后量子态坍缩到对应特征态 |ψₐ⟩。

**期望值**：⟨A⟩_ψ = ⟨ψ|A|ψ⟩ = Σ λₐ|cₐ|²。

### 不确定性原理

**定理 10.1.5**：对任意厄米算符 A, B 和态 |ψ⟩：

```
(Δ_ψ A)² (Δ_ψ B)² ≥ ¼|⟨[A,B]⟩_ψ|²
```

其中 [A,B] = AB−BA 为对易子，Δ_ψ A = √⟨(A−⟨A⟩)²⟩。

**海森堡不确定性**：[x̂, p̂] = iℏ → Δx̂·Δp̂ ≥ ℏ/2。

### 复合系统

多粒子系统的态空间 = 各粒子态空间的**张量积**：V₁⊗V₂⊗…⊗V_N。

## 自旋系统（C² 的例子）

二维酉空间 V = C²。任意厄米算符可唯一表达为：

```
A = α₀I₂ + α₁σₓ + α₂σ_y + α₃σ_z,  αᵢ ∈ R
```

**Pauli 矩阵**：

```
σₓ = [0 1; 1 0],  σ_y = [0 −i; i 0],  σ_z = [1 0; 0 −1]
```

满足：σᵢ² = I，σₓσ_y = iσ_z = −σ_yσₓ（循环），特征值全为 ±1。

**自旋方向**：σ_𝐧 = nₓσₓ + n_yσ_y + n_zσ_z，σ_𝐧² = I，特征值 ±1。

**自旋态**：|u⟩ = [1;0]（上旋，σ_z=+1），|d⟩ = [0;1]（下旋，σ_z=−1）。|r⟩ = (|u⟩+|d⟩)/√2（右旋，σₓ=+1）。|i⟩ = (|u⟩+i|d⟩)/√2。

## 量子纠缠

### 纠缠态

**双自旋系统**：C²⊗C²，基为 |uu⟩, |ud⟩, |du⟩, |dd⟩。

**乘积态** vs **纠缠态**：可分解为 |ψ⟩ = |φ⟩⊗|χ⟩ 的是乘积态，否则是纠缠态。

**单重态**（singlet）：|s⟩ = (|ud⟩−|du⟩)/√2，是纠缠态（不可分解）。

### EPR 佯谬

在纠缠态 |s⟩ 中，如果 Alice 测量粒子 1 的 σ_z 得 +1 → 态坍缩为 |ud⟩ → Bob 的粒子 2 必测 σ_z = −1。

**关键**：无论两粒子相隔多远，测量一方瞬间确定另一方的状态——Einstein 称之为"鬼魅般的超距作用"，质疑量子力学不完备。

### 贝尔不等式

**量子力学预测**：P(𝐧₁,𝐧₂) = ⟨s|σ⁽¹⁾_𝐧₁ σ⁽²⁾_𝐧₂|s⟩ = −(𝐧₁·𝐧₂)。

**隐变量理论**满足贝尔不等式：|P̃(𝐧₁,𝐧₂) − P̃(𝐧₁,𝐧₃)| ≤ 1 + P̃(𝐧₂,𝐧₃)。

**量子力学违反贝尔不等式**：取 𝐧₁=(1,0,0), 𝐧₂=(0,1,0), 𝐧₃=(√2/2,√2/2,0)，则 |−√2/2 − 0| = 0.707 > 1 − √2/2 ≈ 0.293。

**实验结果**支持量子力学，排除**定域隐变量理论**。

## 数学结构全景

| 量子概念 | 线性代数对应 |
|----------|------------|
| 量子态 | 复 Hilbert 空间中的向量 |
| 叠加原理 | 线性组合 λ₁|ψ₁⟩+λ₂|ψ₂⟩ |
| 观测量 | 厄米算符 A = A† |
| 测量值 | 厄米算符的特征值（实数） |
| 测量概率 | |⟨ψₐ|ψ⟩|²（基展开系数的模平方） |
| 复合系统 | 张量积 V₁⊗V₂ |
| 纠缠态 | 不可分解的张量（非乘积态） |
| 不确定原理 | 对易子 [A,B] 的非零期望值 |
| 量子比特 | C²（二维酉空间 + Pauli 算符） |
