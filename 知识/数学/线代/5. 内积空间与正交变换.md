# 内积空间与正交变换

> 线性空间 + 内积 = 可以谈"角度""长度""正交"。SVD、QR、最小二乘全从这里来。

## 内积空间

**欧几里得空间**：实线性空间 + 正定对称双线性型 ⟨·,·⟩。定义了：
- 长度：‖v‖ = √⟨v,v⟩
- 夹角：cos θ = ⟨u,v⟩ / (‖u‖‖v‖)
- 正交：⟨u,v⟩ = 0

**Gram 矩阵**：给定向量组 v₁,...,vₖ，Gram 矩阵 G_{ij} = ⟨v_i, v_j⟩。行列式 = 这些向量张成的平行多面体的体积²。

## Gram–Schmidt 正交化

将任意线性无关组 {v₁,...,vₙ} 转为**正交归一**组 {e₁,...,eₙ}：

```
e₁ = v₁ / ‖v₁‖
u₂ = v₂ − ⟨v₂,e₁⟩·e₁    → e₂ = u₂ / ‖u₂‖
u₃ = v₃ − ⟨v₃,e₁⟩·e₁ − ⟨v₃,e₂⟩·e₂ → e₃ = u₃ / ‖u₃‖
...
```

## 正交矩阵与旋转

**正交矩阵** Q：满足 QᵀQ = I（列向量正交归一）。

| 性质 | 含义 |
|------|------|
| Qᵀ = Q⁻¹ | 逆 = 转置 |
| det(Q) = ±1 | +1 = 旋转 (SO(n)), −1 = 反射 |
| ‖Qx‖ = ‖x‖ | 保长变换 |
| ⟨Qx, Qy⟩ = ⟨x,y⟩ | 保角变换 |

**SO(3)** = { Q ∈ ℝ³ˣ³ : QᵀQ = I, det(Q) = 1 }——三维旋转群。这正是姿态估计中旋转矩阵的数学定义。

## 奇异值分解 (SVD)

对任意 m×n 矩阵 A，存在分解：

```
A = U Σ Vᵀ
```

- U: m×m 正交矩阵（左奇异向量）
- Σ: m×n 对角矩阵（奇异值 σ₁ ≥ σ₂ ≥ ... ≥ 0）
- V: n×n 正交矩阵（右奇异向量）

**几何意义**：任何线性映射 = 旋转/反射 (Vᵀ) → 沿轴缩放 (Σ) → 旋转/反射 (U)。

**关键应用**：
- **伪逆**：A⁺ = V Σ⁺ Uᵀ（Σ⁺ = 非零奇异值取倒数）
- **最小二乘**：min‖Ax−b‖ 的解 = A⁺b，当 A 列满秩时 = (AᵀA)⁻¹Aᵀb
- **低秩逼近**：取前 k 个奇异值 → 最优 k-秩近似（Eckart-Young 定理）
- **协方差分析**：AᵀA = V Σ² Vᵀ → 奇异值² = 特征值 → PCA 主成分

## QR 分解

对任意矩阵 A，存在分解：

```
A = QR
```

- Q: 正交矩阵
- R: 上三角矩阵

由 Gram-Schmidt 直接推出：A 的列向量正交归一化 → Q，系数存 R。

**应用**：解 Ax=b 时比直接求逆更数值稳定（QᵀAx = Qᵀb → Rx = Qᵀb → 回代）。

## 最小二乘法

超定方程组 Ax = b（方程数 > 未知数，通常无精确解）的最小二乘解：

```
x̂ = argmin ‖Ax − b‖²
```

解法：
1. 正规方程：AᵀAx̂ = Aᵀb（数值不稳定）
2. **QR 分解**：A = QR → Rx̂ = Qᵀb（稳定）
3. SVD 伪逆：x̂ = V Σ⁺ Uᵀb（最稳定，代价最高）

**几何解释**：x̂ 使 Ax̂ = b 在 im(A) 上的正交投影——误差 b−Ax̂ ⟂ im(A)。

## 酉空间

实内积空间的复推广。内积变为共轭对称的 Hermite 型 ⟨u,v⟩ = ūᵀv。

酉矩阵 U 满足 U*U = I（U* = 共轭转置）。Hermite 矩阵满足 H* = H，特征值全为实数——量子力学中可观测量 = Hermite 算符。
