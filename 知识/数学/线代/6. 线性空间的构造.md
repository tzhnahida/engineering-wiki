# 线性空间的一些构造

> 第 6 章。从已有线性空间构造新空间：对偶、商、自由生成、张量积、对称代数、外代数——这些构造是现代数学和物理的基础语言。

## 对偶空间

**定义**：V 的对偶空间 V\* = {f: V → k | f 是线性映射}（所有线性函数）。

**对偶基**（命题 6.1.2）：若 {eᵢ} 是 V 的基，定义 eⁱ(eⱼ) = δⁱⱼ，则 {eⁱ} 是 V\* 的基。dim V\* = dim V。

**双重对偶**（命题 6.1.3）：有限维时 V ≅ V\*\*，自然同构为 v ↦ (f ↦ f(v))。

**对偶映射**：T: V → W 的对偶 T\*: W\* → V\* 定义为 (T\*g)(v) = g(Tv)。满足：
- (S∘T)\* = T\*∘S\*
- 若 T 在基下矩阵为 A，则 T\* 在对偶基下矩阵为 Aᵀ

**工程联系**：V\* 中的元素对应协方差加权残差。对偶基 eⁱ(x) = xᵢ 即坐标提取——Kalman 更新中残差 r = z − Hx 的本质是对偶作用。

## 商空间

**定义**：V/W = {v+W | v∈V}，其中 v₁ ∼ v₂ ⇔ v₁−v₂ ∈ W。dim(V/W) = dim V − dim W。

**几何**：商空间 = 把 W "压缩为一个点"。R³ 模一个过原点的平面 → 1 维空间（法线方向）。

**同构**：(V/W)\* ≅ W⁰ = {f∈V\* | f(w)=0 ∀w∈W}（商空间的对偶 = W 的零化子）。

## 自由生成的向量空间

**定义**：对任意集合 X，F(X) = {Σ aₓx | aₓ∈k, 仅有限非零}，以 X 为基。

**泛性质**（命题 6.1.9）：任意集合映射 φ: X→V 可唯一延拓为线性映射 φ̃: F(X)→V。

**例子**：X = {1, x, x², …} → F(X) = R[x]（多项式空间）。有限集 → 有限维。

## 张量积

**构造**：V⊗W = F(V×W)/R，其中 R 由双线性关系生成：(v₁+v₂)⊗w − v₁⊗w − v₂⊗w 等。

**泛性质**：双线性映射 φ: V×W → U 可唯一分解为 V×W → V⊗W → U。

**基与维数**：{eᵢ⊗fⱼ} 是 V⊗W 的基，dim(V⊗W) = (dim V)(dim W)。

**Kronecker 积**：Mₘₓₙ ⊗ Mₚₓₓ ≅ Mₘₚₓₙₓ，A⊗B = [aᵢⱼB]。

**重要同构**：Hom(V,W) ≅ V\*⊗W。多重张量积 V₁⊗…⊗Vₘ：张量 A 的系数 a_{j₁…jₘ} 对应多维数组。

**张量阶数**：0 阶 = 标量，1 阶 = 向量，2 阶 = 矩阵，3 阶+ = 高维数组。张量是向量和矩阵向多指标的自然推广。

## 对称代数

**对称张量**：Tᵐ(V) 中满足 σ(A) = A（置换不变）的元素构成 Symᵐ(V)。dim Symᵐ(V) = C(n+m−1, m)。

**对称化**：Sym(A) = (1/m!) Σ_{σ∈Sₘ} σ(A)。

**乘法**：A•B = Sym(A⊗B)，满足交换律。Sym(V) 同构于多项式代数 R[x₁,…,xₙ]。

## 外代数 (Grassmann 代数)

**反对称张量**：∧ᵐ(V) = {A∈Tᵐ(V) | σ(A) = sgn(σ)A}。

**外积**：A∧B = Alt(A⊗B)，满足 **分次交换律** A∧B = (−1)ʳˢB∧A（A∈∧ʳ, B∈∧ˢ）。

特别地：v∧v = 0，v∧w = −w∧v。

**基与维数**（命题 6.2.15）：{e_{i₁}∧…∧e_{iₖ} | 1≤i₁<…<iₖ≤n} 是 ∧ᵏV 的基，dim ∧ᵏV = C(n,k)。

> R³ 的外代数：∧⁰ = R（标量），∧¹ = R³（向量），∧² ≅ R³（叉积——赝向量），∧³ ≅ R（体积元），∧ᵏ=0 (k>3)

## 行列式的外代数定义

**内蕴定义**（定义 6.2.16）：dim V = n，∧ⁿV 为 1 维。线性映射 T 诱导 ∧ⁿT: ∧ⁿV → ∧ⁿV，定义 det T 使得 ∧ⁿT(ω) = (det T)ω。

展开到基下即得组合定义公式：

```
det T = Σ_{σ∈Sₙ} sgn(σ) a_{σ(1)1} … a_{σ(n)n}
```

## Pfaffian

对 2n×2n 反对称矩阵 A：det A = (Pf(A))²。当 n=1：Pf([0 a; −a 0]) = a。Pfaffian 由外代数 ωⁿ_A/n! = Pf(A)·e₁∧…∧e₂ₙ 定义。

辛矩阵 A（满足 AᵀJA = J）满足 det A = 1——由 Pf(J) = Pf(AᵀJA) = Pf(J)det A 导出。

## 工程视角

- **张量积 + Kronecker 积**：多传感器协方差的联合表达
- **外代数 + 行列式**：SO(3) 旋转矩阵行列式为 1 的内蕴证明
- **对偶空间**：残差、梯度的对偶本质
- **Pfaffian + 辛矩阵**：Hamilton 力学中的保体积性质
