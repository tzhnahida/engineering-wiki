# 线性微分方程

> 第 7 章。线性代数为常微分方程提供了统一的求解框架：一阶化 → 矩阵指数 → Jordan 分解，所有线性 ODE 都可归结为 eᵗᴬ。

## 基本概念

**ODE vs PDE**：ODE 依赖单自变量（如时间 t），PDE 依赖多变量（如热方程 ∂u/∂t = ∂²u/∂x²）。本章专注 ODE。

**线性 vs 非线性**：F(t,y,y′,…,y⁽ⁿ⁾)=0 中，若 F 关于 y 及其导数是线性的 → 线性 ODE，否则非线性。

**n 阶线性 ODE**：a₀(t)y⁽ⁿ⁾ + … + aₙ(t)y + b(t) = 0。b(t)=0 → 齐次。aᵢ 是常数 → 常系数。

**关键技巧——一阶化**（命题 7.1.3）：任意 n 阶 ODE 可化为一阶系统 d**y**/dt = A**y** + **b**(t)：

```
n阶方程 y⁽ⁿ⁾ = a₀y + … + aₙ₋₁y⁽ⁿ⁻¹⁾  ⇔  d/dt [y, y₁, …, yₙ₋₁]ᵀ = A [y, y₁, …, yₙ₋₁]ᵀ
```

伴随矩阵 A 的最后一行 = [a₀, a₁, …, aₙ₋₁]。

## 常系数齐次方程

### 一阶系统

```
d/dt y = Ay,  y(0) = y₀  ⇒  y(t) = eᵗᴬ y₀
```

**解的唯一性定理**（7.2.1）：eᵗᴬ y₀ 是唯一解。关键步骤：若 ỹ 也是解，则 d/dt(e⁻ᵗᴬ ỹ) = 0，故 e⁻ᵗᴬ ỹ 是常数 → ỹ = eᵗᴬ y₀。

### n 阶齐次方程

**特征多项式法**：y⁽ⁿ⁾ + a₁y⁽ⁿ⁻¹⁾ + … + aₙy = 0 的特征多项式为 λⁿ + a₁λⁿ⁻¹ + … + aₙ = 0。

若 P(λ) = (λ−λ₁)ᵐ¹…(λ−λₖ)ᵐᵏ，则 n 个线性无关解为：

```
{e^{λ₁t}, te^{λ₁t}, …, t^{m₁−1}e^{λ₁t}, …, e^{λₖt}, te^{λₖt}, …, t^{mₖ−1}e^{λₖt}}
```

**复根处理**：λ = α±iβ → e^{αt}cos(βt), e^{αt}sin(βt)（重根时乘多项式因子）。

> **例子**：y′′′ − 3y′ + 2y = 0，特征根 1(二重), −2 → 通解 a₁eᵗ + a₂teᵗ + a₃e⁻²ᵗ。

### 非齐次方程

非齐次通解 = 特解 + 齐次通解。

**一阶系统**（定理 7.2.2）：d**y**/dt = A**y** + **b**(t) 的解：

```
y(t) = eᵗᴬ y₀ + ∫₀ᵗ e⁽ᵗ⁻ˢ⁾ᴬ b(s) ds
```

**特解猜测法**：n 阶方程 y′′ + y = cos(2t) → 复数化 z′′+z = e²ⁱᵗ → 猜测 z = ae²ⁱᵗ → a = −1/3 → y = −⅓cos(2t)。若驱动频率 = 特征根频率 → 产生共振（t·sin t 项）。

## 极限行为与稳定性

### Jordan 分解法

eᵗᴬ = Peᵗᴰ eᵗᴺ P⁻¹：
- eᵗᴰ = diag(e^{tλᵢ})（对角部分）
- eᵗᴺ = I + tN + … + tⁿ⁻¹Nⁿ⁻¹/(n−1)!（幂零部分，多项式有界）

**稳定性判据**（命题 7.2.6）：若 A 的所有特征值实部 < 0 → 所有解 t→∞ 时 → 0（汇点/吸引子）。

### 二维系统相图

| 特征值 | 平衡点类型 | 行为 |
|--------|-----------|------|
| λ₁,λ₂ < 0 | 汇点 | t→∞ 所有解 → 原点 |
| λ₁,λ₂ > 0 | 源点 | t→−∞ 所有解 → 原点 |
| λ₁<0<λ₂ | 鞍点 | 一部分吸引，一部分排斥 |
| λ = α±iβ, α<0 | 稳定焦点 | 螺旋趋近原点 |
| λ = α±iβ, α>0 | 不稳定焦点 | 螺旋远离原点 |
| λ = ±iβ | 中心 | 周期轨道（同心圆） |

## 变系数方程

### 路径排序指数

当 A(t) 依赖 t 时，eᵗᴬ⁽ᵗ⁾ 不再是解。推广为 **P exp**(∫₀ᵗ A(s)ds)：

```
P exp(∫₀ᵗ A(s)ds) = Σ_{n≥0} ∫_{0≤t₁≤…≤tₙ≤t} dt₁…dtₙ A(tₙ)…A(t₁)
```

满足 d/dt P(t) = A(t)P(t)，P(0)=I，且 P(t) 可逆。

**变系数解**（定理 7.3.3）：y(t) = P(t)y₀ + P(t)∫₀ᵗ P⁻¹(s)b(s)ds。

### 常数变易法 (Variation of Parameters)

已知齐次方程的 n 个线性无关解 ỹ₁,…,ỹₙ，设特解 y(t) = Σ cᵢ(t)ỹᵢ(t)，解 Wronskian 行列式方程组：

```
W(t) [c₁′,…,cₙ′]ᵀ = [0,…,0,b(t)]ᵀ
```

cᵢ′(t) = Wᵢ(t)/W(t)，其中 W = det[ỹᵢ⁽ʲ⁾]（Wronskian 行列式），Wᵢ = 将第 i 列替换为 [0,…,b(t)]ᵀ。

> **例子**：y″ + y = f(t)，基解 cos t, sin t，W=1，c₁′ = −sin(t)f(t)，c₂′ = cos(t)f(t) → yₚ(t) = ∫₀ᵗ sin(t−s)f(s)ds。

## 工程联系

- **ESKF 状态传播**：dx/dt = Fx + Gw ⇔ 常系数齐次/非齐次 ODE，解 = e^{FΔt} x₀ + 过程噪声积分
- **稳定性分析**：特征值实部 < 0 ⇔ 滤波器收敛，= PID 控制器稳定裕度
- **路径排序指数**：IMU 预积分（连续时间动力学离散化）的本质
- **Wronskian**：所有基解线性无关 ⇔ 可观性矩阵满秩
