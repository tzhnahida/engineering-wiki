# 行列式的几何意义

> 行列式 = 有向体积。n 个向量张成的平行多面体的有向体积，符号表示定向。

## 几何定义

从低维开始：

**2D 面积**：两个向量 a, b 张成的平行四边形面积 = |a₁b₂ − a₂b₁| = |det([a b])|

**3D 体积**：三个向量 a, b, c 张成的平行六面体体积 = |det([a b c])| = |a·(b×c)|

推广到 n 维：det(v₁,...,vₙ) = n 个向量张成的 n 维平行体的**有向体积**。

## 组合定义（Leibniz 公式）

```
det(A) = Σ_{σ∈S_n} sgn(σ) · a_{1,σ(1)} · a_{2,σ(2)} ··· a_{n,σ(n)}
```

每一项是矩阵不同行不同列的 n 个元素的乘积，带符号（偶排列=正，奇排列=负）。

n=3 时有 6 项——这正是 Sarrus 规则。

## 基本性质（从几何推）

| 性质 | 几何解释 |
|------|----------|
| det(I) = 1 | 单位立方体体积=1 |
| 交换两行→符号反转 | 定向翻转 |
| 两行相等→det=0 | 退化（体积为 0） |
| 某行乘 k→det 乘 k | 该方向伸缩 k 倍 |
| 某行加另一行的倍数→det 不变 | 剪切变换保体积 |
| det(AB) = det(A)det(B) | 连续两次变换的体积缩放因子 |

## Laplace 展开定理

沿第 i 行展开：

```
det(A) = Σ_{j=1}^n (−1)^{i+j} a_{ij} · det(M_{ij})
```

M_{ij} = 去掉第 i 行第 j 列的余子式。C_{ij} = (−1)^{i+j}det(M_{ij}) = 代数余子式。

**工程意义**：这是行列式递推计算的基础，也是伴随矩阵求逆的来源。n≤4 时手算最快。

## Cramer 法则

Ax = b 的解：

```
x_i = det(A_i) / det(A)
```

A_i = 将 A 的第 i 列替换为 b。

复杂度 O(n!)——仅适用于 n≤3 的理论推导。实际计算用 LU 分解/Gauss 消元。

## 矩阵的逆

A 可逆 ⇔ det(A) ≠ 0

A⁻¹ = (1/det(A)) · adj(A)

adj(A)_{ij} = C_{ji}（代数余子式矩阵的**转置**）。

## 行列式与线性映射

线性映射 T: V→V 的**行列式** = T 在任意基下的矩阵的行列式——与基的选择无关。

几何意义：det(T) = T 对体积的缩放因子。det(T) > 0 → 保持定向，< 0 → 翻转定向。
