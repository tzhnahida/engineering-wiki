# 线性规划

> 第 9 章。从线性等式 Ax=b 到线性不等式 Ax≤b——线性规划的数学基础，含凸集分离定理、Farkas 引理、单纯形法、对偶理论，以及在博弈论中的应用。

## 凸集

**定义**：C ⊆ Rⁿ 是凸集，若 ∀x,y∈C, λ∈[0,1]：λx + (1−λ)y ∈ C。

**超平面分离定理**（定理 9.1.2）：两个不相交的非空凸集 C, D，存在超平面 aᵀx = b 分离它们：aᵀx ≤ b (x∈C)，aᵀx ≥ b (x∈D)。若 C, D 都是闭集且至少一个紧集，分离是严格的。

这一定理是整个线性规划理论的几何基石。

### Farkas 引理

**命题 9.1.3**：对于 A (m×n) 和 b∈Rᵐ，以下二系统恰好一个有解：

| 系统 (1) | 系统 (2) |
|----------|----------|
| Ax = b, x ≥ 0 | Aᵀy ≥ 0, bᵀy < 0 |

**几何解释**：要么 b 在 A 的列向量生成的凸锥中（有非负系数表达），要么存在一个超平面将 b 与这个锥分离。

**不等号版本**（推论 9.1.4）：Ax ≤ b, x ≥ 0 无解 ⇔ 存在 y ≥ 0 使得 Aᵀy ≥ 0, bᵀy < 0。

## 线性规划标准形式

```
最大化 cᵀx
满足   Ax ≤ b
       x ≥ 0
```

可行域 S = {x: Ax≤b, x≥0} 是凸多面体。**解存在性定理**（9.2.1）：可行域非空且目标函数有上界 → 最优解存在。无最优解只有两种情况：(1) 可行域为空，(2) 目标函数无界。

## 单纯形法 (Simplex Method)

核心思想：沿凸多面体的顶点移动，逐步改进目标函数值。

**步骤示意**（以生产计划问题为例）：
1. 引入松弛变量，化不等式为等式
2. 从可行域的一个顶点出发（x₁=x₂=0）
3. 检查目标函数各变量的系数——选择系数最大的变量进基
4. 确定离基变量（约束条件中最紧的）
5. 更新顶点，重复直到目标函数系数全非正

**关键洞察**：线性目标函数的最优值一定在凸多面体的某个顶点取到（若最优解存在）。

## 对偶理论

**原问题 (Primal)** → **对偶问题 (Dual)**：

| | 原问题 | 对偶问题 |
|--|--------|----------|
| 目标 | max cᵀx | min bᵀy |
| 约束 | Ax ≤ b, x ≥ 0 | Aᵀy ≥ c, y ≥ 0 |
| 变量数 | n | m |
| 约束数 | m | n |

**弱对偶定理**（9.2.3）：cᵀx ≤ bᵀy（原问题任意可行解 ≤ 对偶问题任意可行解）。

**强对偶定理**（9.2.4）：若原问题有最优解，则对偶问题也有最优解，且最优值相等：max{cᵀx} = min{bᵀy}。

**证明核心**：用 Farkas 引理 + 反证法证明存在对偶可行解 y\* 使 bᵀy\* ≤ z\*，结合弱对偶得等号。

## 博弈论应用

### Minimax 定理

**双人零和博弈**：收益矩阵 A = (aᵢⱼ)，玩家 1 收益 aᵢⱼ，玩家 2 收益 −aᵢⱼ。

**混合策略**：玩家 1 以概率分布 x∈Δₘ 选策略，玩家 2 以概率分布 y∈Δₙ 选策略。期望收益 = xᵀAy。

**Minimax 定理**（9.3.1）：

```
max_{x∈Δₘ} min_{y∈Δₙ} xᵀAy = min_{y∈Δₙ} max_{x∈Δₘ} xᵀAy = v
```

**证明思路**：玩家 1 的优化问题可表述为线性规划（max v, s.t. Σ aᵢⱼxᵢ ≥ v），其对偶 = 玩家 2 的优化问题。由强对偶定理得等号。

**推论**（9.3.2）：有限策略两人零和博弈的混合策略纳什均衡总是存在的。

**猜硬币例子**：无纯策略均衡，混合策略 (p=q=1/2) 是纳什均衡，博弈值 = 0。

## 工程联系

- **最优控制**：LQR 的约束形式可转化为线性规划（不等式约束）
- **资源分配**：传感器带宽分配、计算资源调度
- **对偶理论**：凸优化中 Lagrange 对偶的线性特例——KTT 条件在此退化为 Farkas 引理
