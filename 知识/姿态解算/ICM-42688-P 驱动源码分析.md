# ICM-42688-P 驱动源码分析

> 基于 SlimeVR 固件的 `icm42688.h` 驱动。I2C 地址 0x68，16 位模式，200Hz 陀螺 / 100Hz 加计。

## 初始化序列（7 步）

| 步 | 寄存器 | 值 | 含义 |
|----|--------|-----|------|
| 1 | DEVICE_CONFIG (0x11) | 0x01 | 软复位 |
| 2 | INTF_CONFIG0 (0x4C) | 0x00 | 小端、FIFO 2048 字节 |
| 3 | GYRO_CONFIG0 (0x4F) | 0x27 | ±1000dps, 200Hz ODR |
| 4 | ACCEL_CONFIG0 (0x50) | 0x28 | ±8g, 100Hz ODR |
| 5 | FIFO_CONFIG0 (0x16) | 0x40 | Stream-to-FIFO 模式 |
| 6 | FIFO_CONFIG1 (0x5F) | 0x07 | 启用 accel+gyro+temp |
| 7 | PWR_MGMT0 (0x4E) | 0x0F | 低噪声模式 |

## 灵敏度 / 量程

| 参数 | 16 位模式 | 20 位高分辨率 |
|------|----------|-------------|
| 陀螺 LSB/dps | **32.8** | 131.0 |
| 加计 LSB/g | **4096** | 8192 |
| 陀螺转换 rad/s | `PI/(32.8×180)` = 5.32e-4 | 1.33e-4 |
| 加计转换 m/s² | `9.81/4096` = 2.395e-3 | 1.198e-3 |

## FIFO 数据包结构 (16 字节/包)

| 偏移 | 字段 | 类型 | 大小 | 说明 |
|------|------|------|------|------|
| 0 | accel[0] | int16 | 2 | X 轴加速度 |
| 2 | accel[1] | int16 | 2 | Y 轴加速度 |
| 4 | accel[2] | int16 | 2 | Z 轴加速度 |
| 6 | gyro[0] | int16 | 2 | X 轴角速度 |
| 8 | gyro[1] | int16 | 2 | Y 轴角速度 |
| 10 | gyro[2] | int16 | 2 | Z 轴角速度 |
| 12 | temp | int8 | 1 | ⚠️ 应为 int16 |
| 13 | timestamp | uint16 | 2 | 时间戳 |
| **有效数据** | | | **15** | 合计有效字节 |
| +1 头部字节 | | | **1** | 被丢弃 |
| **总计** | | | **16** | 每包大小 |

FIFO 容量：2048B / 16B = **128 个数据包**。每次批量读取 8 个（128B 缓冲）。

## 20 位高分辨率解包

```cpp
// 陀螺仪：19 位有效（LSB 始终 0）
gyro_20bit = (int32_t(gyro_16bit) << 3) | ((xlsb & 0x0E) >> 1)

// 加速度计：18 位有效（最低 2 位始终 0）
accel_20bit = (int32_t(accel_16bit) << 2) | ((xlsb & 0xF0) >> 6)
```

高分辨率模式下 FIFO 包 = 20 字节，每批 4 包。

## 电源

当前配置：陀螺 LN + 加计 LN = **~3.7mA** @ 200Hz。

| 模式 | 陀螺 | 加计 | 总电流 |
|------|------|------|--------|
| 低噪声 | 3.0mA | 0.7mA | 3.7mA |
| 低功耗 | — | 0.22mA | <1mA |

## 驱动缺陷（对比 ICM45Base）

| 问题 | 影响 |
|------|------|
| 缺少 FIFO M-1 模式 | 可能读到损坏的空包（AN-000364 建议） |
| 温度 int8 vs int16 | 无效值检测始终通过（比较 bug） |
| 滤波器寄存器未配置 | 使用默认 LPF 拐角 ~50Hz |
| 无 WHO_AM_I 验证 | 不确认芯片存在 |
| 无中断配置 | 轮询 FIFO_COUNT，增加总线负载 |
| FIFO 头部丢弃 | ICM45Base 解析 has_gyro/has_accel 位 |

## 温度传感器

```
T(°C) = raw_LSB × 2.07 + 25.0     (16 位模式)
T(°C) = raw_LSB × 0.004043 + 25.0 (20 位模式)
```

采样周期与陀螺 ODR 相同 (5ms)。
