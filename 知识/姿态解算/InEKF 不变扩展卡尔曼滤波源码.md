# InEKF 不变扩展卡尔曼滤波源码

> UMich-CURLY/husky_inekf — C++ Eigen 实现。状态在 SE_2(3) 李群上，15 维误差状态。

## 核心创新：状态在群上，不在向量空间

标准 EKF 把旋转当欧拉角/四元数向量处理 → 线性化点依赖状态估计 → **不一致**。

InEKF 把状态放在 SE_2(3) 矩阵群上：

```
X = [ R   v   p ]    ∈ SE_2(3) ⊂ R^{5×5}
    [ 0   1   0 ]
    [ 0   0   1 ]

R: SO(3) 旋转矩阵
v: 世界坐标系速度
p: 世界坐标系位置
```

误差定义：δX = X⁻¹ · X̂（左不变）→ 误差动力学与状态估计**无关**。

## 状态向量

| 部分 | 维度 | 载体 | 说明 |
|------|------|------|------|
| 群状态 X | 5×5 矩阵 | SE_2(3) | R, v, p + 可增强界标列 |
| 偏差 Θ | 6×1 向量 | ℝ⁶ | b_g(3) + b_a(3) |
| 协方差 P | 15×15 | ℝ^{15×15} | 方向+速度+位置+偏差 |

可动态增强（augment）：每增加一个接触点/界标，X 加一列，P 加 3 维。

## 预测步：闭式积分

不使用 RK4。基于 Rodrigues 公式的 Gamma 级数展开：

```
R_{k+1} = R_k · Γ_0(φ)           Γ_0 = I + sinθ/θ·φ^ + (1-cosθ)/θ²·(φ^)²
v_{k+1} = v_k + (R_k·Γ_1(φ)·a + g)Δt
p_{k+1} = p_k + v_k·Δt + (R_k·Γ_2(φ)·a + ½g)Δt²
```

Γ_1 = SO(3) 左 Jacobian，Γ_2 = 高阶积分。小角度时自动退化为泰勒级数。

**状态转移矩阵 Φ** 完全闭式——不数值差分。这是 InEKF 理论要求的精度。

## 校正步

支持的测量类型：

| 测量 | 方法 | 不变性 |
|------|------|--------|
| 运动学接触点 | CorrectKinematics | 右不变 |
| 视觉界标 | CorrectLandmarks | 右不变 |
| 机体速度 | CorrectVelocity | 右不变 |
| GPS 位置 | CorrectPosition | *左不变(注释掉，未测试)* |
| 磁力计 | CorrectMagnetometer | *未实现* |

校正公式（右不变）：`X_new = exp(K·Z)^ · X`

**偏航偏差不可观强制**：`dTheta(2) = 0`，对应协方差行/列清零。这是物理事实——仅 IMU 无法观测偏航偏差。

## 与标准 EKF 的关键差异

| 标准 EKF | InEKF |
|----------|-------|
| 线性化点 = 当前状态估计 | 线性化点 = 恒等元（固定） |
| 误差动力依赖状态 → 可能不一致 | 误差动力与状态无关 → **一致** |
| 偏航可能虚假可观 | 正确保留偏航不可观性 |
| 协方差可能在旋转大时崩溃 | 协方差在群结构下保持有效 |
| 需要手动归一化四元数 | 指数映射自然保持 SO(3) |

## 噪声参数默认值

| 参数 | 值 | 含义 |
|------|-----|------|
| Q_g | 0.01² I | 陀螺白噪声 (rad/s)² |
| Q_a | 0.1² I | 加速度计白噪声 (m/s²)² |
| Q_bg | 10⁻⁵ I | 陀螺偏差随机游走 |
| Q_ba | 10⁻⁴ I | 加速度计偏差随机游走 |

## Phase 2 适用性

对于 15 节点全身动捕：InEKF 可用速度测量（ZUPT 输出的零速）和接触点测量（脚着地）。基态 15×15 矩阵在 ESP32 上不可行——需要 PC 端实现。但你的 PC 端 Phase 2 本来就需要 GPU/CPU 混合方案。
