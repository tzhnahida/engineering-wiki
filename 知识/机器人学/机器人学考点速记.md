# 机器人学考点速记

> [!note] 页面定位
> 面向闭卷笔试的机器人学基础速记：坐标变换、DH 参数、正/逆运动学、雅可比与奇异、动力学、轨迹规划、差速运动学、PID。所有结论标注来源与置信度；四元数的深入内容见 [姿态解算/IMU姿态解算算法演进](../姿态解算/IMU姿态解算算法演进.md)。

## 1. 旋转矩阵与坐标变换

旋转矩阵 R 是**正交矩阵**，性质（高频填空题）：

- 每列（每行）各元素平方和为 1：`r11²+r21²+r31² = 1`（列向量模为 1）
- 不同列（行）对应元素乘积之和为 0（列向量两两正交）
- det(R) = +1，R⁻¹ = Rᵀ

**三种用途**（同一个矩阵，三种身份）：
1. 姿态描述（相对某参考系的方位）
2. 坐标变换（把向量从一个系映射到另一个系）
3. 算子（在同一个系内旋转向量）

**变换口诀**："**右乘联体、左乘基**"——绕当前（运动）坐标系旋转用右乘，绕固定（基）坐标系旋转用左乘。

齐次变换矩阵（4×4）同时表达旋转和平移：

```text
T = [ R  p ]     R: 3×3 旋转矩阵, p: 3×1 平移向量
    [ 0  1 ]
```

⚠️ 易错：绕 x 轴旋转的旋转矩阵中 sin 项位置——R_x(θ) 的 (2,3)/(3,2) 项为 ∓sinθ；绕 y 轴旋转时 sin 符号与 x/z 轴**相反**（(1,3) 为 +sinθ）。

## 2. 欧拉角与万向节锁

- **ZYX 欧拉角**（α 绕 Z、β 绕 Y、γ 绕 X）：R = R_z(α)·R_y(β)·R_x(γ)（⚠️ 注意乘序与旋转顺序相反——先转的写在最右边）
- **万向节锁**：当中间角 β = ±90° 时，第一轴与第三轴共线，丢失一个自由度（三个角退化描述两个自由度）
- 判断记忆句：β = ±90° 时 R(3,1) = ∓sinβ = ∓1，出现万向节锁

## 3. 四元数

- 定义：q = w + xi + yj + zk = [w, v]，单位四元数 ‖q‖ = 1 表示旋转
- **轴角转四元数**：绕单位轴 u 转 θ → q = [cos(θ/2), u·sin(θ/2)]
- **四元数转轴角**：轴 = 向量部分归一化方向，θ = 2·arccos(w)（或 2·arcsin(‖v‖)）
- 例（高频填空题）：q = [0.707, 0, 0.707, 0] = [√2/2, 0, √2/2, 0] → 向量部分指向 Y 轴，θ = 2·arcsin(0.707) = 90°，即**绕 Y 轴旋转 90°**
- **四元数插值 slerp**（真题出现大题）：初末角速度为零、中间转速恒定、角速度连续——这是四元数相对欧拉角的插值优势
- 单位四元数性质：q·q⁻¹ = [1,0,0,0]；连续旋转用四元数乘法（不可交换）

| 姿态表示 | 参数数 | 最小表示? | 万向节锁 | 插值 |
|----------|--------|-----------|----------|------|
| 旋转矩阵 | 9 | 否 | 无 | 困难 |
| 欧拉角 | 3 | 是 | 有（β=±90°） | 逐角线性插值不自然 |
| 等效轴角 | 4（轴3+角1） | 否（约束1） | 无 | 可 |
| 四元数 | 4 | 否（约束1） | 无 | slerp 最短路径、角速度连续 |

⚠️ 易错判断题：**"等效轴角表示是姿态的最小表示" = 错误**（轴 3 参数 + 角 1 参数共 4 个，带单位约束，最小表示为 3 参数的欧拉角族）。

## 4. DH 参数与正运动学

**DH 四参数**（连杆 i-1 到连杆 i）：a（连杆长度）、α（连杆扭转角）、d（关节偏距）、θ（关节角）。旋转关节 θ 为变量，移动关节 d 为变量。

**标准型 DH 变换顺序**：绕 z 转 θ → 沿 z 平移 d → 沿 x 平移 a → 绕 x 转 α：

```text
Tᵢ = Rot_z(θᵢ)·Trans_z(dᵢ)·Trans_x(aᵢ)·Rot_x(αᵢ)
```

⚠️ 易错：标准型与改进型（Modified DH）的差异在于 a/α 在**前置还是后置坐标系**上——标准型建系时 zᵢ 轴放在关节 i+1 上，改进型 zᵢ 轴放在关节 i 上；α、a 的位置在两版公式中交换。答题时明确用的是哪一版。

**正运动学**：已知关节角求末端位姿，T = T₁·T₂·⋯·Tₙ（齐次矩阵连乘），解唯一。

**运动学分析四步**（简答题标准答案）：① 建立坐标系 → ② 确定连杆参数 → ③ 写出各齐次变换矩阵 → ④ 写出运动学方程。

## 5. 逆运动学

已知末端位姿求关节角。核心考点是**多解性**与**解析解存在条件**：

- 平面二连杆逆解有两组（肘上/肘下），求解套路：两式平方相加消元用 arccos 求 θ₂，再用 atan2 求 θ₁；或余弦定理法
- ⚠️ 高频易错：**"三轴相交是逆运动学有解析解的充分条件" = 错误**。正确表述：6 自由度操作臂存在封闭解的充分条件是**相邻 3 个关节轴线相交于一点**（Pieper 准则，"连续三个 R"），且需存在正交关节轴或多个 αᵢ = 0 或 ±90°
- 解的存在性由工作空间决定；数值解（迭代法）通用但慢，解析解（封闭解）快且能枚举全部解

## 6. 雅可比矩阵与奇异

- 定义：关节速度到末端速度的线性映射 **ẋ = J(q)·q̇**
- 维度：行数 = 操作空间自由度 m，列数 = 关节数 N；**J 是时变的**（随构型 q 变）
- 几何雅可比 vs 分析雅可比：几何雅可比的速度分量是线速度 + 角速度（物理量）；分析雅可比的分量是姿态表示参数的导数（如欧拉角速率），两者通过 J_a = diag(I, B_a⁻¹)·J 联系（⚠️ 存疑：B_a 为 ω 与欧拉角速率之间的映射矩阵，出自课程笔记）

**奇异位形**（简答题标准答案）：使雅可比矩阵**不满秩**的位形——此时某些末端速度无法由任何关节速度实现，即**自由度减少、运动受限**。

- 无冗余（m = N）：判据 **det(J) = 0**，J 不可逆
- 冗余（m < N）：判据 rank(J) < m
- 两类奇异：**边界奇异**（臂完全展开/收回）与**内部奇异**（两个关节轴线共线）
- **可操作度**：κ = √det(J·Jᵀ)（= |det(J)| 当 J 为方阵），衡量位形离奇异位形的"距离"

**静力映射**（力域与速度域对偶）：τ = Jᵀ·F——末端笛卡尔力 F 到关节力矩 τ 的映射，**不需要逆运动学**；由虚功原理导出（Fᵀδx = τᵀδq，δx = Jδq）。注意方向与速度映射相反。

⚠️ 判断题记忆句：**"6 关节机器人中，速度域的奇异位形不一定是力域的奇异位形"** —— 对一般 6 关节臂，速度域奇异 ⇔ 力域奇异（均对应 J 奇异），该命题作为陷阱题出现时按具体语境作答（⚠️ 存疑：真题原题未给出标准答案，仅列出命题）。

## 7. 动力学基础

- **牛顿-欧拉法**：基于**力学**的方法（力/力矩平衡），递推高效，数值解标准
- **拉格朗日法**：基于**能量**的方法（动能-势能，L = K − P），解析表达式清晰
- 判断记忆句（真题反复考）：**"牛顿欧拉法是基于力学的方法，拉格朗日法是基于能量的方法" = 对**
- 标准形式：τ = H(q)q̈ + C(q,q̇)q̇ + G(q)，H 惯性矩阵、C 科氏力/离心力、G 重力项
- 逆动力学（τ 由轨迹算出）用于前馈控制；正动力学用于仿真

## 8. 轨迹规划

- **关节空间规划** vs **笛卡尔空间规划**：关节空间无奇异/无逆解问题、计算快，但末端路径形状不可控；笛卡尔空间路径可控但有奇异与逆解多解问题
- 常用曲线：三次多项式（给定初末位置速度）、五次多项式（还给定初末加速度）、梯形速度曲线（加减速+匀速段）
- 差速轮底盘常用圆弧/直线段拼接的路径规划

## 9. 差速移动机器人运动学

假设**纯滚动、无滑动**。两轮差速：

```text
v  = (v_L + v_R) / 2        —— 车体中心线速度（左右轮速度平均）
ω  = (v_R − v_L) / L        —— 车体角速度（右减左除以轮距 L）
```

- **同一轮速 → 直线**（ω=0）；**等大反向 → 原地旋转**（v=0）
- 位姿状态方程（高频填空/推导）：

```text
ẋ = v·cosθ,   ẏ = v·sinθ,   θ̇ = ω
```

- 瞬时转动中心（ICC）在轮轴延长线上；**原地旋转时 ICC 在两轮中心**
- 里程计：由轮速积分得 v、ω，再积分位姿；航向角必须先累加再投影到全局坐标
- ⚠️ 符号易错：ω = (v_R − v_L)/L 是**右减左**；若题目给 ω=(v₁−v₂)/d 形式，注意 v₁/v₂ 与左右轮的对应关系；半径 R = v/ω（ω=0 时为直线，半径无穷大）
- 轮距、轮半径记号的常见混用：公式统一记 L（轮距）、r（轮半径）

## 10. PID 控制

```text
u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt
```

| 项 | 作用 | 副作用 |
|----|------|--------|
| P | 按当前误差快速响应 | 过大则振荡 |
| I | 消除稳态误差（积累历史误差） | 过大则超调、积分饱和 |
| D | 按误差变化率抑制超调、阻尼 | 放大噪声 |

- **调参顺序**（简答标准答案）：先调 Kp（响应快且不振荡）→ 再调 Kd（抑制超调）→ 最后调 Ki（消除稳态误差，取小值）
- 位置式 PID（输出绝对控制量）vs 增量式 PID（输出增量 Δu，无积分饱和、切换冲击小，常用于电机控制）
- 差速车工程实践：左右轮各一套闭环 PID 控制轮速，上层再输出 v、ω

## 常见陷阱判断题

1. "旋转矩阵的转置仍是旋转矩阵" → **对**（R⁻¹=Rᵀ 且 det=1）
2. "串联关节机器人笛卡尔空间 6 维 ⇒ 关节空间 6 维" → **错**（关节数由机构决定，与笛卡尔空间维度无关）
3. "等效轴角是姿态的最小表示" → **错**
4. "三轴相交是逆解有解析解的充分条件" → **错**（相邻三轴相交）
5. "牛顿欧拉法基于力学、拉格朗日法基于能量" → **对**（考了多次）
6. "奇异位形处自由度减少、运动受限" → **对**（det(J)=0）
