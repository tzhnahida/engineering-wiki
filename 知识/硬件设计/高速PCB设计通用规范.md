# 高速PCB设计通用规范

> 从 TI、Infineon、Microchip 等厂商的 11 份设计指南和 Bogatin/Ott/Johnson 的 EMC 规则中提炼的**通用高速 PCB 设计规范**。不针对特定接口（DDR/PCIe/USB 有各自的专项页面），只覆盖跨接口通用的物理层规则。

## 1. 什么是"高速"

**判断标准不是频率，是上升沿。**

| 判断方法 | 公式 | 阈值 |
|----------|------|------|
| **Knee 频率** | f_knee = 0.5 / t_rise | 若走线长度 > λ/6，则需作为传输线处理 |
| **上升沿** | — | t_rise ≤ 1ns → 必须考虑阻抗控制 |
| **信号波长** | λ = c / (f × √εr) | 走线 > λ/10 → 传输线效应不可忽略 |

```
例: t_rise = 100ps (STM32H7 GPIO 的上升沿)
  f_knee = 0.5 / 100ps = 5 GHz
  λ (FR-4) = 150 mm/ns / 5 GHz = 30 mm
  走线 > 5mm → 必须按高速传输线处理
```

> [!warning] 即使 1 MHz 的方波，上升沿 100ps 就是高速信号。低频重复频率 ≠ 低速边沿。判断依据永远是 **rise time, not clock rate**。

## 2. 阻抗控制

### 2.1 常见接口阻抗

| 接口 | 差分阻抗 | 单端阻抗 | 容差 |
|------|----------|----------|------|
| USB 2.0 HS | 90 Ω | 45 Ω | ±10% |
| USB 3.x SS | 90 Ω | — | ±10% |
| PCIe | 85 Ω (Gen1-2) / 100 Ω (Gen3+) | — | ±10% |
| HDMI | 100 Ω | 50 Ω | ±10% |
| SATA/SAS | 100 Ω | — | ±10% |
| DDR4 DQ | — | 40/50 Ω | ±10% |
| DDR4 DQS/CK | 80-100 Ω | — | ±10% |
| Ethernet (1000Base-T) | 100 Ω | — | ±10% |
| MIPI D-PHY | 100 Ω | — | ±10% |

### 2.2 阻抗计算

线宽不是画出来的，是**从阻抗反推**的：

```
输入: 目标阻抗 Z₀, PCB 层厚 h, 铜厚 t, εr, 微带/带状线
输出: 线宽 W, 差分间距 S

关键: 用板厂的参数, 不用理论值
      JLC/华秋等有在线阻抗计算器——填叠层结构直接出线宽
```

| 结构 | 近似公式 (50Ω 微带) |
|------|---------------------|
| 微带线 (Microstrip) | W ≈ 2h (当 h 较薄时) |
| 带状线 (Stripline) | W ≈ 0.8h ~ 1.2h |
| 差分微带 | W/S 由差分阻抗和耦合系数决定 |

> 4 层板 1.6mm: Top→L2(GND) 间距 0.2mm → 50Ω 单端线宽 ≈ 14mil (取决于铜厚和 εr)

## 3. 差分对设计

### 3.1 黄金规则

| # | 规则 | 原因 |
|---|------|------|
| 1 | **等长** (±5 mil 典型) | 不等长 = skew = 共模噪声 |
| 2 | **等距** (恒定间距) | 间距不恒定 → 差分阻抗不均匀 |
| 3 | **同层同过孔数** | 不同层速度不同; 不同过孔数引入不同 delay |
| 4 | **连续参考平面** | 跨分割 → 阻抗突变 → 反射 |
| 5 | **避免 stub** (过孔 stub <10mil) | Stub = 并联电容 + 反射源 |

### 3.2 差分对耦合

```
间距 S 与线宽 W 的关系:
  S < 2W  → 紧耦合 — 差分阻抗主要由 S 决定
  S > 3W  → 松耦合 — 每根线约 2×Z₀ 的单端阻抗
  
高速差分对的 S 通常在 1W-2W 之间
```

### 3.3 差分对内 skew 的危害

```
差分信号: V_diff = V_P - V_N
当 P/N 有 Δt skew:
  → 转换时刻 V_P 和 V_N 不一致
  → V_CM = V_diff × Δt / (2 × T_rise)     (Ott Ch.19)
  
例: V_diff = 1V, Δt = 10ps, T_rise = 50ps
  V_CM = 1V × 10/100 = 100mV — 可观的共模噪声
```

### 3.4 差分对间距

| 信号 | 对内间距 | 对间间距 | 与其他信号 |
|------|----------|----------|-----------|
| USB 3.x SS | 紧耦合 | ≥4W | ≥5W |
| PCIe Gen3+ | 紧耦合 | ≥4W | ≥5W |
| HDMI | 紧耦合 | ≥3W | ≥4W |
| LVDS | 紧耦合 | ≥3W | ≥3W |

## 4. 参考平面

### 4.1 核心规则

**高速信号的回流路径紧贴信号线下方，在参考平面上流动。**

| # | 规则 | 违反后果 |
|---|------|----------|
| 1 | 高速信号必须有**连续参考平面** | 跨分割 → 回流绕路 → 环路面积增大 → EMI + 串扰 |
| 2 | 参考平面优先用 **GND**，不用 VCC | VCC 平面有纹波噪声 |
| 3 | **换层必须加回流过孔** | 换参考平面 → 回流路径断开 |
| 4 | 回流过孔距信号过孔 **≤ 50mil** | 远 > 50mil → 环路面积增大 |
| 5 | 高速信号不跨越**参考平面分割线** | 跨越 = 阻抗突变 → 反射 + 辐射 |

### 4.2 回流过孔

```
Top Layer 信号换到 L3:

  Top (信号) ──→[过孔]──
                     ↓
  L2 (GND)  ──→   [回流过孔] ←── 50mil 内至少有 1 个
  
  L3 (信号) ──→[过孔]──
  
不放过孔: 回流路径绕到最近的 GND 过孔
  → 回流环路面积暴增 → 电感增加
```

### 4.3 平面分割处理

若信号必须跨分割（比如在 PWR 平面上方走线）：

```
跨接电容 (Stitching Cap):
  分割线两端各放 0.1μF + 10nF 并联
  → 为高频回流提供低阻抗路径
  → 电容自谐振频率 > f_knee
```

## 5. 过孔设计

### 5.1 过孔的寄生效应

过孔不是理想导体——它引入：

| 效应 | 模型 | 影响 |
|------|------|------|
| 寄生电感 L_via | L ≈ 0.2 × h × [ln(4h/d) + 1] nH | 串联电感：减缓上升沿、增加阻抗 |
| 寄生电容 C_pad | C ≈ 1.31 × εr × D1 × t / (D2 − D1) pF | 对地电容：低通滤波效应 |
| Stub 谐振 | Stub = 开路线 → λ/4 短路谐振 | 特定频率能量被 trap |

### 5.2 Stub 管理

| 方案 | Stub 长度 | 成本 | DDR5/PCIe5 |
|------|-----------|------|------------|
| 背钻 (Back-drill) | ≤10 mil | +10-15% | ✅ 推荐 |
| 盲埋孔 (μVia) | 0 | +30-50% | ✅ 最优 |
| 信号走表层 | 0 | 叠层受限制 | ✅ |
| 不做处理 | 30-80 mil | 0 | ❌ 不可接受 |

> [!warning] 60mil stub → 5GHz 谐振点 (λ/4 ≈ 60mil) → PCIe Gen4/5 和 DDR5 Nyquist 频率在此附近 → **眼图闭合**

### 5.3 过孔阻抗优化

```
优化手段 (按重要性):
1. 背钻去除 stub (最有效)
2. 增加反焊盘直径 (减小过孔到平面的寄生电容)
3. 回流过孔 (提供回流路径)
4. 椭圆形反焊盘 (差分对过孔)
5. 过孔 staggered (错位排列，减少耦合)
```

## 6. 蛇形线

### 6.1 规则

| 参数 | DDR4-3200 | DDR5-5600 | 通用推荐 |
|------|-----------|-----------|----------|
| 蛇形线间距 | ≥5W | ≥7W | ≥5W |
| 拐角 | 圆弧 R≥3W | 圆弧 R≥3W | 避免 45°/90° 切角 |
| 幅度（绕线高度） | ≥3W | ≥3W | 太浅没有意义 |

> **蛇形线间距不够 → 相邻段耦合 → 信号实际传播快于物理长度 → 蛇形线的等长作用打折扣。** 间距 3W: 耦合 ~12-18%，延迟短 5-10%。间距 5W: 耦合 <5%，延迟短 <2%。

## 7. 串扰控制

### 7.1 3W 规则

差分对间距 ≥3× 介质厚度 (h) → 近端串扰 (NEXT) < 3%

```
微带线: 间距 ≥ 3W
带状线: 间距 ≥ 3h

例: 0.2mm 介质厚 → 差分对间距 ≥ 0.6mm
```

### 7.2 串扰类型

| 类型 | 来源 | 影响 |
|------|------|------|
| NEXT (近端) | 同层平行走线 | 耦合能量返回到源端 |
| FEXT (远端) | 同层平行走线 | 耦合能量传播到负载端 |
| 垂直串扰 | 相邻层信号 | 通过过孔和平面的耦合 |

### 7.3 间距推荐

| 场景 | 最小间距 |
|------|----------|
| 一般数字信号 | ≥3W |
| 时钟/敏感信号 | ≥5W |
| 高速差分对 vs 其他信号 | ≥5W |
| DDR 组间 | ≥5W |
| DDR CK/DQS vs 其他 | ≥5W (DDR4), ≥5W (DDR5) |
| 非关联信号 | ≥4W-5W |

## 8. EMC 设计规则

### 8.1 辐射机制

```
差模辐射: 信号-回流环路 = 环形天线
  E = K × f² × A × I / r    (Ott Ch.6)
  减小环路面积 A → 降低辐射 (A 减半 → -6dB)

共模辐射: 电缆/走线 = 单极天线
  E = K × f × L × I_CM / r   (Ott Ch.19)
  驱动源: 不完整的回流路径、不平衡的差分对
```

### 8.2 关键规则 (来自 kicad-happy EMC Rules)

| # | 规则 | 阈值 | 原理 (引用) |
|---|------|------|------------|
| GP-001 | 无地平面空洞 | 任何打断 GND 的 void | Hubing: #1 EMC 故障原因 |
| GP-002 | 无禁用层 | 无连续 GND 的布线层 | Ott Ch.16: GND 是最重要的 EMC 要素 |
| IO-001 | 连接器旁 EMC 滤波 | < 10mm | Ott Ch.19: 5µA CM 电流 = 46.4 dBµV/m @ 100MHz |
| CK-002 | 时钟线 ≤ 100mm | > 100mm 视为天线 | Johnson Ch.1 |
| SU-001 | 高速信号层紧邻 GND | 间距 0.1-0.2mm | Ott: 间距减半 → -6dB 辐射 |
| DC-001 | 去耦电容距 IC pin | < 50mil | Bogatin: 安装电感主导去耦效果 |
| BE-003 | 连接器旁过孔缝合 | λ/20 间距 | Ott Ch.16: 防止边缘辐射 |

### 8.3 EMI 滤波器布置

```
Connector → [TVS/ESD] → [共模扼流圈 (CMC)] → [RC 滤波] → IC

顺序: ESD 保护最靠近连接器 (先拦截 ESD)，CMC 次之，RC 最后
关键: CMC 到连接器的距离 < 10mm (防止这段走线成为共模天线)
```

## 9. PDN 设计

### 9.1 目标阻抗

```
Z_target = ΔV_allowed / ΔI_transient

例: 1.2V VDDQ, ΔV ≤ ±30mV, ΔI = 3A/ns
  → 实际要满足 30mV / 3A = 10mΩ @ 开关频率...但这个值在 MHz 以上越来越难
```

> Z_target 是频域概念，但**必须跑时域瞬态**——频域满足 ≠ 时域没问题。

### 9.2 去耦电容策略

| 频段 | 负责元件 | 典型值 |
|------|----------|--------|
| DC ~ 1 kHz | VRM (电压调节模块) | — |
| 1 kHz ~ 1 MHz | 大容量电容 (Bulk) | 10-100 µF |
| 1 MHz ~ 100 MHz | MLCC (片式多层) | 0.1-0.01 µF 并联 |
| > 100 MHz | PCB 平面电容 + 封装内置 | — |

> **0.1µF + 0.01µF 并联**不是玄学：小电容的自谐振频率更高，覆盖的频段不同。

### 9.3 安装电感是瓶颈

```
去耦电容的等效电路:
  R_ESR ── L_ESL ── C
         └─（器件自身寄生）─┘

实际瓶颈: 安装电感 L_mount
  L_mount = 过孔回路电感 + 走线电感 + 焊盘电感 ≈ 1-5 nH
  
即使 C 值选对，L_mount 太高→高频阻抗下不来→去耦失效
```

## 10. 叠层设计

### 10.1 4 层板 (标准)

```
L1: Signal (高速优先)      ← 参考 L2
L2: GND (完整)              ← 参考 L1, L3
L3: PWR + 低速信号           ← 参考 L2, L4
L4: Signal                  ← 参考 L3
```

核心：L1↔L2 紧耦合 (0.1-0.2mm)，高速信号在 L1 布线时可获最优信号质量。

### 10.2 6 层板 (DDR/PCIe)

```
L1: Signal (高速)           ← 参考 L2
L2: GND                     ← 参考 L1, L3
L3: Signal (高速, 可)       ← 参考 L2, L4
L4: PWR                     ← 参考 L3, L5
L5: GND                     ← 参考 L4, L6
L6: Signal                  ← 参考 L5
```

> 两个完整 GND 平面 (L2, L5) + 紧耦合 PWR↔GND = 天然平板去耦电容。

### 10.3 选材

| 应用 | 材料 | Df (损耗因子) | 适用频率 |
|------|------|-------------|----------|
| 低频/通用 | FR-4 (普通) | 0.02 | < 1 GHz |
| 中频 | FR-4 (低损耗) | 0.01-0.015 | < 3 GHz |
| 高频 | Megtron 6 / Rogers 4350B | 0.003-0.005 | < 10 GHz |
| 微波 | Rogers 5880 / Teflon | < 0.001 | > 10 GHz |

> PCIe Gen5 (16 GHz Nyquist) 和 DDR5-5600 → 普通 FR-4 的插损可能超标 → 考虑低损耗材料。
