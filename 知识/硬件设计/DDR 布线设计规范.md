# DDR 布线设计规范

> DDR 走线是 PCB 设计的最高难度科目之一。从 DDR3 的 T-branch 到 DDR4/DDR5 的 Fly-by，速率从 800 Mbps 到 5600+ Mbps，时序裕量从几百 ps 压到几十 ps。本页覆盖 DDR4/DDR5 布线的全部关键约束，包含 6 个最常踩的陷阱和 JEDEC 规范速查表。

## 速查：6 大陷阱

| # | 陷阱 | 影响等级 | 核心指标 |
|---|------|----------|----------|
| 1 | Fly-by 分支不对称 | **致命** | 分支差 ≤±5mil, 总长 ≤120mil |
| 2 | 蛇形线间距太密 | **致命** | DDR5 ≥5W, DDR5-5600 ≥7W |
| 3 | 只做组内等长，忽略组间 | **致命** | DQS↔CLK ±10mil (DDR5-5600) |
| 4 | 参考平面不连续 | **严重** | 换层加回流过孔 (50mil内) |
| 5 | DDR5 不用背钻 | **严重** | stub ≤10mil, 否则插损 1.5-5dB |
| 6 | 解耦电容摆位不当 | **严重** | 距 DRAM pin <50mil, 过孔放焊盘内侧 |

## 1. Fly-by 拓扑

DDR4 开始，地址/命令/时钟 (A/Cmd/CLK) 总线**强制使用 Fly-by**。T-branch（DDR3 风格）不再适用。

### 1.1 为什么必须 Fly-by

```mermaid
flowchart LR
    Ctrl["控制器"] --> D0["DRAM 0"] --> D1["DRAM 1"] --> D2["DRAM 2"] --> D3["DRAM 3"] --> Rterm["VTT 终端"]
```

- 时钟从控制器出发，一路穿过每片 DRAM，最后到终端电阻
- 每片 DRAM 接收到的时钟边沿有固定时间差——**最后一片和第一片的 CLK 差可达几百 ps**
- 这个延迟差靠 **Write Leveling** 补偿——但补偿范围有限

### 1.2 定量约束

| 参数 | DDR4-3200 | DDR5-4800 | DDR5-5600 |
|------|-----------|-----------|-----------|
| CLK 周期 (tCK) | 625 ps | 417 ps | 357 ps |
| UI (数据速率倒数) | 312.5 ps | 208.3 ps | 178.6 ps |
| Write Leveling 补偿范围 | ~0.6 tCK | ~0.6 tCK | ~0.6 tCK |
| **允许最大 Fly-by 延迟差** | ≤ 375 ps | ≤ 250 ps | **≤ 214 ps** |
| **建议 Fly-by 总延迟** | < 300 ps | < 200 ps | **< 170 ps** |

> [!warning] DDR5-5600 的 Fly-by 总延迟允许不到 1.4 inch (FR-4 微带线 ~150ps/inch)。如果 Fly-by 路径超过这个值，Write Leveling 就调不过来了。

### 1.3 分支规则

| 规则 | 值 | 原因 |
|------|-----|------|
| 各 DRAM 分支等长 | **±5 mil** | 反射对称，Write Leveling 线性假定 |
| 分支总长 | **≤ 120 mil** | 越短反射越小 |
| DRAM 间距 | **均匀** | 保持延迟步长恒定 |
| 终端电阻 (A/Cmd/CLK) | 39-60 Ω (VTT 上拉) | 匹配特征阻抗 |

> [!note] 最后一个 DRAM 和第一个 DRAM 接收到的时钟边沿有时间差。DDR5-5600 下，8 片 DRAM 串联、每片间距 50ps → 总延迟差 350ps → 超过半个周期。**必须做后仿**：提取 Fly-by 路径 S 参数，DDR5-5600 要求在 3GHz 处插损不低于 -3dB。

## 2. 蛇形线间距与耦合

### 2.1 核心问题

蛇形线相邻平行段之间存在**电磁耦合**——间距越近，耦合越强，信号实际传播速度变快。等效结果：**实际电延迟比物理长度对应的延迟短**。

### 2.2 间距与延迟损失

| 蛇形线间距 | 耦合系数 | 实际延迟 vs 物理长度 | 适用场景 |
|-----------|----------|---------------------|----------|
| 1.5W (太密) | 0.35-0.45 | **短 15-25%** | ❌ 不适合 DDR |
| 3W (临界) | 0.12-0.18 | 短 5-10% | DDR4-2400 以下勉强 |
| 5W (推荐) | <0.05 | **短 <2%** | DDR4-3200 / DDR5 |
| 7W (保守) | <0.02 | 可忽略 | DDR5-5600+ |

> W = 蛇形线自身的线宽。

### 2.3 拐角规则

- **拐角用圆弧过渡 (R ≥ 3W)**——不要用 45° 切角
- 直角或 45° 切角导致拐角处阻抗局部突变 5-8Ω——DDR5-5600 下每个拐角可能吃掉几个 ps 时序裕量
- 蛇形线幅度（绕线高度）≥ 3W——否则绕线没有意义

| 标准 | 蛇形线间距 | 拐角 |
|------|-----------|------|
| DDR4-3200 | ≥ 5W | 圆弧 R ≥ 3W |
| DDR5-4800 | ≥ 5W | 圆弧 R ≥ 3W |
| DDR5-5600+ | **≥ 7W** | 圆弧 R ≥ 3W |

## 3. 等长匹配

### 3.1 四组必配

| 匹配组 | DDR4-3200 | DDR5-4800 | DDR5-5600 |
|--------|-----------|-----------|-----------|
| DQ[x] ↔ DQS (组内) | ±10 mil | ±5 mil | **±3 mil** |
| DQS ↔ CLK (组间) | ±25 mil | ±15 mil | **±10 mil** |
| A/Cmd ↔ CLK | ±50 mil | ±30 mil | **±20 mil** |
| 不同 Byte Lane 的 DQS 之间 | ±50 mil | ±25 mil | ±15 mil |

### 3.2 最易遗漏的匹配

- **DQS 和 CLK 之间的 skew**——DQS 的对齐基准是 CLK。DQS↔CLK skew 超范围 → Write Leveling 调不通
- **A/Cmd 相对 CLK 的延迟**——DDR4-3200 的 tIS (输入建立时间) 仅 **50ps**，DDR5-4800 仅 **35ps**
- **DDR5 WCK (Write Clock)**——Gear 2 模式下 WCK 频率是 CLK 的两倍 (4.8GHz)，周期 208ps。**WCK 差分对内 P/N 长度差控制在 ±2mil**

### 3.3 JEDEC 通用约束

| 参数 | 规范值 |
|------|--------|
| 总信号长度 (CLK/A/Cmd) | ≤ 2.5 inch |
| 总信号长度 (Data) | ≤ 2.2 inch |
| CK 差分对内 | ±1 mil |
| DQS 差分对内 (DDR5) | ±1 mil (typ) |
| 同组线同层 | 必须同一 PCB 层 |
| 过孔数差异 (组内) | ≤ 1 |
| 速度补偿 | 微带长度 × 0.9 = 等效带状线长度 |

## 4. 阻抗控制

| 信号 | 典型阻抗 | 容差 |
|------|----------|------|
| DQ (单端) | 40 Ω 或 50 Ω | ±10% (DDR4), ±5% (DDR5) |
| DQS (差分) | 80-100 Ω | ±10% |
| CK (差分) | 76-100 Ω | ±10% |
| A/Cmd/CTRL (单端) | 40 Ω | ±10% |

> DDR5 推荐使用**嵌入式微带**结构，将阻抗变化控制在 ±2% 以内。

## 5. 参考平面与回流路径

### 5.1 换层规则

- **换层必须加回流过孔**——换层点 50mil 内放 ≥1 个 GND 过孔
- DDR 走线层尽量只参考**一个连续 GND 平面**——不要靠电源平面当回流路径
- 若必须跨分割：跨接位置两端各放 **stitching 电容 (0.1μF + 10nF 并联)**

### 5.2 间距与隔离

| 规则 | 值 |
|------|-----|
| 组内间距 | ≥ 3W |
| 组间间距 | ≥ 5W (25 mil typ) |
| CK/DQS 到其他信号 (DDR4) | ≥ 3W |
| CK/DQS 到其他信号 (DDR5) | ≥ 5W |
| 到非 DDR 信号 | ≥ 4W-5W |
| DDR 区域 keep-out | 40 mil |

### 5.3 仿真要求

DDR5 时代 **2.5D 求解器精度不够**——过孔和平面分割效应必须用 3D 全波提取 (HFSS/SIwave)：

- TDR 静态阻抗测试带宽不够会漏掉局部反射
- DDR5-5600 信号上升沿 ~25ps，对应带宽 ~14GHz——这个不连续点会被激励出来
- 投板前至少对 Fly-by 路径和几根代表性数据线做 3D 仿真

## 6. 过孔 Stub 与背钻

### 6.1 DDR4 vs DDR5 的差异

| 参数 | DDR4-3200 | DDR5-5600 |
|------|-----------|-----------|
| Nyquist 频率 | 1.6 GHz | 2.8 GHz |
| 信号能量延伸 | 1-3 GHz | 8-10 GHz |
| Stub 容忍度 | 40-60 mil 可接受 | **>25 mil 开始有明显影响** |

### 6.2 Stub 长度与插损

| Stub 长度 | 等效并联电容 | 5GHz 额外插损 | 对 DDR5 影响 |
|-----------|-------------|--------------|-------------|
| 10 mil | ~20-30 fF | **<0.3 dB** | ✅ 基本无影响 |
| 25 mil | ~50-75 fF | ~0.5-1 dB | 🟡 DDR5-4800 以下可接受 |
| 40 mil | ~80-120 fF | **~1.5-3 dB** | ❌ DDR5-5600 裕量被吃掉 |
| 60 mil | ~120-180 fF | ~3-5 dB | ❌ 眼图明显闭合 |
| 80 mil | ~160-240 fF | ~5-8 dB | ❌ 眼图可能打不开 |

> [!warning] 6 层板：信号走 L1/L3，过孔通到 L6，stub = L3→L6 ≈ 30-40mil → 贡献 1.5-3dB 额外插损。

### 6.3 解决方案

| 方案 | 效果 | 成本 |
|------|------|------|
| **背钻** (推荐) | 留 ≤10mil stub | +10-15% |
| **盲埋孔** (L1→L3 激光) | 零 stub | +30-50% |
| **靠底层引出** (L1/L6 走线) | 零 stub | 叠层设计受限 |

## 7. 电源完整性 (PDN)

### 7.1 解耦电容的核心问题

**不在电容值，在寄生电感。** 安装电感（过孔+走线+焊盘的回路电感，通常 2-5nH）是 ESL 的 5-10 倍。

| 做法 | 环路电感 | 效果 |
|------|----------|------|
| 电容离 DRAM pin 200mil+，通过细线引出 | 6-10 nH | ❌ 高频完全失效 |
| 电容放 DRAM 背面，两个通孔连到电源/地 pin | 2-4 nH | 🟡 勉强能用 |
| 电容紧贴 DRAM pin (<50mil)，过孔紧贴焊盘 | **0.5-1.5 nH** | ✅ 最佳 |

> DDR5 VDDQ 瞬态 di/dt = 2-5 A/ns。V = L × di/dt = 5nH × 3A/ns = **15mV** (单回路)。多 DRAM 同时翻转叠加可达 50-80mV，远超 DDR5 ±30mV 范围。

### 7.2 实操规范

| # | 规范 | 参数 |
|---|------|------|
| 1 | 每个 VDDQ pin 旁放 | 0.1μF + 0.01μF 并联 (覆盖更宽频段) |
| 2 | 电容距 DRAM pin | **< 50 mil** |
| 3 | 过孔位置 | 放在焊盘**内侧**（每加 1mm 走线 ≈ +1nH 电感） |
| 4 | 每个 DRAM 配大电容 | 10-22μF，200mil 内 |
| 5 | 仿真 | **必须跑时域瞬态**——频域 Z-target 满足 ≠ 时域没问题 |

|------|-----|

| DQ 阻抗 | 40/50 Ω ±10% |

| DQ↔DQS 等长 | ±10 mil |
| DQS↔CLK 等长 | ±25 mil |
| Fly-by 分支等长 | ±5 mil, ≤120 mil |

| 参数 | 值 |

| 拓扑 | Fly-by (A/Cmd/CLK), 点对点 (DQ/DQS) |
| DQ 阻抗 | 40/50 Ω ±5% |

| DQ↔DQS 等长 | **±3 mil** |
