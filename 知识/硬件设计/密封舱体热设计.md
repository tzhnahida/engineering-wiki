# 密封舱体热设计

密封舱体（水下/防爆/防尘）的热设计与开式机箱有本质区别：热量只能通过舱壁传出，舱内静止空气膜成为绝对瓶颈。本页给出一套热阻网络 + 双时间常数的工程计算法，公式均来自传热学基础（自然对流 Nu 关联式、Stefan-Boltzmann 辐射、集总热容法）。

## 1. 热阻网络模型

任何密封舱可分解为三段串联热阻：

```
热源 P → [舱内空气膜 R_i] → [舱壁 R_wall] → [环境 R_ext] → 环境温度 T_∞
```

| 环节 | 公式 | 典型值 |
|------|------|--------|
| 舱内空气膜 | R_i = 1/(h_i × A_i)，h_i = h_conv + h_rad | 空气自然对流 h≈5-8，内部辐射 h_rad = 4εσT³≈3-5 → h_i ≈ 9-12 W/m²K |
| 舱壁导热 | R_wall = t/(k × A) | 316L k=16，t=5mm，A=0.07m² → 0.005 K/W（几乎永远可忽略） |
| 环境侧 | R_ext = 1/(h_ext × A_ext) | 空气自然对流 h≈8-12（含辐射）；静水 h≈300-500；流水 >1000；强制风冷 25-100 |

**通用结论一：舱内空气膜占 90%+ 总热阻。** 壁材（钢/铝/钛）和壁厚在工程范围内几乎不影响结果——热量卡在"器件 → 内壁"的空气间隙里。舱壁温度 ≈ 环境温度。

**通用结论二：环境侧只在空气环境才重要。** 水下 R_ext 比 R_i 小两个数量级，水温水速怎么变都无所谓；空气中 R_ext 与 R_i 同量级，且辐射贡献约 1/3。

## 2. 稳态温升

```
ΔT_ss = P × ΣR = P × (R_i + R_wall + R_ext)
```

| 环境 | h_ext | R_ext (A=0.07m²) | ΣR | 每瓦温升 |
|------|-------|------------------|-----|----------|
| 静水 | 400 | 0.036 | ≈1.4 K/W | **1.4 °C/W** |
| 空气自然对流 | 9（含辐射） | 1.6 | ≈3.0 K/W | 3.0 °C/W |
| 空气 + 强迫风冷 | 50 | 0.29 | ≈1.7 K/W | 1.7 °C/W |

判断标准：舱内总功耗 P < ~15 W 且环境为水 → 平均温升 < 21°C，通常可行；空气环境 P > 10 W → 平均温升 > 30°C，需要专门散热设计。

## 3. 时间响应：双时间常数

舱体热系统是两级热容：舱内空气（热容极小）+ 舱壁（热容大）。

- **舱内空气**：τ_air = C_air × R_i ≈ 1-3 秒——秒级建立温升 P×R_i
- **舱壁**：τ_wall = C_wall × R_ext，C_wall = m×c = A×t×ρ×c

| 环境 | τ_wall（3.3kg 钢壳） | 达 95% 稳态 |
|------|---------------------|-------------|
| 水下 | ≈1 分钟 | **≈3-5 分钟** |
| 空气 | ≈1.5 小时 | ≈4.5 小时 |

```
T_air(t) ≈ T_∞ + P×R_i + P×R_ext × (1 − e^(−t/τ_wall))
```

**通用结论三：水下舱热稳定极快（分钟级）且不漂移**——水把舱壁锚定在水温上。空气舱则有一小时的慢漂移，短任务（<1h）根本到不了稳态，实际温升远小于稳态值，这是空气舱设计时容易被高估散热能力的地方（短时任务其实更安全）。

## 4. 组件级热阻：真正的杀手

舱内平均空气温度达标 ≠ 组件不烧。组件结温还要再叠一段"组件 → 舱内空气"的热阻：

```
T_junction = T_air + P × (R_jc + R_tim + R_heatsink)
```

- 舱内静止空气自然对流下，40mm 被动散热片 R ≈ 12-20 K/W：**6W 的 SoC 会高出空气 70-120°C，必死**
- 唯一正确解法：**高功率器件用导热垫/铝块/热管直接压到舱壁**。导热垫路径 R ≈ 0.5-2 K/W，结温 ≈ 环境温度 + P×R_path + 10°C 级余量
- 小功率器件（<1W）可靠板上自然散热，但结温余量需按 T_air 最热工况校核

**通用结论四：密封舱的散热策略是"传导到壁"，不是"对流到空气"。** 舱内空气只负责搬运残余热量（<15 W 量级）。

## 5. 材料参数速查

| 材料 | k (W/mK) | ρ (kg/m³) | c (J/kgK) | 备注 |
|------|----------|-----------|-----------|------|
| 316L 不锈钢 | 16 | 8000 | 500 | 壁热阻可忽略，但导热垫路径上不如铝 |
| 6061 铝 | 167 | 2700 | 900 | 导热块/散热片首选，比钢轻 3 倍 |
| 钛合金 | 7 | 4500 | 520 | 深海用，热阻仍可忽略（壁薄） |
| 空气（25°C） | 0.026 | 1.16 | 1005 | 舱内气隙 = 保温层 |

## 6. 算例：1.34 L 316L 矩形舱（水下）

参数：盒体 160×110×76 mm（A≈0.076 m²，壁厚 5 mm），静水 25°C，热源为 75W DC-DC（95%，损耗 3.9W）+ H723 MCU + RK3588 SoC。

- R_i = 1/(9.5×0.076) = 1.35 K/W（97%），R_wall = 0.004，R_ext = 0.033 → **ΣR = 1.39 K/W**
- 稳态：ΔT = 1.39×P → 满负荷 15W 时舱内 ≈ 46°C ✓；若 75W 负载全在舱内（78.9W）→ ΔT ≈ 110°C ✗
- 时间：τ_air ≈ 2 s、τ_wall ≈ 55 s，**3-5 分钟达稳态**
- 结论：水下热环境宽松，前提是 RK3588 导热垫直贴舱壁；H723 锁 VOS1（0.3W）即可（功耗数据见 [STM32H723VE](../../元件/MCU无线/STM32H723VE.md) 温升速查表）

## 7. 局限与验证

- h_i、h_ext 的取值有 ±50% 不确定度：舱内有隔板/支架会恶化对流，器件密集会增强局部辐射——初样必须做温箱+水温试验标定实际 ΣR
- 本模型是集总参数近似，忽略舱内温度分布：大功率器件与温度敏感器件（晶振、电池）应分开布置
- 公式基础为经典传热学（Incropera《传热学》自然对流与辐射章节），本页未另立来源页
