# PCB 设计标准流程

## 十三步概览

```
1.  需求规格          → 一页纸说清楚这板子干嘛
2.  方案设计          → 框图 + 芯片选型 + 电源树
3.  原理图设计        → 分页画 Schematic，跑 ERC
4.  仿真验证          → 关键电路在纸上验证——错在纸面免费
5.  元器件选型封装    → 每个符号对应真实可买到的物料（顺便查库存）
6.  PCB 布局          → 摆件 + 定连接器/散热/天线位置
7.  堆叠设计          → Layer Stackup + 阻抗计算 → 反推布线线宽
8.  PCB 布线          → 阻抗优先 → 时钟 → 模拟 → 大电流 → 数字
9.  SI/PI 分析        → 信号质量 + 电源质量——布线之后立即验证
10. DFM 检查          → 可制造性——板厂做不做得出来
11. 设计审查          → 给别人看，自己看不出自己的错
12. 出制造文件        → Gerber + BOM + 装配图 + 钢网
13. 回板调试          → 测短路 → 量电压 → 焊MCU → 逐个外设
```

每一步有硬门槛：上一步的输出不完整，下一步不能开始。

---

## 1. 需求规格

**不画图。只写字。** 如果这一页填不清楚，别往下走——芯片选型没有依据。

必须明确：

| 项目 | 示例 |
|------|------|
| 输入电压范围 | 5V USB-C PD / 12-24V 电池 |
| 输出电压 + 电流 | 3.3V 1A + 5V 2A |
| MCU | STM32F407VET6（Cortex-M4 / 168MHz / 512KB Flash） |
| 外设清单 + 协议 | IMU (I2C)、OLED (SPI)、MicroSD (SDIO) |
| 通信接口 | USB-C ×1、CAN ×1、UART ×2 |
| 尺寸约束 | ≤ 50×40mm、四角 M2 安装孔、板厚 1.6mm |
| 层数约束 | 2 层（成本）/ 4 层（信号质量） |
| 特殊要求 | 电池供电 → 低功耗设计；电机驱动 → 功率地和信号地隔离 |

---

## 2. 方案设计

**画框图，不是原理图。** 确定信号流和芯片间关系：

```
电池 → BMS → 降压DCDC(5V) → LDO(3.3V) → MCU
         │                      ↓
         └→ 电机驱动(12V)    I2C  SPI  UART
                             IMU OLED ESP32
```

明确：
- **电源树**：每一级电压、电流需求、DCDC 还是 LDO
- **信号流**：芯片间协议、主从关系、速率
- **电平匹配**：3.3V ↔ 5V 的接口需要电平转换
- **关键约束**：天线位置、高速信号路径、模拟信号隔离

**跳过这步直接画原理图 = 画到一半发现供电架构错了。**

---

## 3. 原理图设计

分页准则——每页一个子系统，跨页用 off-page connector：

```
Sheet 1: 电源树
Sheet 2: MCU 核心（MCU + 晶振 + 复位 + SWD + BOOT）
Sheet 3: 外设（传感器 / 存储 / 显示）
Sheet 4: 通信（USB / CAN / UART / WiFi）
Sheet 5: 功率输出（电机驱动 / LED 驱动）
```

原理图规则：
- 信号流向：左进右出、高压上低压下
- 去耦电容 100nF 贴着 IC 电源引脚画，每引脚一个
- 未用引脚标记 NC，不要悬空不标
- 测试点留焊盘：关键电源轨、UART TX/RX
- **画完跑 ERC。ERC 不通禁止进入下一步。**
- 选料时顺手在 JLC/立创查库存——不用等独立"BOM 评审"，发现没货当场换

---

## 4. 仿真验证

**在纸面上改电路，成本为零。**

### 必须仿真的电路

| 电路类型 | 仿什么 | 工具 |
|---------|--------|------|
| DC-DC 电源 | 环路稳定性（Bode）、负载瞬态、纹波、启动过冲 | LTspice / PSpice / TINA-TI |
| 运放/模拟前端 | 增益、带宽、噪声、共模范围 | LTspice / PSpice |
| 滤波器（LPF/BPF） | 频率响应、相位 | LTspice / Filter Designer |
| 电机驱动 | 开关损耗、死区时间、电流尖峰 | LTspice |

### DC-DC 仿真四步法

```
1. 稳态     → 输出电压对不对、纹波多大
2. AC 小信号 → Bode 图看相位裕度（>45° = 稳定）
3. 负载瞬态 → 电流从 10% 跳到 90%，看电压掉多少、恢复多久
4. 启动     → 上电瞬间有没有过冲
```

**四步全过，电源方案才叫验证完成。** 只跑稳态看不出环路振荡，上电过冲能烧芯片。

> [!note] 相位裕度判据
> ">45° = 稳定"是工程习惯下限（典型设计目标 45°–60°）。⚠️ 存疑：此判据无入库来源，属控制理论通识，需人工复核后才可当作硬门槛。

### 不需要仿真的

MCU + GPIO 点灯、SPI/I2C/UART 低速通信——时序不苛刻，仿真无意义。

### 工具整合

OrCAD Capture 自带 PSpice——同一套原理图导出网表给 PCB Layout，也能直接跑仿真。前提：元器件有 PSpice 模型。TI/ADI/ST 原厂基本都有；国产芯片大概率没有——没模型就依赖原厂参考设计。

---

## 5. 元器件选型与封装确认

原理图里的每个符号必须对应真实物料。几个问题收不住不能进布局：

| 检查 | 问自己 |
|------|--------|
| 封装 | 手焊还是机贴？0402 手焊 = 折磨 |
| 库存 | JLC/立创有现货？停产料别选 |
| 替代 | pin-to-pin 替代有吗？独家供应 = 风险 |
| 封装库 | CIS 里有这个封装吗？没有 → 在这一步画完 |

封装缺失在这一步解决，不要拖到布局阶段才发现封装不存在。

---

## 6. PCB 布局

**布局定了 PCB 质量的 80%。**

先定不能动的：
1. 连接器位置（外壳决定）
2. 安装孔
3. 天线位置（如有 RF，周围禁铺铜）
4. 发热器件（DCDC、电机驱动——散热路径）

再按信号流摆放：

```
电源入口 → 保护电路 → DCDC → LDO → MCU + 去耦电容
                                           ↓
                  功率区（远离 MCU）     信号区（靠近 MCU）
                  电机驱动               SPI / I2C 传感器
```

分区规则：
- 模拟区与数字区用地线隔开
- 大电流回路面积最小化
- 去耦电容贴着 IC 引脚放
- 晶振紧贴 MCU，底部禁走信号线，周围包地

> [!note] 关于"80%"
> "布局定了 PCB 质量的 80%"是编者经验判断，⚠️ 存疑：无入库来源，不构成可量化结论。

---

## 7. 堆叠设计

**布局之后、布线之前，定层叠结构和阻抗参数。** 这不是"选 4 层板"。

### 为什么要这步

布线线宽不是随便画的——由阻抗反推。USB 需要 90Ω 差分阻抗 → 根据层厚、介电常数、铜厚反算线宽和线距。**不先算阻抗，布线就是瞎画。**

### 4 层板标准层叠（1.6mm）

```
L1  Top     : 信号（高速优先放顶层）     1oz   (≈0.035mm)
    Prepreg : ≈0.21mm  (7628, FR-4)
L2  GND     : 完整地平面（禁止割裂！）    0.5oz (≈0.015mm)
    Core    : ≈1.065mm
L3  PWR     : 电源平面 + 少量信号        0.5oz (≈0.015mm)
    Prepreg : ≈0.21mm  (7628, FR-4)
L4  Bottom  : 信号                       1oz   (≈0.035mm)

合计 ≈ 1.59mm → 标称板厚 1.6mm（与第 1 节的尺寸约束一致）
```

> [!warning] 这张表是示意图，不是下单依据
> 叠层厚度由**板厂标准叠层**决定。上表这组数对应嘉立创 7628 叠层（外层 1oz / 内层 0.5oz / 芯板 ≈1.065mm / prepreg 7628 ≈0.21mm），合计 ≈1.59mm，标称 1.6mm。
> ⚠️ 存疑：不同板厂的叠层代码、芯板厚度、prepreg 型号都不同（嘉立创另有 3313 叠层，芯板 ≈1.265mm）。**实际厚度与铜厚必须以板厂阻抗计算器显示的叠层代码为准，本表不可直接下单。**

### 关键规则

- 高速信号的**参考平面必须是完整的 GND**，不能跨过割缝——跨了阻抗突变、反射回来
- 电源层与地层紧耦合（薄介质 = 大平板电容 = 天然去耦）
- **阻抗计算用板厂的参数**，不用理论值——JLC 有在线阻抗计算器，填板厚+叠层结构，直接给出线宽

### 输出

计算完成确认：USB 差分线宽 ×mil、间距 ×mil；单端 50Ω 线宽 ×mil。

**这步不完成，布线不能开始——线宽是算出来的，不是估出来的。**

---

## 8. PCB 布线

**严格按优先级布线（线宽已从堆叠设计确定）：**

```
1. 阻抗控制信号  → USB 差分 90Ω、MIPI 100Ω 等长等距
2. 时钟 / 晶振   → 最短、包地、不打过孔
3. 敏感模拟信号  → 远离数字区、完整地平面
4. 大电流走线    → 线宽按允许温升算，不要背固定值（见下方注）
5. 电源走线      → 星型拓扑，不形成环路
6. 其余数字信号  → 能连就行
```

> [!warning] 载流线宽必须带温升条件
> 走线载流能力取决于**允许温升 ΔT**——离开 ΔT 谈线宽没有意义，同一条线在 ΔT=10°C 与 30°C 下差 1.6 倍。
> 常见保守经验值（1oz 铜，ΔT=10°C，IPC-2221）：**外层 1mm ≈ 2.4A，内层 1mm ≈ 1.2A**（内层约为外层一半）。
> ⚠️ 存疑：IPC-2221 标准未入库，上值为按该标准公式计算所得，需人工核对。**设计时请用板厂载流计算器，并在项目文档里写明 ΔT 假设。**

完成后跑 DRC——**零错误才能继续。**

## 9. SI/PI 分析

布线之后、出 Gerber 之前，验证物理实现的信号质量和电源质量。

### SI（Signal Integrity）

| 检查项 | 工具 | 什么问题 |
|--------|------|---------|
| 阻抗匹配 | HyperLynx / ADS | 反射导致眼图闭合 |
| 串扰 | HyperLynx / ADS | 相邻走线互相干扰 |
| 眼图 | ADS / Sigrity | 高速信号实际可用的时序窗口 |
| 差分偏移 | HyperLynx | 差分对不等长 → 共模噪声 |

**低频板（<50MHz、无 USB/MIPI/DDR）可跳过 SI。**

### PI（Power Integrity）

| 检查项 | 工具 | 什么问题 |
|--------|------|---------|
| DC IR Drop | Sigrity / ADS | 铜皮压降——MCU 实际吃到的电压 |
| PDN 阻抗 | Sigrity / ADS | 电源平面谐振点——噪声放大 |
| 去耦效果 | Sigrity | 放的那些电容在工作频率上真起了作用吗 |

PI 最容易忽略的坑：DC-DC→MCU 走线太细 → 大电流压降 0.3V → MCU 供电实际 3.0V → 随机复位。

### 适用场景

| 板子类型 | SI | PI |
|---------|-----|-----|
| 2 层低速 | ❌ | ⚠️ 大电流跑 IR Drop |
| 4 层 + USB | ✅ 阻抗 + 眼图 | ✅ IR Drop + PDN |
| 6 层 + DDR/MIPI | ✅ 必须 | ✅ 必须 |
| 大电流（电机/BMS） | ❌ | ✅ IR Drop 必须 |

## 10. DFM 检查

**可制造性设计——板厂做不做得出来、良率多少。**

| 检查 | 不过会怎样 |
|------|-----------|
| 工艺边 / Mark 点 / 定位孔 | 贴片机对不准，拒收 |
| 器件方向统一（极性、pin1 朝向） | 贴反 → 报废 |
| 最小线宽/间距超出板厂工艺能力 | 短路或断路 |
| 拼板方式（V-Cut 还是邮票孔） | 分板时 MLCC 崩裂 |
| 测试点覆盖 | 板厂不测，短路板直接到你手里 |

**嘉立创 DFM / 华秋 DFM 在线工具**：Gerber 拖进去自动报错，免费。出 Gerber 之前跑一次，花 2 分钟省几百块返工。

---

## 11. 设计审查

**给别人看。** 自己看不出自己的错。

检查清单：
- 电源：所有 VCC/GND 都连了？去耦电容没少？
- 连接器：引脚定义和外壳方向一致？
- 丝印：正负极、pin1、方向、版本号都标了？
- 测试点：电源轨、GND、UART TX/RX 留了焊盘？
- 散热：发热芯片下面有铜皮？有散热过孔？
- 安装：孔径对得上螺丝？器件高度碰外壳？

## 12. 出制造文件

| 文件 | 内容 | 给谁 |
|------|------|------|
| Gerber | 铜皮 + 丝印 + 阻焊 + 钻孔 | PCB 板厂 |
| NC Drill | 钻孔坐标 | PCB 板厂 |
| BOM | 物料编号 + 封装 + 位号 + 用量 | 贴片厂/自己 |
| 装配图 | XY 坐标 + 角度 + 封装 | 贴片厂 |
| 钢网文件 | 焊膏开窗 | 钢网厂（机贴用） |

**Gerber 导出后用 Gerber Viewer 看一遍。** 不看 = 蒙着眼睛下单。

## 13. 回板调试

**绝不一次焊满。** 一次焊满上电冒烟，分不清焊接还是设计。

```
1. 空板量电源对地短路    → 蜂鸣档响了 = 短路，直接报废
2. 上电量各电压轨        → 逐一量，不对不往下走
3. 焊电源芯片 + MCU + 晶振 → SWD 连上、烧点灯程序
4. LED 亮了 = MCU 活了      → 核心验证通过
5. 逐个焊外设，焊一个调一个 → SPI OLED → I2C IMU → SD 卡
```

焊接问题优先查——至少 50% 的"设计问题"其实是虚焊。
⚠️ 存疑：上述"50%"为经验判断，无入库来源。

## 14. 高速数字设计专项（叠加在标准流程上）

以上 13 步是通用流程。当板子包含 **USB 2.0 HS、USB 3.x、MIPI、DDR3+、PCIe、HDMI、Ethernet** 时，每一步需要叠加高速专项规则。

> [!important] 本节只讲"嵌进哪一步"，不复制规则
> 规则本体在 [硬件设计/高速PCB设计通用规范](高速PCB设计通用规范.md)。本节**不再抄一份**——两处维护必然漂移，而且抄写过程会丢掉出处。
> 唯一的例外是**阻抗目标**（14.2）：它是第 7 步的输入，必须在这里定下来。

### 14.1 叠加在哪几步

| 步骤 | 高速专项动作 | 规则出处 |
|------|-------------|---------|
| 7 堆叠设计 | 由阻抗目标反推线宽/间距 | [硬件设计/高速PCB设计通用规范](高速PCB设计通用规范.md) §2 阻抗控制 · §10 叠层设计 |
| 8 PCB 布线 | 差分对（等长/等距/同过孔数/连续参考平面）· 蛇形线 · 串扰间距 | 同上 §3 差分对设计 · §6 蛇形线 · §7 串扰控制 |
| 9 SI/PI 分析 | 过孔 stub 管理 · PDN 目标阻抗 | 同上 §5 过孔设计 · §9 PDN 设计 |
| 11 设计审查 | 参考平面完整性 · EMC 规则 | 同上 §4 参考平面 · §8 EMC 设计规则 |

### 14.2 阻抗目标（第 7 步的输入）

| 接口 | 差分阻抗 | 容差范围 | 来源（页码） |
|------|----------|----------|-------------|
| USB 2.0 HS | 90 Ω | 81–99 Ω (±10%) | SPRAAR7J Table A-2, p.16 |
| USB 3.x SuperSpeed | 90 Ω | 83.7–96.3 Ω (±7%) | SPRAAR7J Table A-2, p.16 |
| HDMI TMDS | 100 Ω | 90–110 Ω (±10%) | SPRAAR7J Table A-2, p.16 |
| SATA | 100 Ω | 85–115 Ω (±15%) | SPRAAR7J Table A-2, p.16 |
| PCIe（TI 处理器 SoC） | 100 Ω | 90–110 Ω (±10%) | SPRAAR7J Table A-2, p.16 |
| PCIe（CEM 扩展卡） | 85 Ω | ±15%（Gen3/Gen4） | SNLA426 p.6, p.7, p.13 |
| MIPI D-PHY | 100 Ω | 单端 50 Ω | MIPI D-PHY 2.5, p.103 |

> [!warning] PCIe 有两套数字——先确认板子的角色，再选阻抗
> - 板子是**处理器 SoC 的载板**（AM57xx / DRA7xx / AM64x 等）→ 照 TI 器件设计指南：**100 Ω**（AM64x 为 95 Ω，±5%）
> - 板子是**插进主板槽的 CEM 扩展卡** → 照 PCI-SIG CEM 规范：**85 Ω**
>
> 两者差 15 Ω，画错直接抬高插损。
>
> ⚠️ **不要按 PCIe 代际切分阻抗**（例如"Gen1-2 取 85 / Gen3+ 取 100"）——库内两份来源都不支持这种切分：SNLA426 本身就是 Gen5 指南，仍明确写 85 Ω。

DDR 的阻抗不在本表——DDR 有专项页面 [硬件设计/DDR 布线设计规范](DDR%20布线设计规范.md) §4 阻抗控制。

### 14.3 什么时候可以不叠加

| 板子类型 | 叠加范围 |
|---------|---------|
| 2 层、无 USB HS / MIPI / DDR / PCIe | 不需要特殊叠加，走完 13 步即可 |
| 4 层 + USB 2.0 HS | 叠加差分对规则 + 阻抗控制 |
| 6 层 + DDR / MIPI / PCIe | 全量叠加（规范页 §3–§9） |

> TI 建议高速设计至少用 6 层（SPRAAR7J §3.12, p.14）。

## 流程铁律

1. **不跳步。** 需求没写完不画框图。框图没画不画原理图。ERC 没通不进布局。仿真没跑不进投板。堆叠没算不开始布线。
2. **验证在纸上，不在板上。** 仿真 + SI/PI 分析 + DFM 检查：三层验证把问题截在免费阶段。板子回来之前，每一关都过。
3. **DRC 零错误。** warning ≠ 无所谓。warning = "板厂可能正确执行、也可能猜错"——别赌。
4. **Gerber 必须看。** 导出后用 Gerber Viewer 确认一遍。

## 项目目录标准

每个 PCB 项目使用统一的工程目录结构。文档类内容用英文命名，遵循国际惯例。

```
project-name/
├── design/
│   ├── schematic/       # OrCAD project + auto PSpice files
│   └── allegro/         # Board file + Sigrity SI/PI workspace
├── manufacturing/       # Gerber + BOM + PnP + paste
├── firmware/            # MCU firmware (optional)
├── mechanical/          # 3D STEP + assembly drawings
├── docs/                # Full documentation, English, per-project
├── _LLM/                # CC workspace, .gitignored
├── README.md            # Overview + photo
├── log.md               # Design review records, append-only
├── CLAUDE.md            # PM CC rules: 13-step enforcement
└── LICENSE
```

规则：
- **`README.md`**：一页概览——什么人、什么板子、一个词描述、一张照片。不写技术细节
- **`docs/`**：完整文档——需求规格、方案架构、设计决策。全英文
- **`log.md`**：跟维基 log 同格式——`## [YYYY-MM-DD] type | Subject`，append-only
- **`_LLM/`**：CC 工作区，放截图/中间产物，`.gitignore` 排除
