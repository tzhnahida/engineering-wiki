# LVDS 差分信号基础

> LVDS (Low-Voltage Differential Signaling) 是最广泛使用的高速差分信号标准之一。它定义的不是协议，而是**物理层电气规范**——只要你符合 LVDS 的电平/摆率/共模范围，上层跑什么协议都行（FPD-Link、GMSL、MIPI D-PHY 的物理基础都源于 LVDS）。
>
> ⚠️ 来源说明：TIA/EIA-644 电气参数的标准原文未入库（⚠️ 存疑）；与 FPD-Link/GMSL 的关系部分引自对应数据手册来源页。

## 1. 电气规范

### 1.1 核心参数 (TIA/EIA-644)

| 参数 | 值 | 说明 |
|------|-----|------|
| 差分摆幅 V_OD | 250-450 mV | **低摆幅 = 低功耗 + 低 EMI** |
| 共模电压 V_CM | 1.125-1.375V (典型 1.25V) | 偏置在 VDD/2 |
| 直流耦合接收阈值 | ±100 mV | 最小可识别差分电压 |
| 数据率 | > 655 Mbps (标准), 可 > 3 Gbps | 取决于驱动器和线缆 |
| 驱动器输出电流 | 3.5 mA (标称) | 在 100Ω 终端上产生 350mV |

### 1.2 为什么低摆幅好

```
单端 3.3V CMOS: 轨到轨翻转 (3.3V) → di/dt 大 → EMI 大
LVDS: 350mV 翻转 → di/dt 小 → EMI 小 → 功耗低
  
同时: 差分信号 → 等幅反相 → 磁场抵消 → EMI 进一步降低
```

### 1.3 终端方案

```
Driver ────[100Ω 差分线]────┬──── Receiver
                            │
                           [100Ω]
                            │
                           GND (或 V_CM)

终端电阻 100Ω:
  - 匹配差分线特征阻抗
  - 必须在接收端（远端）——不在驱动端
  - 位置距离接收 pin < 5mm
```

## 2. 差分信号原理

### 2.1 为什么差分

```
共模噪声: 两根线受到的干扰相同 → V_P 和 V_N 同时被抬升/拉低
差分接收: V_diff = V_P - V_N → 共模干扰被减法消除
  
相比单端:
  - 单端: 信号 + GND → 噪声叠加在信号上
  - 差分: P + N → 噪声同时叠加 → 相减消除
```

### 2.2 共模抑制

| 频率 | 典型 CMRR | 说明 |
|------|-----------|------|
| DC | 60-80 dB | 静态偏置差异 |
| 1 MHz | 50-60 dB | 低频噪声 |
| 100 MHz | 30-40 dB | 高频时 P/N 路径不对称开始显现 |
| 1 GHz | 10-20 dB | 最高频率边界 |

> CMRR 下降的原因是：PCB 走线的不对称（P/N 长度差、过孔数不等、阻抗不均）→ 共模到差模转换。

## 3. 典型应用

### 3.1 纯 LVDS (TIA/EIA-644 兼容)

| 接口 | 说明 |
|------|------|
| **FPD-Link** (TI) | 基于 LVDS 的车载视频链路——单根 STP/同轴传输视频+控制 |
| **GMSL** (ADI/Maxim) | 类似 FPD-Link，同轴供电 (PoC) 支持 |
| **OpenLDI** | 笔记本内屏接口——LVDS 平行视频总线 |
| **Camera Link** | 工业相机接口——多路 LVDS 并行 |

### 3.2 LVDS 派生物理层

| 接口 | 与标准 LVDS 的关系 |
|------|-------------------|
| **MIPI D-PHY** | LVDS 的定制变体——更低摆幅 (200mV)、HS/LP 双模、源端终端 |
| **MIPI C-PHY** | 三线编码——非差分，但电气特性继承自 LVDS |
| **HDMI TMDS** | 电流模差分——源自 LVDS 概念，独立标准 |
| **USB 3.x** | 超高速差分——源自 LVDS 电流模驱动概念 |

## 4. 电路设计要点

### 4.1 终端位置

```
✅ 正确: 驱动端→传输线→终端电阻→接收器
                            ↑
                         紧贴接收 pin ✓

❌ 错误: 驱动端→终端电阻→传输线→接收器
         ↑
     终端在源端 ← 反射回接收器
```

### 4.2 AC 耦合

当发送端和接收端的共模电压不匹配时：

```
Driver ──[C_ac]───[100Ω 差分线]───[C_ac]──┬── Receiver
                                           │
                                         [100Ω]
                                           │
                                      V_CM (接收端偏置)
```

| 参数 | 推荐值 |
|------|--------|
| AC 耦合电容 | 100 nF (≤ 1 Gbps), 10 nF (> 1 Gbps) |
| 电容类型 | X7R 或 NPO，0402 封装 (低 ESL) |
| 放置位置 | 紧靠发送端（或两端各一个） |

### 4.3 共模扼流圈 (CMC)

```
Driver ──[CMC]───[差分线]─── Receiver

CMC 作用: 对共模信号呈高阻抗 (抑制共模噪声)
          对差模信号呈低阻抗 (信号畅通)
          
选型: 差模阻抗 < 5Ω, 共模阻抗 > 500Ω @ f_knee
```

> CMC 放在靠近连接器的一侧——抑制电缆辐射，而非 PCB 走线辐射。

## 5. PCB 布局要点

| 规则 | 值 | 原因 |
|------|-----|------|
| 差分对内等长 | ±5 mil | 不等长 → skew → 共模噪声 |
| 差分对间距 | 1-2W | 紧耦合抑制辐射 |
| 差分对 vs 其他 | ≥3W | 减少串扰 |
| 参考平面 | 连续 GND | 回流路径不中断 |
| 过孔数 | P/N 等量 | 引入相等寄生参数 |
| 终端电阻 | 接收 pin < 5mm | 减少 stub 反射 |

## 6. 信号质量验证

### 6.1 眼图

```
  ┌─────────────────────────┐
  │    ┌──────┐              │  ← 眼高 (vertical opening)
  │    │ Eye  │              │
  │    │      │              │
  │────┼──────┼──────        │  ← 限图模板 (eye mask)
  │    │      │              │
  │    └──────┘              │
  └─────────────────────────┘
     ←── 眼宽 (horizontal) ──→

LVDS 典型要求:
  眼高 > 200mV, 眼宽 > 0.5 UI
```

### 6.2 常见问题

| 症状 | 原因 | 检查 |
|------|------|------|
| 眼图闭合 | 终端不匹配 | 测量终端电阻 100Ω ±1% |
| 眼高不足 | 线缆过长或插损过大 | 缩短线缆或降低速率 |
| 共模噪声大 | P/N 不对称 | 检查等长、等过孔数、等层 |
| 低频抖动 | 电源噪声耦合 | 检查发送端 VDD 纹波 |
