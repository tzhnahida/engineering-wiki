# SlimeVR 骨骼模型与姿态解算

## 一句话

> 87 块骨骼的 FK 层级树 + 旋转复位/漂移校正/约束执行 → 11 个计算输出追踪点 → SteamVR。

## 骨骼层级

![[SlimeVR 骨骼层级.excalidraw]]

手臂从肩膀向下（正常模式）或从手向上（6-DOF 控制器模式，链反转）。

手指有 30 块骨骼（每只手 3 节 × 5 指），缺指尖时插值。

## 旋转校正管线

每个 Tracker 的原始四元数经过四级校正后才进入骨骼 FK：

Stages of rotation correction:
1. _rawRotation (UDP thread writes raw quaternion)
2. stayAligned.yawCorrection — yaw drift correction
3. resetsHandler.getAdjustedRotation():
   - mountRotFix: mounting orientation reset
   - gyroFix: gyro cumulative drift compensation
   - attachmentFix: strap offset compensation
   - yawResetFix: yaw reset
4. filteringHandler.getFilteredRotation() — optional smoothing/prediction
5. Bone.setRotation() — final rotation applied to skeleton

**复位类型速查：**

| 复位 | 触发方式 | 效果 |
|------|----------|------|
| **Full Reset** | 双击按钮 | 重置安装偏置 + 偏航原点 |
| **Yaw Reset** | 快速按钮 | 仅重置偏航原点（保留俯仰/横滚） |
| **Mounting Reset** | 更换身体位置时自动 | 重置安装矩阵 |

## 姿态更新管线 (skeleton.updatePose)

每帧执行，顺序严格：

### Step 1: Stay Aligned — 偏航漂移补偿

```kotlin
StayAligned.adjustNextTracker(trackerSkeleton, config)
```

检测 Tracker 偏航角缓慢漂移，施加微小 yaw 校正。参考加速度方向维持"下"的概念，限制漂移速率。

### Step 2: updateTransforms() — FK 装配

按层级递归：

FK assembly by region:
- Head: HEAD_TRACKER rotation → head bone; NECK_TRACKER rotation → neck bone (lower priority than head)
- Spine: First available from UPPER_CHEST / CHEST / WAIST / HIP tracker; extended mode interpolates missing segments
- Legs: UPPER_LEG tracker → thigh rotation (yaw borrowed from hip); LOWER_LEG tracker → calf rotation; FOOT tracker → foot rotation; extended knee mode: thigh/calf pitch+roll weighted average
- Arms: HAND tracker (6-DOF mode, reverse chain from hand to shoulder) or SHOULDER tracker + ELBOW tracker (normal chain); falls back to UPPER_CHEST rotation if no tracker available

每个 `Bone` 由 `headNode`（关节）和 `tailNode`（末端）两个 `TransformNode` 组成。`tailNode.localTranslation` 定义骨骼长度（沿 -Y），`rotationOffset` 补偿骨骼自然方向。

### Step 3: 约束执行

```kotlin
headBone.updateWithConstraints()
```

对每个关节施加旋转约束：

| 约束类型 | 自由度 | 典型关节 |
|----------|--------|----------|
| **Twist-Swing** | 3-DOF 限制 | 肩、髋 |
| **Hinge** | 1-DOF 铰链 | 膝、肘 |
| **Loose Hinge** | 1-DOF + 松弛 | 踝 |
| **Complete** | 3-DOF 自由 | 头 |

约束超出阈值 → 将修正量反馈回 Tracker 的 `resetsHandler.updateConstraintFix()`，让后续帧的原始旋转更合规。

### Step 4: IK 求解器 (CCDIK)

```kotlin
ikSolver.update(skeleton)
```

**Cyclic Coordinate Descent IK** — 支持 6-DOF 位置追踪器与 IMU 追踪器共存：

- 构建 IK 链：在分支点和位置约束处断开
- `backwardsCCDIK()`：从末端迭代向根，逐关节旋转调整
- 参数：最多 20 次迭代，容差 1e-8（0.01cm²）
- 阻尼 + 退火防止过调

### Step 5: 计算输出追踪点

```kotlin
updateComputedTrackers()
```

将骨骼世界变换复制到 11 个计算 Tracker：

Computed trackers:
- human://HEAD
- human://CHEST
- human://WAIST
- human://LEFT_KNEE, human://RIGHT_KNEE
- human://LEFT_FOOT, human://RIGHT_FOOT
- human://LEFT_ELBOW, human://RIGHT_ELBOW
- human://LEFT_HAND, human://RIGHT_HAND

这些 Tracker 经过速度估算（`updateDerivedVelocity()`）后输出到 SteamVR。

### Step 6: 腿部校正

→ 详见 [3. SlimeVR 腿部校正与地面交互](3.%20SlimeVR%20%E8%85%BF%E9%83%A8%E6%A0%A1%E6%AD%A3%E4%B8%8E%E5%9C%B0%E9%9D%A2%E4%BA%A4%E4%BA%92.md)

### Step 7: 自定位 (Localizer)

当没有 6-DOF 头显时，通过足部着地检测 + 质心速度估算实现身体自定位。支撑脚反向推算身体位移。

## 骨骼配置

`SkeletonConfigManager` 管理三类可调参数：

| 类别 | 示例 | 说明 |
|------|------|------|
| **Offsets** (长度) | headShift, neckLength, torsoLength, upperArmLength... | 身体比例，单位米 |
| **Toggles** (开关) | extendedSpine, skatingCorrection, floorClip, ikSolver... | 功能启用/禁用 |
| **Values** (权重) | waistFromChestHipAveraging=0.5, kneeLegsAveraging=0.6... | 扩展模型的加权系数 |
