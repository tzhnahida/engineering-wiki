# USB 3.0 信号完整性设计

## 一句话

**USB 3.0（5Gbps）跑不满速度，问题往往不在固件而在 PCB 布线。核心就三条：90Ω 阻抗、严格等长、ESD 紧贴接口。**

## 信号架构

USB 3.0 在保留 D+/D-（USB 2.0 向后兼容）基础上，额外加了两对 SuperSpeed 差分线：

| 信号对 | 方向 | 说明 |
|---|---|---|
| D+/D- | 半双工 | USB 2.0 兼容，最高 480Mbps |
| SSTX± | 发送 | SuperSpeed 发送 |
| SSRX± | 接收 | SuperSpeed 接收 |

一根线缆里 4 组差分信号同时工作，全双工通信。任何一组阻抗不匹配、长度不对等、或串扰，轻则速度降级，重则设备识别失败。

## 关键布线参数速查

| 参数 | USB 3.0 SuperSpeed | USB 2.0 |
|---|---|---|
| 差分阻抗 | **90Ω ±7%** | 90Ω ±15% |
| 单端阻抗 | 45Ω ±10% | 45Ω |
| 对内等长误差 | **±2mil（<15ps）** | ±5mil |
| 最大走线长度 | 建议 6 英寸 | 建议 10 英寸 |
| 过孔数量 | ≤2 个 | 尽量少 |
| TVS 结电容 | **<0.5pF** | <1pF |
| TVS 距接口 | ≤3mm | ≤5mm |
| 包地线间距 | ≥20mil | ≥20mil |

## 差分阻抗：90Ω 是底线

USB 3.0 信号上升沿 ~100ps，对应频率分量达 GHz 级别。差分阻抗偏离 90Ω → 信号在传输线上来回反射 → 眼图闭合 → 接收端解不出数据。

> [!warning] 反射严重性
> 若走线实际阻抗 80Ω（连接器端 90Ω），反射系数约 0.058，**6% 信号能量被反射**。多次叠加足以让眼图闭合。

### 影响差分阻抗的因素

| 因素 | 趋势 |
|---|---|
| 线宽 ↑ | 阻抗 ↓ |
| 线距 ↑ | 耦合 ↓，差分阻抗 ↑ |
| 介质厚度 ↑（离参考平面越远） | 阻抗 ↑ |
| 介电常数 Er ↑ | 阻抗 ↓ |
| 阻焊层覆盖 | 阻抗降低 5~10% |

> [!tip] 4 层板参考参数
> SIG-GND-PWR-SIG，Er=4.2，介质厚度 0.2mm，1oz 铜厚，差分线宽 4.5mil、线距 5mil → 约 90Ω。具体用 Polar Si9000 或嘉立创阻抗计算器验证。

## 地平面：不可忽视

USB 3.0 信号回流路径完全依赖地平面。地平面不完整 → 回流绕远路 → 地弹和串扰。

### 避坑清单

- 差分线下方**禁止跨分割**
- 包地线地过孔**每隔 200mil** 打一个
- 连接器外壳用 **≥4 个过孔**连到地平面
- 外壳地与信号地保持 **≥2mm** 间距

## 设计检查清单

- [ ] 差分阻抗 90Ω ±7%（已与板厂确认叠层参数）
- [ ] 对内等长 ±2mil 以内
- [ ] TVS 结电容 <0.5pF，距接口 ≤3mm
- [ ] 过孔 ≤2 个
- [ ] 走线长度 ≤6 英寸
- [ ] 地平面完整，无跨分割
- [ ] 包地线地过孔间隔 ≤200mil
- [ ] USB 2.0 和 SuperSpeed 信号之间隔离充分
