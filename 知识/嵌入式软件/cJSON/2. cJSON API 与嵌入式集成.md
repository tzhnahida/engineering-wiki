# 2. cJSON API 与嵌入式集成

## 解析 API

| 函数 | 说明 |
|------|------|
| `cJSON_Parse(value)` | 解析 null-terminated 字符串 |
| `cJSON_ParseWithLength(value, len)` | 解析指定长度的 buffer（不需要 null 终止） |
| `cJSON_ParseWithOpts(value, &end, require_null)` | 带选项，`end` 返回解析结束位置（线程安全） |
| `cJSON_ParseWithLengthOpts(value, len, &end, require_null)` | 组合版，所有其他解析函数最终调用此函数 |

## 渲染 API

| 函数 | 说明 |
|------|------|
| `cJSON_Print(item)` | 格式化输出，返回需 `cJSON_free` 的字符串 |
| `cJSON_PrintUnformatted(item)` | 紧凑输出，无空格换行 |
| `cJSON_PrintBuffered(item, prebuf, fmt)` | 带初始 buffer 大小提示，减少 realloc |
| `cJSON_PrintPreallocated(item, buf, len, fmt)` | **无堆渲染**：写入用户提供的固定 buffer，返回 1=成功 0=溢出 |

## 构造 API

```c
cJSON *root = cJSON_CreateObject();
cJSON_AddStringToObject(root, "name", "sensor");
cJSON_AddNumberToObject(root, "value", 42);
cJSON_AddItemToObject(root, "nested", cJSON_CreateObject());
```

`cJSON_CreateIntArray/FloatArray/DoubleArray/StringArray` 批量创建数组。

## 访问与遍历

```c
cJSON *val = cJSON_GetObjectItem(root, "key");          // 大小写不敏感
cJSON *val = cJSON_GetObjectItemCaseSensitive(root, "key"); // 大小写敏感
cJSON *elem = cJSON_GetArrayItem(array, index);           // O(n) 遍历

// 高效遍历（O(n) 而非 O(n²)）:
cJSON_ArrayForEach(elem, array) { /* ... */ }
```

## 关键操作

### 从 Object 中取出而不释放

```c
cJSON *item = cJSON_DetachItemFromObject(obj, "key");  // 取出
// ... 继续使用 item ...
cJSON_Delete(item);  // 手动释放
```

### 深度比较

```c
cJSON_Compare(a, b, false);  // 大小写不敏感；true = 大小写敏感
```

### 原地去除空白

```c
cJSON_Minify(json_str);  // 移除空格、换行、// 和 /* */ 注释
```

## 嵌入式集成模式

### 模式 1：解析网络 buffer（MQTT 负载）

```c
// UART/网络收到 JSON，已知长度
cJSON *json = cJSON_ParseWithLength(rx_buffer, rx_len);
if (json) {
    cJSON *cmd = cJSON_GetObjectItem(json, "command");
    // ...
    cJSON_Delete(json);
}
```

### 模式 2：无堆渲染（ISR 安全）

```c
char buf[256];
cJSON *root = cJSON_CreateObject();
cJSON_AddNumberToObject(root, "sensor", read_sensor());
if (cJSON_PrintPreallocated(root, buf, sizeof(buf), 0)) {
    uart_send(buf);
}
cJSON_Delete(root);
```

### 模式 3：配合 FreeRTOS 内存池

```c
// 使用 FreeRTOS heap_4 的 pvPortMalloc
cJSON_Hooks hooks = { .malloc_fn = pvPortMalloc, .free_fn = vPortFree };
cJSON_InitHooks(&hooks);
```
