# 1. cJSON 概述与数据模型

## 定位

cJSON 是 Dave Gamble 开发的 ANSI C (C89) JSON 解析/渲染库，仅两个文件，零外部依赖。设计哲学："最蠢但管用的 JSON 解析器"。

核心指标：

| 项目 | 值 |
|------|-----|
| 文件数 | 2 (`cJSON.h` + `cJSON.c`) |
| 总行数 | ~3500 |
| 编译后 | ~10-20KB |
| 依赖 | 仅 C 标准库 |
| 协议 | MIT |

## 数据模型

### cJSON 节点结构体

```c
typedef struct cJSON {
    struct cJSON *next;      // 兄弟节点链表
    struct cJSON *prev;      // 前驱（首节点的 prev 指向末尾，O(1) 追加）
    struct cJSON *child;     // 子节点（Array/Object）
    int type;                // 位掩码：类型 + 标志
    char *valuestring;       // String/Raw 的值
    int valueint;            // ⚠️ 已弃用，用 cJSON_SetNumberValue
    double valuedouble;      // Number 的值
    char *string;            // Object 成员的 key
} cJSON;
```

### 类型系统（位掩码设计）

类型是位掩码，低 8 位为基本类型，高位为标志：

| 类型 | 值 | 说明 |
|------|-----|------|
| `cJSON_Invalid` | 0 | 未初始化 |
| `cJSON_False` | 2 | 布尔假 |
| `cJSON_True` | 1 | 布尔真 |
| `cJSON_NULL` | 4 | 空值 |
| `cJSON_Number` | 8 | 数字（double + int） |
| `cJSON_String` | 16 | 字符串 |
| `cJSON_Array` | 32 | 数组 |
| `cJSON_Object` | 64 | 对象 |
| `cJSON_Raw` | 128 | 原始 JSON 字符串 |

| 标志 | 值 | 含义 |
|------|-----|------|
| `cJSON_IsReference` | 256 | `valuestring`/`child` 是借用引用，不释放 |
| `cJSON_StringIsConst` | 512 | key 指针指向常量，不释放 |

类型检查：`(item->type & 0xFF) == cJSON_Number`

### 链表结构

Object 和 Array 的成员通过 `child` 指针构成双向链表。关键优化：**首节点的 `prev` 指向末节点**，实现 O(1) 尾部追加（`cJSON_AddItemToArray`）。

## 内存模型

### 三种所有权模式

| 模式 | 创建 API | 释放行为 |
|------|---------|---------|
| **拥有**（默认） | `cJSON_CreateString`, `cJSON_Parse` | `cJSON_Delete` 递归释放全部 |
| **引用** | `cJSON_CreateStringReference` | 不释放 `valuestring` 和 `child` |
| **常量 key** | `cJSON_AddItemToObjectCS` | 不释放 key 指针 |

### 自定义分配器

```c
cJSON_Hooks hooks;
hooks.malloc_fn = my_malloc;
hooks.free_fn = my_free;
cJSON_InitHooks(&hooks);
```

与 FreeRTOS 堆分配器配合，避免标准库 `malloc` 碎片。

### 无堆渲染

`cJSON_PrintPreallocated(item, buffer, length, format)` 渲染到固定缓冲区，完全不需要堆。适合 ISR 或无堆环境。

## 解析流程

递归下降解析器，`parse_value()` 根据首字符分发：

| 首字符 | 分发到 |
|--------|--------|
| `"` | `parse_string()` |
| `0-9`、`-` | `parse_number()` |
| `[` | `parse_array()` |
| `{` | `parse_object()` |
| `t`/`f`/`n` | 字面量 true/false/null |

### 数字解析细节

1. 扫描所有合法字符（数字、`.`、`e`/`E`、`+`/`-`）
2. `strtod()` 转 double
3. `valueint` 为饱和截断：`(int)(valuedouble)`，溢出时截到 `INT_MAX`/`INT_MIN`

### 嵌套保护

`CJSON_NESTING_LIMIT`（默认 1000），解析时跟踪 depth 计数器，超过限制返回错误（防止栈溢出）。

## 错误处理

- 全局 `cJSON_GetErrorPtr()`（非线程安全）返回输入中错误位置指针
- 线程安全替代：`cJSON_ParseWithOpts` 的 `return_parse_end` 参数
- 所有类型检查函数接受 NULL（返回 false），不会崩溃

## 渲染精度

`print_number()` 先尝试 `%1.15g`，再用 `sscanf` 验证能否还原原始 double；失败则回退到 `%1.17g`（IEEE 754 double 精确往返所需的最小精度）。
