# 1. letter-shell 概述与命令系统

## 定位

letter-shell 是嵌入式串口命令行 shell，C99。通过 `SHELL_EXPORT_CMD` 宏将 C 函数自动注册为 shell 命令，支持 Tab 补全/历史/变量/认证/函数签名验证。

| 指标 | 值 |
|------|-----|
| 核心文件 | `shell.c` + `shell.h` + `shell_cfg.h` |
| 依赖 | 零（仅用户提供 read/write 回调） |
| 协议 | MIT |
| 版本 | 3.2.4 |

## 命令自动注册（链接器段魔法）

`SHELL_EXPORT_CMD(attr, name, func, desc)` 展开为一个全局常量，放入 `"shellCommand"` 链接器段：

```c
SHELL_USED const ShellCommand
shellCommand##name SHELL_SECTION("shellCommand") = {
    .attr.value = _attr,
    .data.cmd.name = "name",
    .data.cmd.function = (int (*)())func,
    .data.cmd.desc = "desc",
};
```

`shellInit()` 时通过工具链特定符号确定段边界：
- **GCC**：`_shell_command_start` / `_shell_command_end`（链接脚本符号）
- **Keil**：`shellCommand$$Base` / `shellCommand$$Limit`
- **IAR**：`__section_begin("shellCommand")` / `__section_end("shellCommand")`

**零初始化代码**——所有命令由链接器自动收集。

## 命令分发流程

```
shellTask() → shellHandler(char)
    ↓ 检测回车键
shellExec(buffer)
    ↓ 空格分割参数（支持引号）
shellSeekCommand() — 线性 strcmp 搜索命令表
    ↓
shellRunCommand() — 根据类型分发
    ├── CMD_MAIN → func(argc, argv)  (main 风格)
    ├── CMD_FUNC → 类型转换后 func(p1, p2, ...)  (func 风格)
    ├── VAR_* → 显示/修改变量值
    └── USER → 切换用户
```

## 命令类型

### Main 风格

```c
int my_cmd(int argc, char *argv[]) {
    shellPrint(shell, "argc=%d, argv[0]=%s\n", argc, argv[0]);
    return 0;
}
SHELL_EXPORT_CMD(SHELL_CMD_PERMISSION(0), my_cmd, my_cmd, "example command");
```

参数是字符串数组，类似 `main()`。

### Func 风格（带签名）

```c
int add(int a, int b) { return a + b; }
SHELL_EXPORT_CMD_SIGN(SHELL_CMD_PERMISSION(0), add, add, "add a b", "ii");
//                                                             类型签名: int, int
```

shell 自动将字符串参数转为对应类型后调用。支持类型：`i`(int), `s`(string), `f`(float), `d`(double), `[i]`(int 数组) 等。

### 代理命令

```c
SHELL_EXPORT_CMD_AGENCY(SHELL_CMD_TYPE(SHELL_TYPE_CMD_MAIN),
    sensor_read, sensor, "read sensor CH1", 1);
//  函数     代理名   描述          固定参数
```

预设参数，用户只需键入代理名。shell 自动拼接固定参数后调用函数。

## 输入处理

`shellHandler()` 每字符检测多字节转义序列：

| 按键 | 序列 | 行为 |
|------|------|------|
| Tab | `\t` | 命令补全 |
| ↑ | `\e[A` | 历史后退 |
| ↓ | `\e[B` | 历史前进 |
| ← | `\e[D` | 光标左移 |
| → | `\e[C` | 光标右移 |
| Backspace | `\b`/`\x7F` | 删除前一字符 |

## Tab 补全逻辑

1. 线性扫描命令表，前缀匹配
2. 单匹配 → 直接完成
3. 多匹配 → 显示所有候选 + 截断到最长公共前缀
4. 双击 Tab → 显示带描述的命令列表（类似 bash 的双击 Tab）

## 命令历史

循环缓冲区（默认 5 条，可配置）。历史条目与输入缓冲区共享连续内存，零动态分配。上下箭头导航。

## 变量导出

将 C 变量暴露为 shell 可读写：

```c
static int kp = 100;
SHELL_EXPORT_VAR(SHELL_CMD_PERMISSION(0), kp, kp, int, "PID Kp");
```

shell 中直接 `kp` 显示值，`kp 250` 修改值。支持 int/short/char/string/pointer/node（带 get/set 回调）。

**调试 PID 参数时不用重新烧固件**。

## 用户认证

```c
SHELL_EXPORT_USER(SHELL_CMD_PERMISSION(0), admin, "password123");
SHELL_EXPORT_USER(SHELL_CMD_PERMISSION(1), user, "userpass");
```

- 未认证时禁止执行命令
- 8 位权限掩码与命令权限位 AND 判断
- 可选空闲超时自动锁定（`SHELL_LOCK_TIMEOUT`）

## 集成步骤（STM32 + FreeRTOS）

```c
static Shell shell;
static char shellBuffer[512];

void userShellWrite(const char *data, unsigned short len) {
    HAL_UART_Transmit(&huart, (uint8_t*)data, len, 100);
}

void setup_shell() {
    shell.write = userShellWrite;
    shell.read = userShellRead;   // UART 接收函数
    shellInit(&shell, shellBuffer, 512);
    xTaskCreate(shellTask, "shell", 256, &shell, 5, NULL);
}
```
