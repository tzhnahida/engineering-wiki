# TinyUSB 概述与架构

## 定位

TinyUSB 是 hathach 开发的开源跨平台 USB 协议栈，同时支持设备模式（Device）和主机模式（Host）。设计目标是零动态内存分配、编译时可裁剪、适配从 Cortex-M0 到 Cortex-M7 的各类 MCU。

## 分层架构

```
┌─────────────────────────────────────────────────┐
│                应用层 (Application)              │
│   tud_cdc_write() / tuh_hid_receive_report()    │
├─────────────────────────────────────────────────┤
│              类驱动 (Class Drivers)              │
│   CDC / MSC / HID / DFU / Audio / MIDI / BTH   │
├─────────────────────────────────────────────────┤
│           设备/主机核心 (USBD / USBH)            │
│   设备状态机, 控制传输, 标准请求, 驱动注册        │
├─────────────────────────────────────────────────┤
│          操作系统抽象层 (OSAL)                   │
│   osal_none / osal_freertos / osal_rtthread     │
├─────────────────────────────────────────────────┤
│        设备/主机控制器驱动 (DCD / HCD)            │
│   STM32 / nRF / RP2040 / ESP32-S2/S3 / ...      │
├─────────────────────────────────────────────────┤
│                USB 硬件外设                      │
└─────────────────────────────────────────────────┘
```

## 设备栈 vs 主机栈

| 方面 | 设备模式 (Device) | 主机模式 (Host) |
|------|------------------|----------------|
| 启用宏 | `CFG_TUD_ENABLED=1` | `CFG_TUH_ENABLED=1` |
| API 前缀 | `tud_*` | `tuh_*` |
| 典型应用 | USB 键盘/U盘/串口 设备 | 读 U 盘/接键盘/接鼠标 |
| 关键文件 | `src/device/usbd.c` | `src/host/usbh.c` |

支持 OTG 的硬件上，两个栈可同时启用实现双角色。

## 核心设计原则

1. **无动态内存分配**：所有缓冲区和对象在编译时确定大小
2. **延迟中断模型**：ISR 只捕获事件入队，`tud_task()` 上下文处理
3. **编译时描述符**：`TUD_CONFIG_DESCRIPTOR` 宏在编译时拼装 USB 描述符 → ROM 中的字节数组 → 零运行时开销
4. **`usbd_class_driver_t` 统一接口**：所有类驱动通过同一个虚函数表注册

## 关键目录

| 路径 | 内容 |
|------|------|
| `src/device/usbd.c`, `usbd_control.c` | 设备核心 + 控制传输 |
| `src/host/usbh.c` | 主机核心 |
| `src/portable/<vendor>/<series>/dcd_*.c` | DCD 驱动 |
| `src/class/<class>/*_device.c` | 设备侧类驱动 |
| `src/class/<class>/*_host.c` | 主机侧类驱动 |
| `src/osal/osal_*.h` | OS 抽象 (FreeRTOS/RT-Thread/none) |
| `src/tusb.h` | 统一入口头文件 |

## 与 FreeRTOS 的集成

```c
#define CFG_TUSB_OS  OPT_OS_FREERTOS

// 专用 USB 任务
void usb_device_task(void* params) {
    while (1) {
        tud_task();  // 阻塞等待 USB 事件 → 处理
    }
}

// USB IRQ — 最少处理
void USB_IRQHandler(void) {
    dcd_int_handler(0);  // 捕获事件 → OSAL 队列 → 唤醒 tud_task
}
```

| TinyUSB OSAL | FreeRTOS |
|-------------|----------|
| `osal_semaphore_create` | `xSemaphoreCreateBinary` |
| `osal_semaphore_post` (ISR) | `xSemaphoreGiveFromISR` + `portYIELD_FROM_ISR` |
| `osal_mutex_create` | `xSemaphoreCreateMutex` |
| `osal_queue_send` | `xQueueSendToBack` |
