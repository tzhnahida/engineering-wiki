# 2. FlashDB TSDB 时序数据库

## 定位

TSDB（Time Series Database）是 FlashDB 的追加式时序日志模式。专门为"传感器定时采集数据，需要按时间范围查询"的场景设计。

## 双向布局

TSDB 扇区采用**双向增长**布局最大化空间利用：

```
扇区顶 ─────────────────────────────
  ↓ 索引区向下增长
[Sector Header] [TSL Idx 0] [TSL Idx 1] ...
                    ...     [TSL Data 1] [TSL Data 0]
                                                   ↑ 数据区向上增长
───────────────────────────── 扇区底
```

### TSL 索引结构

```c
struct log_idx_data {
    status_table;   // PRE_WRITE → WRITE → USER_STATUS1 → DELETED → USER_STATUS2
    time;           // 时间戳 (int32_t 或 int64_t)
    log_len;        // 日志长度（固定大小模式省略）
    log_addr;       // 数据地址（固定大小模式省略，改为计算）
};
```

### 扇区头

```
[status] [magic "TSL0"] [start_time] [end_info[0]] [end_info[1]] [reserved]
```

- **双 end_info** 提供冗余——一个写入不完整时另一个可能完好，保证掉电后能找到正确结束位置

## 追加写入

`fdb_tsl_append(db, blob)`:

1. 验证 blob 大小和时间戳单调性
2. 检查当前扇区空间：
   - 空间不足 → 写 end_info，标记 FULL，前进到下一扇区（环形，必要时格式化）
   - 扇区为 EMPTY → 标记 USING，写 start_time
3. 写 TSL：PRE_WRITE → time + data → WRITE（提交）

## 查询操作

### 遍历查询

```c
fdb_tsl_iter(db, callback, arg);          // 正向
fdb_tsl_iter_reverse(db, callback, arg);  // 反向
```

### 时间范围查询

```c
fdb_tsl_iter_by_time(db, from, to, callback, arg);
```

支持正向（from<to）和反向（from>to）。内部用**二分查找**定位起始 TSL（因为扇区内 TSL 按时间序排列）。

### 计数查询

```c
fdb_tsl_query_count(db, from, to, status);
```

只统计特定状态的 TSL（如已写入未处理、已处理等）。

## 固定大小模式

`FDB_TSDB_FIXED_BLOB_SIZE`：所有日志等长时启用。省略 `log_len` 和 `log_addr`（每 TSL 省 8 字节），数据地址由公式计算：

```
log_addr = sector_base + sec_size - (tsl_index + 1) * ALIGNED(blob_size)
```

适合固定结构的传感器数据（如 `struct {float ax, ay, az, temp;}` 每 10ms 一条）。

## TSL 生命周期管理

用户可修改 TSL 状态实现数据生命周期：

```
UNUSED → PRE_WRITE → WRITE → USER_STATUS1 → DELETED → USER_STATUS2
                                    ↑                      ↑
                               "已处理"标记          "已清除"标记
```

`fdb_tsl_set_status()` 改变单条 TSL 状态。用于"标记已上传到云端"这类场景。

## STM32 集成

需要 FAL 依赖：
1. 实现 `fal_flash_dev` 结构体（read/write/erase 回调）
2. 在 `fal_cfg.h` 中定义分区表
3. 设置锁回调（裸机用 `__disable_irq()`，RTOS 用信号量）
4. 配置 `FDB_WRITE_GRAN`（F1=32, F2/F4=8, F7=64）
