# 2. EasyLogger 移植与输出模式

## 移植接口（6 个函数）

```c
ElogErrCode elog_port_init(void);            // 一次性的输出硬件初始化
void elog_port_output(const char *log, size_t size); // 输出日志字节
void elog_port_output_lock(void);             // 获取互斥锁
void elog_port_output_unlock(void);           // 释放互斥锁
const char *elog_port_get_time(void);         // 返回时间字符串
const char *elog_port_get_p_info(void);       // 返回进程标识（可返回 ""）
const char *elog_port_get_t_info(void);       // 返回线程标识（可返回 ""）
```

以及异步模式的可选通知函数：

```c
void elog_async_output_notice(void);          // 通知消费线程有新日志
```

## 裸机移植（STM32 HAL）

```c
void elog_port_output(const char *log, size_t size) {
    printf("%.*s", size, log);                    // 重定向 printf → UART
}
void elog_port_output_lock(void)   { __disable_irq(); }
void elog_port_output_unlock(void) { __enable_irq(); }
const char *elog_port_get_time(void) {
    static char buf[16];
    RTC_TimeTypeDef t;
    HAL_RTC_GetTime(&hrtc, &t, RTC_FORMAT_BIN);
    snprintf(buf, sizeof(buf), "%02d:%02d:%02d", t.Hours, t.Minutes, t.Seconds);
    return buf;
}
```

⚠️ 裸机 `__disable_irq()` 会禁用 SysTick——如果输出很慢（低波特率 UART），可能丢失 tick。对于快速输出（高波特率/CAN/SWO），影响可接受。

## FreeRTOS 移植

```c
// 使用 CMSIS-RTOS2 信号量（可跨 FreeRTOS/RTX/ThreadX 移植）
static osSemaphoreId_t elog_lock;

void elog_port_output_lock(void)   { osSemaphoreAcquire(elog_lock, osWaitForever); }
void elog_port_output_unlock(void) { osSemaphoreRelease(elog_lock); }
const char *elog_port_get_t_info(void) {
    return pcTaskGetName(NULL);                    // FreeRTOS 任务名
}
```

## 输出模式详解

### 直接同步模式（默认）

每次 `log_d(...)` 立即格式化 + 调用 `elog_port_output`。简单直接，但低速 I/O（如 9600 波特率 UART）会阻塞调用者。适合高速接口或带宽不是瓶颈的场景。

### 缓冲模式（`ELOG_BUF_OUTPUT_ENABLE`）

日志攒入 `ELOG_BUF_OUTPUT_BUF_SIZE`（默认 10KB）固定缓冲区。缓冲区满时整批输出。适合 DMA 传输——一次 DMA 发一整个 buffer，比逐条传输效率高得多。

```c
elog_buf_enabled(true);
log_d("tag", "msg1");
log_d("tag", "msg2");
// ... 积攒 ...
elog_flush();  // 或等 buffer 满自动输出
```

### 异步模式（`ELOG_ASYNC_OUTPUT_ENABLE`）

**非阻塞**——日志写入环形缓冲区后立即返回，专门的消费任务负责实际 I/O。适用场景：慢速 UART（115200 波特率仍可能阻塞）、SPI Flash 日志存储。

关键配置：
- `ELOG_ASYNC_OUTPUT_LVL`（默认 `ELOG_LVL_ASSERT`）：高于此级别的日志走直接路径（Assert 级别的日志不应该排队丢失）
- `ELOG_ASYNC_OUTPUT_BUF_SIZE`（默认 `LINE_BUF_SIZE * 10`）：环形缓冲区大小
- 消费任务：POSIX pthread（`ELOG_ASYNC_OUTPUT_USING_PTHREAD`）或自定义 RTOS 任务

**环形缓冲区细节：**
- 满时静默丢弃新日志（不覆盖旧日志——因为重要的日志可能在旧日志里）
- 线程安全：put/get 在锁保护下操作
- 行模式输出（`ELOG_ASYNC_LINE_OUTPUT`）：消费端按完整行取日志，保证每次 `elog_port_output` 得到整条日志

## 文件/Flash 后端插件

EasyLogger 提供两个输出插件（位于 `plugins/`）：

| 插件 | 文件 | 后端 |
|------|------|------|
| 文件 | `elog_file.c` | 通过文件系统（FatFS/LittleFS）写入文件，支持按大小轮转 |
| Flash | `elog_flash.c` | 通过 EasyFlash 直接写 Flash 裸分区 |

插件在 `elog_port_output` 层面接入——输出同时送到串口和文件/Flash。

## 与 printf 对比

| 维度 | printf | EasyLogger |
|------|--------|-----------|
| 级别过滤 | 手动 `#ifdef` 每次 | 编译时+运行时自动门控 |
| 模块标签 | 手动加字符串 | 内置，且可按标签过滤 |
| 线程安全 | 无 | 内置互斥锁 |
| 输出模式 | 仅直接阻塞 | 直接/缓冲/异步三选一 |
| 格式 | 每次手写前缀 | 自动 8 字段格式前缀 |
| 彩色 | 手动 ESC 码 | 可配置每级 ANSI 色 |
| 非阻塞 | 不支持 | 环形缓冲+消费任务 |
| Hex dump | 手动循环 | `elog_hexdump()` 一行 |
| 文件/Flash存储 | 无 | 插件支持 |
