# 1. EasyLogger 概述与架构

## 定位

EasyLogger 是 armink 开发的超轻量嵌入式日志库，ROM <1.6KB，RAM <0.3KB（核心）。目标：比 `printf` 调试强一个档次，但远轻于 `log4c`/`zlog`。

| 指标 | 值 |
|------|-----|
| 核心文件 | `elog.c` + `elog.h` + `elog_cfg.h` |
| ROM 占用 | <1.6KB |
| RAM 占用 | <0.3KB (核心) |
| 日志等级 | 6 级 (A/E/W/I/D/V) |
| 协议 | MIT |

## 架构

```
用户代码 (log_a/log_e/.../log_v 宏)
    ↓
elog.c (格式化 + 过滤器 + 级别检查)
    ↓
    ├── 直接模式 → elog_port_output() [用户实现]
    ├── 缓冲模式 (ELOG_BUF_OUTPUT_ENABLE) → 积攒满一批再输出
    └── 异步模式 (ELOG_ASYNC_OUTPUT_ENABLE) → 环形缓冲 + 消费任务
```

### 单例架构

全局 `EasyLogger` 结构体（`static EasyLogger elog`）持有所有状态：
- 过滤器（全局级别、标签子串、关键词、每标签级别）
- 每级格式 bitmask
- 输出开关、锁开关、颜色开关
- 初始化/锁状态标志

零动态内存分配——全部静态或栈上。

## 六级日志

| 级别 | 宏 | 前缀 | 用途 |
|------|-----|------|------|
| Assert | `log_a` | `A/` | 致命断言 |
| Error | `log_e` | `E/` | 运行时错误 |
| Warn | `log_w` | `W/` | 警告 |
| Info | `log_i` | `I/` | 一般信息 |
| Debug | `log_d` | `D/` | 调试 |
| Verbose | `log_v` | `V/` | 详细追踪 |

编译时级别门控：`ELOG_OUTPUT_LVL` 以上的级别被编译成 `((void)0)`，零开销。

## 过滤器系统（四级过滤）

1. **全局级别**：`elog.filter.level` — 高于此级别的日志被丢弃
2. **标签子串**：`elog.filter.tag` — 标签中不含此子串则丢弃（`strstr` 匹配）
3. **关键词**：`elog.filter.keyword` — 格式化后的消息体不含此关键词则丢弃
4. **每标签级别覆盖**：`elog.filter.tag_lvl[]`（最多 5 个条目）— 每个模块可独立设置级别

过滤逻辑：`level ≤ 全局级别 AND level ≤ 标签级别 AND 标签包含子串 AND 消息含关键词` → 放行。

## 格式控制

每条日志可配置 8 个格式字段（按位或）：

```c
elog_set_fmt(ELOG_LVL_INFO,
    ELOG_FMT_LVL | ELOG_FMT_TAG | ELOG_FMT_TIME | ELOG_FMT_DIR | ELOG_FMT_LINE);
```

| 位 | 效果 |
|----|------|
| `ELOG_FMT_LVL` | `I/` 级别前缀 |
| `ELOG_FMT_TAG` | `[module_name]` |
| `ELOG_FMT_TIME` | `[10:08:12]` 时间戳 |
| `ELOG_FMT_P_INFO` | 进程标识 |
| `ELOG_FMT_T_INFO` | 线程标识 |
| `ELOG_FMT_DIR` | `(file.c)` |
| `ELOG_FMT_FUNC` | `(function_name)` |
| `ELOG_FMT_LINE` | `(line 123)` |

每个级别可单独设置不同格式。例如：`INFO` 简洁 `I/tag: msg`，`DEBUG` 全开带文件行号。

## ANSI 彩色输出

每个级别独立配置前景色/背景色/样式：

| 级别 | 默认色 |
|------|--------|
| Assert | 紫红 `\033[35;22m` |
| Error | 红 `\033[31;22m` |
| Warn | 黄 `\033[33;22m` |
| Info | 青 `\033[36;22m` |
| Debug | 绿 `\033[32;22m` |
| Verbose | 蓝 `\033[34;22m` |

运行时可通过 `elog_set_text_color_enabled(bool)` 开关。通过 UART 输出到终端时视觉效果很好。

## 使用模式

```c
// 方式 A: 每行指定 tag
elog_i("wifi", "Connected to AP, RSSI: %d", rssi);

// 方式 B: 文件级默认 tag（最常用）
#define LOG_TAG   "wifi"
#define LOG_LVL   ELOG_LVL_DEBUG
#include <elog.h>
log_d("SSID: %s", ssid);  // 自动用 "wifi" 作为 tag
```
