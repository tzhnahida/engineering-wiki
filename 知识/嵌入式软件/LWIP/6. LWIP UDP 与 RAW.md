# LWIP UDP 与 RAW

## UDP

UDP 是 lwIP 中最简单的传输层协议——无状态、无重传、无拥塞控制。

### UDP PCB

```c
struct udp_pcb {
  IP_PCB;                          // 嵌入 IP 通用字段
  struct udp_pcb *next;
  u8_t flags;                      // UDP_FLAGS_CONNECTED, UDP_FLAGS_NOCHKSUM...
  u16_t local_port, remote_port;   // 本地/远程端口（网络字节序）
  udp_recv_fn recv;                // 数据到达回调
  void *recv_arg;                  // 回调参数
};
```

### UDP 入站 `udp_input`

```
1. 验证 UDP 头（长度 >= UDP_HLEN）
2. 遍历 udp_pcbs 链表找匹配：
   a. local_port == dest_port
   b. local_ip 匹配（ANY、单播、广播、多播）
   c. 完美匹配：remote_port + remote_ip 也匹配
3. 通过 pcb->recv 回调传递数据包
4. 未找到匹配 → 发 ICMP 端口不可达
```

**PCB 匹配优先级**：
1. 精确匹配（已 connect 的 PCB，远程端口+IP 都匹配）
2. 第一个匹配的未连接 PCB

### UDP 出站 `udp_sendto_if_src`

```
1. 若未绑定 → 自动绑定随机端口
2. pbuf 上加 UDP 头（若 PBUF_IP 层有空间则原地加，否则分配头 pbuf 并链接）
3. 填写源/目标端口、总长度
4. 计算伪头校验和（可选关闭 UDP checksum）
5. 调用 ip_output_if_src
```

### 与 TCP PCB 的关键差异

| 特性 | TCP PCB | UDP PCB |
|------|---------|---------|
| 状态机 | 11 状态 | 无状态 |
| 段队列 (unsent/unacked/ooseq) | 有 | 无 |
| 重传 | 有 (RTO) | 无 |
| 拥塞控制 | 有 (cwnd/ssthresh) | 无 |
| 回调数量 | 5 个 (recv/sent/connected/poll/err) | 1 个 (recv) |

## RAW — 原始 IP 协议

RAW PCB 允许用户实现自定义 IP 协议（非 TCP/UDP）。

```c
struct raw_pcb {
  IP_PCB;
  struct raw_pcb *next;
  u8_t protocol;            // IP 协议号（如 1=ICMP, 2=IGMP）
  raw_recv_fn recv;         // 收到匹配协议的数据包时回调
  void *recv_arg;
};
```

**入站**：`raw_input` 在 IP 层被调用，遍历 `raw_pcbs` 链表，为每个匹配协议的 PCB 复制 pbuf 并调用 `recv` 回调。

**出站**：`raw_send` 直接将 pbuf + IP 头传给 IP 层输出。

## 与 FreeRTOS 的对比

| lwIP UDP/RAW | FreeRTOS |
|-------------|----------|
| UDP PCB 链表 | 类似软件定时器链表——单链表通过临界区保护遍历 |
| UDP 无状态 | 类似 FreeRTOS 消息队列的"发后即忘"语义 |
| RAW PCB | 无直接对应——类似中断服务程序的注册机制 |
