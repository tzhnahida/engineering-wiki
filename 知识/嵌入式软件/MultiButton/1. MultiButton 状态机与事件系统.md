# 1. MultiButton 状态机与事件系统

## 定位

MultiButton 是超轻量嵌入式按键驱动，一个 C 文件（322行）+ 一个 H 文件（117行），C99 标准。非阻塞、事件驱动、每个按钮 ~30 字节 RAM。

| 指标 | 值 |
|------|-----|
| 核心文件 | `multi_button.c` + `multi_button.h` |
| 每按钮 RAM | ~30 bytes（位域优化） |
| 驱动方式 | 5ms 周期 `button_ticks()` |
| 协议 | MIT |

## 数据结构

```c
struct _Button {
    uint16_t ticks;
    uint8_t  repeat : 4;        // 重复点击计数 (0-15)
    uint8_t  event  : 4;        // 当前事件 (0-15)
    uint8_t  state  : 3;        // 状态机状态 (0-7)
    uint8_t  debounce_cnt : 3;  // 消抖计数 (0-7)
    uint8_t  active_level : 1;  // 有效电平
    uint8_t  button_level : 1;  // 当前去抖后电平
    uint8_t  button_id;         // 用户分配 ID
    uint8_t  (*hal_button_level)(uint8_t);  // GPIO 读函数
    BtnCallback cb[7];          // 每事件回调
    void*    user_data;         // 用户上下文
    Button*  next;              // 链表下一节点
};
```

16 bits 状态字段（repeat + event + state + debounce_cnt + active_level + button_level）通过位域压缩。`DEBOUNCE_TICKS` 上限 7 由编译期 `#error` 保护。

## 五态状态机

```
                    +--LONG_TICKS 超时→ [LONG_HOLD]
                    |                     |
[IDLE]─按下→[PRESS]                       释放
  ↑           |                            |
  |        释放                            |
  |           ↓                            |
  +-超时←[RELEASE]←──────────←─────────────+
            |      ^
        超时|      |再按 (SHORT_TICKS 内)
            |      |
            +→[REPEAT]──→
                   |
            按住超 SHORT_TICKS → 重置到 [PRESS]
```

### 状态详解

| 状态 | 进入 | 退出条件 | 产生的事件 |
|------|------|---------|-----------|
| IDLE | 初始化/超时 | 电平变化 | — |
| PRESS | 按下消抖完成 | 释放 / 超 LONG_TICKS | `PRESS_DOWN` |
| RELEASE | 释放 | 再按 / 超 SHORT_TICKS | `PRESS_UP` → `SINGLE_CLICK` 或 `DOUBLE_CLICK` |
| REPEAT | 快速再次按下 | 释放 / 超 SHORT_TICKS | `PRESS_DOWN`, `PRESS_REPEAT` |
| LONG_HOLD | 长按超时 | 释放 / 持续按住 | `LONG_PRESS_START`(一次), `LONG_PRESS_HOLD`(每滴答) |

## 七种事件

| 事件 | 触发时机 | 典型用途 |
|------|---------|---------|
| `PRESS_DOWN` | 按下消抖完成 | 按下即反应（静音键） |
| `PRESS_UP` | 释放 | 对偶操作 |
| `PRESS_REPEAT` | 快速多次按下 | 多击检测 |
| `SINGLE_CLICK` | 短按后释放超时 | 确认/切换 |
| `DOUBLE_CLICK` | 双击后超时（repeat==2） | 高级操作 |
| `LONG_PRESS_START` | 按住超过 1 秒 | 进入设置模式 |
| `LONG_PRESS_HOLD` | 长按持续中（每 5ms 一次） | 连续调节（亮度/音量） |

### N 击检测

库原生支持单击/双击。三击及以上不产生专用事件——用户在 `SINGLE_CLICK` 回调中检查 `button_get_repeat_count()`。`repeat` 饱和值 15。

## 数字消抖

消抖窗口 = `DEBOUNCE_TICKS × TICKS_INTERVAL`。默认 3×5ms = 15ms。

```c
if (按钮电平 ≠ 上一次去抖后的电平) {
    debounce_cnt++;
    if (debounce_cnt >= DEBOUNCE_TICKS) {
        接受新电平; debounce_cnt = 0;
    }
} else {
    debounce_cnt = 0;  // 任何不一致就重置
}
```

不需要外部 RC 网络或硬件消抖电路。`DEBOUNCE_TICKS` 最大 7（受 3-bit bitfield 限制），最大消抖 7×5=35ms。

## 可配置参数

| 宏 | 默认值 | 效果 |
|----|--------|------|
| `TICKS_INTERVAL` | 5ms | 驱动周期 |
| `DEBOUNCE_TICKS` | 3 | 消抖采样次数 |
| `SHORT_TICKS` | 300/TICKS_INTERVAL = 60 | 短按超时（区分单击/长按） |
| `LONG_TICKS` | 1000/TICKS_INTERVAL = 200 | 长按触发阈值 |
| `PRESS_REPEAT_MAX_NUM` | 15 | 重复次数上限 |

修改 `TICKS_INTERVAL` 自动缩放所有时间阈值（因为 SHORT/LONG_TICKS 是宏计算出来的）。

## 集成模式

### 基本用法

```c
static Button btn_ok;

uint8_t read_pin(uint8_t id) {
    return HAL_GPIO_ReadPin(BTN_OK_GPIO_Port, BTN_OK_Pin);
}

void on_click(void* btn, void* ctx) { /* ... */ }
void on_long_press(void* btn, void* ctx) { /* ... */ }

void setup() {
    button_init(&btn_ok, read_pin, 0, 1);     // active_level=0 拉低有效
    button_attach(&btn_ok, SINGLE_CLICK, on_click, NULL);
    button_attach(&btn_ok, LONG_PRESS_START, on_long_press, NULL);
    button_start(&btn_ok);
}

// 每 5ms 调用（TIM 中断 / FreeRTOS 任务 / 主循环）
void TIM3_IRQHandler() { button_ticks(); }
```

### 线程安全

定义 `MULTIBUTTON_THREAD_SAFE` 并提供锁宏：
```c
#define MULTIBUTTON_LOCK()   xSemaphoreTake(btn_mutex, portMAX_DELAY)
#define MULTIBUTTON_UNLOCK() xSemaphoreGive(btn_mutex)
```

回调执行时不持锁——在回调内 `button_stop()`/`button_start()` 不会死锁。
