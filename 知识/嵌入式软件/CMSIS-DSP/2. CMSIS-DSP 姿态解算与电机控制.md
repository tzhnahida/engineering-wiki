# 2. CMSIS-DSP 姿态解算与电机控制

## 与你的维基的关系

你的 `知识/姿态解算/` 页面涵盖 Madgwick AHRS、ESKF。CMSIS-DSP 直接提供这些算法所需的核心数学函数——比你手写更快（SIMD）、更可靠（测试过），且几乎零额外 ROM 成本（CubeMX 已自带）。

## 四元数函数 — 姿态解算核心

所有四元数以 `[w, x, y, z]` 格式存储为 4 元素 float32 数组。

### 基础运算

```c
float32_t q1[4] = {qw, qx, qy, qz}, q2[4], qout[4];

arm_quaternion_normalize_f32(q1);            // 归一化 → 漂移修正
arm_quaternion_product_single_f32(q1, q2, qout);  // q1 * q2 → 姿态更新
arm_quaternion_conjugate_f32(q1, qout);      // 共轭 → 旋转逆
arm_quaternion_inverse_f32(q1, qout);         // 逆（单位四元数 = 共轭）
```

### 四元数 ↔ 旋转矩阵

```c
float32_t R[9];  // 行主序: [R00,R01,R02, R10,R11,R12, R20,R21,R22]

arm_quaternion2rotation_f32(q, R);  // 四元数 → 3×3 旋转矩阵
arm_rotation2quaternion_f32(R, q);  // 旋转矩阵 → 四元数
```

这在 EKF 中用于状态向量 ↔ 观测模型之间的坐标系转换。

### Madgwick AHRS 中的应用

Madgwick 算法每步迭代需要：
- 四元数乘法（陀螺仪积分）
- 四元数归一化（漂移修正）
- 梯度下降中的向量运算

`arm_quaternion_product_single_f32` + `arm_quaternion_normalize_f32` 直接替代手写四元数运算。在 M4/M7 上启用 `ARM_MATH_DSP` 自动获得 SIMD 加速。

## 快速三角函数 — 高频调用的瓶颈

姿态解算中每次迭代都要计算 sin/cos/atan2：

```c
float32_t angle;
float32_t sin_val, cos_val;

arm_sin_cos_f32(angle, &sin_val, &cos_val);  // 一次查表得 sin+cos
```

`arm_sin_cos_f32` 使用 360 条目表（每度一项），比 `sinf()/cosf()` 快 3-5 倍，精度 ~1e-4。在 1000Hz IMU 更新率下，省下的 CPU 时间可做更多事情。

## FFT — 频域分析

```c
arm_cfft_instance_f32 S;
arm_cfft_init_256_f32(&S);        // 使用 size-specific init（省 ROM）
arm_cfft_f32(&S, data, 0, 1);     // ifftFlag=0 (正变换), bitReverse=1
arm_cmplx_mag_f32(data, mag, 256); // 幅值谱
```

IMU 振动分析、电机电流谐波分析——不需要额外库。

## 矩阵函数 — EKF 基础

EKF 每步：
1. **状态预测**：`F * x` → `arm_mat_vec_mult_f32`
2. **协方差预测**：`F * P * F^T + Q` → `arm_mat_mult_f32` + `arm_mat_trans_f32` + `arm_mat_add_f32`
3. **卡尔曼增益**：`P * H^T * (H * P * H^T + R)^-1` → `arm_mat_inverse_f32`

在 M4/M7 上这些矩阵运算有汇编级 SIMD 加速。

## 电机控制 — Clarke/Park/PID

### FOC 变换链

```
3 相电流 (Ia, Ib)                        ─Clarke→  (Iα, Iβ) 静止 2 轴
                                          ─Park→    (Id, Iq) 旋转坐标系
PID 控制器 → (Vd, Vq)
                                          ─逆Park→  (Vα, Vβ)
                                          ─逆Clarke→ 3 相电压 → SVPWM
```

```c
arm_clarke_f32(Ia, Ib, &Ialpha, &Ibeta);
arm_park_f32(Ialpha, Ibeta, &Id, &Iq, sin_theta, cos_theta);

// PID 控制 Id, Iq
arm_pid_f32(&pid_d, Id_ref - Id);   // inline 函数，一个 MAC
arm_pid_f32(&pid_q, Iq_ref - Iq);

arm_inv_park_f32(Vd, Vq, &Valpha, &Vbeta, sin_theta, cos_theta);
arm_inv_clarke_f32(Valpha, Vbeta, &Va, &Vb);
```

### PID 控制器

```c
arm_pid_instance_f32 pid;
arm_pid_init_f32(&pid, 1);      // resetState=1
pid.Kp = 0.5f; pid.Ki = 0.01f; pid.Kd = 0.1f;

// 每控制周期:
float32_t out = arm_pid_f32(&pid, setpoint - measurement);
```

`arm_pid_f32` 是 **inline** 函数——零函数调用开销。实现差分方程：

```
y[n] = y[n-1] + A0*x[n] + A1*x[n-1] + A2*x[n-2]
```

其中 A0/A1/A2 从 Kp/Ki/Kd 计算。

## STM32 上的实际使用

CMSIS-DSP 已经包含在 CubeMX 工程中。启用步骤：

1. CubeMX → Software Packs → 勾选 CMSIS-DSP
2. 编译宏：`ARM_MATH_DSP`（M4/M7）+ `ARM_MATH_LOOPUNROLL`（可选）
3. 优化：`-O3 -ffast-math`

**不需要额外下载或配置**——你的所有 STM32F4/H7 工程已经自带。

## 与手写代码的性能差距

| 操作 | 手写 C | CMSIS-DSP (M4 SIMD) |
|------|--------|---------------------|
| 四元数乘法 | ~30 周期 | ~15 周期 |
| 128 点 FFT | ~50K 周期 | ~15K 周期 |
| 4×4 矩阵乘 | ~200 周期 | ~80 周期 |
| sin+cos | ~200 周期 | ~40 周期 |

**结论**：如果你的姿态解算/电机控制代码还在手写数学函数，立刻换 CMSIS-DSP——不需要任何代价，性能翻倍。
