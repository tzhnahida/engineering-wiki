# 1. CMSIS-DSP 概述与函数全景

## 定位

CMSIS-DSP 是 Arm 官方优化的嵌入式计算库。17 个函数类别，7 种数据类型（f64/f32/f16/q31/q15/q7），三级 SIMD 加速（DSP 扩展/Helium/Neon）。

| 指标 | 值 |
|------|-----|
| 数据类型 | f64, f32, f16, q31, q15, q7 |
| SIMD 加速层 | M4/M7 DSP 扩展 → M55/M85 Helium MVE → A 系列 Neon |
| 协议 | Apache 2.0 |
| 编译要求 | `-O3 -ffast-math` |

## 函数类别总览

### 基础数学 (BasicMathFunctions)

向量逐元素运算：`arm_add/sub/mult/scale/abs/dot_prod/offset/negate/shift_f32/q31/q15/q7`。全部无状态。固定点 scale 用 `(scaleFract, shift)` 分裂表示。

### 快速数学 (FastMathFunctions)

标量快速近似（查表+插值）：

| 函数 | 方式 |
|------|------|
| `arm_sin_f32/q31/q15` | 512 条目表 + 线性插值 |
| `arm_cos_f32/q31/q15` | 同上 |
| `arm_sqrt_f32` | Newton-Raphson，f32 用硬件 VSQRT |
| `arm_atan2_f32/q31/q15` | 四象限反正切 |

### 复数数学 (ComplexMathFunctions)

复数数组以交错格式存储 `[real, imag, real, imag, ...]`。`arm_cmplx_mag`（幅值）、`arm_cmplx_mag_squared`（功率谱，省 sqrt）、`arm_cmplx_mult_cmplx`（复乘）。

### 滤波器 (FilteringFunctions) — 最大类别

| 类别 | 代表函数 | 用途 |
|------|---------|------|
| FIR | `arm_fir_f32` | 通用数字滤波，任意阶数 |
| 双二阶 IIR | `arm_biquad_cascade_df1/df2T_f32` | 均衡器/滤波器，低状态内存 |
| LMS 自适应 | `arm_lms_f32` | 回声消除、噪声抑制 |
| 卷积/相关 | `arm_conv/correlate_f32` | 信号处理 |
| 抽取/插值 | `arm_fir_decimate/interpolate_f32` | 多速率信号处理 |

所有滤波器使用**实例结构体**（状态+系数），以块为单位处理（非逐样本）。

### 矩阵 (MatrixFunctions)

`arm_matrix_instance_f32`（行主序）。支持：加减乘、转置、求逆（Gauss-Jordan）、Cholesky/LDL^t/QR 分解、上下三角求解。

### 变换 (TransformFunctions)

CFFT/RFFT 支持 16/32/64/128/256/512/1024/2048/4096 点（2 的幂）。DCT Type-IV（`arm_dct4_f32`）、MFCC（`arm_mfcc_f32`，语音特征）。

**关键**：使用 size-specific init（如 `arm_cfft_init_256_f32`）而非 generic init，链接器可剔除不用的旋转因子表，节省 ~16KB ROM。

### 统计 (StatisticsFunctions)

`arm_mean/var/std/rms/power/min/max/entropy` 等。`min/max` 返回值和索引。

### 控制 (ControllerFunctions)

| 函数 | 用途 |
|------|------|
| `arm_pid_f32` | PID 控制器 |
| `arm_clarke_f32` | 3 相 → 2 轴静止（FOC 第一步） |
| `arm_inv_clarke_f32` | 2 轴 → 3 相 |
| `arm_park_f32` | 静止 → 旋转坐标系 |
| `arm_inv_park_f32` | 旋转 → 静止坐标系 |
| `arm_sin_cos_f32` | 同时计算 sin+cos（360 表） |

Clarke/Park 变换是 FOC（磁场定向控制）的数学基础。

### 四元数数学 (QuaternionMathFunctions)

`arm_quaternion_product/normalize/inverse/conjugate`、`arm_quaternion2rotation`（→3×3 旋转矩阵）、`arm_rotation2quaternion`。**与姿态解算直接相关。**

### 窗函数 (WindowFunctions)

22 种窗函数：Hanning/Hamming/Bartlett/Welch → Nuttall/Blackman-Harris → 多达 HFT248dB 的 flat-top 窗。FFT 预处理必备。

### 距离 (DistanceFunctions)

欧几里得/曼哈顿/切比雪夫/余弦/相关/JS 散度/DTW（动态时间规整）。布尔距离家族（Dice/Jaccard/Hamming 等 10 种）。主要用于聚类和 ML 推理。

### SVM/Bayes (SvmFunctions/BayesFunctions)

二分类 SVM（Linear/Polynomial/RBF/Sigmoid 四种核）+ 高斯朴素贝叶斯。从 scikit-learn 导出参数后直接部署到 MCU。

### 插值 (InterpolationFunctions)

线性/双线性/三次样条插值。

### 支持 (SupportFunctions)

`arm_copy/fill`、定点-浮点互转（`arm_float_to_q15` 等）、排序（bitonic/bubble/heap/insertion/quick/selection/merge）。

## API 命名模式

```
arm_<操作>_<变体>_<数据类型>
```

- 操作：add, fir, cfft, mat_mult, pid, quaternion_product ...
- 变体：`fast`（DSP 优化）、`no_idx`（不返回索引）
- 数据类型：f32, f64, q31, q15, q7, f16
