# CH9344L

> 沁恒（WCH）· USB 转 **4 路 UART** 桥接控制器 · LQFP-48 (7×7 mm, P0.5)
> 本库中共 **1 颗**（[USB_4USB](../../USB_4USB.md) U2），四路串口全部引出。

**手册**：`F:\Projects\PCB\Library\Datasheet\Chip_USBConverter_CH9344L.PDF`
WCH **CH9344 Datasheet V1C**，7 页。

---

## 1. 特点（`p1` §2）

| 项目 | 值 |
|---|---|
| 类型 | USB 转 **4 路 UART** 桥接控制器（UART0/1/2/3，全双工） |
| 工作电压 | **3.3 V**（VCC33） |
| USB | **高速 USB 2.0**（外围只需晶体与电容） |
| UART 内核 | 兼容 **16C550** 并增强 |
| 数据格式 | 5 / 6 / 7 / 8 数据位；1 或 2 停止位 |
| 校验 | 奇、偶、无、blank0、mark1 等 |
| 流控 | 支持 **RTS / CTS 硬件自动流控** |
| 半双工 | 支持半双工；**支持发送状态 RS485 切换，默认开启** |
| GPIO | 提供 **12 个 GPIO** |
| 波特率 | 可编程，115200 bps 起，**最高 12 Mbps** |
| **独立供电** | **UART0/1/2 及部分 I/O 独立供电**，支持 **3.3 / 2.5 / 1.8 V**；**UART3 固定 3.3 V** |
| 驱动 | Windows XP~11/Server、Linux 等 |
| 封装 | **LQFP-48**，7×7 mm，0.5 mm 间距（`p2` §3） |

## 3. 本库用法（网表实测，21/48 脚落地）

[USB_4USB](../../USB_4USB.md) 的 U2。24 个未用脚中多数是 UART1/2/3 的流控与 GPIO，以及测试脚。

| 类别 | 引脚 → 网络 | 手册对应 |
|---|---|---|
| 供电 | 2 / 27 / 33 = `+3.3V` · 1 / 34 = `GND` | VCC33 / GND |
| 内核电源 | 3 = `$1N1585` · 35 = `$1N51` | **V12O（1.2 V 输出）/ V12I（1.2 V 输入）** |
| 保留脚 | 30 = `$1N49` | **RSVD1（12 kΩ + 20 pF）** |
| 复位 | 38 = `$1N43` | RST# |
| USB | 31 = `DP1` · 32 = `DN1` | UD+ / UD− |
| UART0 | 19 = `TXD0` · 22 = `RXD0` | ✓ |
| UART1 | 45 = `TXD1` · 44 = `RXD1` | ✓ |
| UART2 | 43 = `TXD2` · 42 = `RXD2` | ✓ |
| UART3 | 41 = `TXD3` · 40 = `RXD3` | ✓ |
| **I/O 电源** | **18 = `VIO1` · 48 = `VIO2`** | 见 §4 |

> [!note] 上一轮标为「局部自动命名网（晶振、配置等）」的四个脚，现在全部具名
> `$1N1585` = **V12O**（1.2 V 内核输出，需 3.3 µF）、`$1N51` = **V12I**（需 0.1 µF）、
> `$1N49` = **RSVD1**（需 12 kΩ + 20 pF）、`$1N43` = **RST#**。
> 其中 **RSVD1 的 12 kΩ + 20 pF 是硬性要求** —— ⚠️ 板上是否按此配置，网表看不出元件值配对，需回原理图确认。

## 4. 上一轮没解决的问题：`VIO1`/`VIO2` 到底接哪 —— 已查清

网表里这两个网络的名字就是 `VIO1`/`VIO2`，成员**全是连接器的引脚**：

```
VIO1  [3]  U2-18(CH9344L) | U12-1(4P 排针) | U13-2(3P 排针)
VIO2  [5]  U2-48(CH9344L) | U9-1 | U10-1 | U11-1(均 4P 排针) | U14-2(3P 排针)
```

把 6 个排针的完整引脚与四路 UART 的信号去向拼起来，结构就清楚了：

| 排针 | 位号 | 引脚定义 | 对应 UART |
|---|---|---|---|
| U12 | 4P | 1 = **`VIO1`** · 2 = `TXD0` · 3 = `RXD0` · 4 = `GND` | UART0 |
| U10 | 4P | 1 = **`VIO2`** · 2 = `TXD1` · 3 = `RXD1` · 4 = `GND` | UART1 |
| U9 | 4P | 1 = **`VIO2`** · 2 = `TXD2` · 3 = `RXD2` · 4 = `GND` | UART2 |
| U11 | 4P | 1 = **`VIO2`** · 2 = `TXD3` · 3 = `RXD3` · 4 = `GND` | UART3 |
| U13 | 3P | 1 = `+3.3V` · 2 = **`VIO1`** · 3 = `+5V` | **VIO1 选择跳线** |
| U14 | 3P | 1 / 2 = **`VIO2`** · 3 = 待确认 | **VIO2 选择跳线** |

> [!tip] 这是一个刻意做的「**I/O 电平可选**」设计
> 四路 UART 的排针**第 1 脚都接自己那一路的 VIO 轨**（UART0 → VIO1，UART1/2/3 → VIO2），
> 与手册的分工**完全吻合**：手册说 **VIO1 给 11–26 脚供电**（UART0 在其中）、
> **VIO2 给 42–48 脚供电**（UART1/2/3 在其中）。
> 而 U13/U14 是**三脚跳线**：短接 1–2 则 VIO = 3.3 V，短接 2–3 则 VIO = 5 V。
> 即**每路串口的 I/O 电平由跳线决定**，接 3.3 V 或 5 V 外设都不用改板。
> ⚠️ 这是从网络成员表推出的结构，跳线帽的实际状态与 U14 的第 3 脚去向需回原理图确认。

> [!danger] 但 **5 V 档超出手册声明的范围**
> 手册 `p1` 明确写：UART0/1/2 及部分 I/O 独立供电「**支持 3.3 V、2.5 V 或 1.8 V**」——
> **没有 5 V**。而 U13 提供的可选项之一是 `+5V`。
> 若跳线选到 5 V，VIO 轨就超出数据手册承诺的范围（器件实际是否耐受 5 V，手册未表态）。
> ⚠️ 这是「网表结构 vs 手册范围」的比对结论，是否实际用过 5 V 档、器件是否耐受，**均需确认**。
