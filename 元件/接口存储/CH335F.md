## 1. 特点（`p1`）

| 项目 | 值 |
|---|---|
| 类型 | **4 端口 USB 2.0 HUB 控制器** |
| 上行端口 | USB 2.0 **高速 480 Mbps / 全速 12 Mbps / 低速 1.5 Mbps** |
| 下行端口 | 向下兼容 USB 1.1 |
| 电源控制 | 各端口**独立电源控制**，或 **GANG 整体联动** |
| 过流检测 | 各端口**独立过流检测**，或 GANG 整体；过流信号输入**支持 5 V 耐压** |
| 传输模式 | 支持 **MTT**（4 个 TT 各对应 1 个端口，并发处理），总带宽是 STT 的 **4 倍** |
| 指示 | 支持端口状态 **LED 指示灯** |
| 配置 | 外部 EEPROM 可配置复合设备/不可移除设备/自定义 VID、PID；**内置信息存储器** |
| PHY | 自研专用 USB PHY + **LPM 低功耗** |
| 时钟 | 支持外部 12 MHz 晶体（内置电容）或**免晶振**（内置高精度时钟） |
| 端接电阻 | 上行端口内置 **1.5 kΩ 上拉**；下行端口内置 Host 所需**下拉电阻** |
| 内置 LDO | 可将 USB 总线 **5 V 转为芯片 3.3 V 工作电源** |
| ESD | USB 引脚 **6 kV 增强 ESD**，Class 3A |
| 温度 | 工业级 **−40 ~ 85 °C** |

`p3` 表1-1 同簇型号对比（**CH335F 列**）：MTT ✓ · 过流检测 **独立/GANG** ✓ · 电源控制 **独立/GANG** ✓ ·
LED **5 灯/9 灯** · I/O 引脚配置 √ · 外部 EEPROM √ · 定制配置信息 √ · 免晶振 可选 · **交换上行端口 可选**。

## 3. `PWREN#` 极性 —— 与 [CH217K](../电源管理/CH217K.md) 的 `EN#` **同极性，直连正确**

这是本轮专门核的一处，因为它决定 [USB_4USB](../../USB_4USB.md) 上「Hub 直连限流开关」是否成立。

`p5` 表1-3 原文：

| 引脚 | 手册原文 |
|---|---|
| PWREN1# | 1# 下行端口电源输出控制引脚，**PWREN1# 为低电平开启**，CH334X 的 PWREN1 为高电平开启 |
| PWREN2# | 2# 下行端口电源输出控制引脚，**PWREN2# 为低电平开启**，CH334X 的 PWREN2 为高电平开启 |
| PWREN3# / PWREN4# | 同上（低电平开启） |

`p6` 注原文：**「CH334X 的 4 个 PWREN 可参考 CH335 的 4 个 PWREN#，引脚一一对应，但电源控制极性相反。」**

> [!note] 结论：**CH335F = 低电平开启；CH334X = 高电平开启**
> 而 [CH217K](../电源管理/CH217K.md) 的 pin 4 是 **`EN#`，低电平有效（低 = 开）**（CH217 手册 `p2`）。
> ⇒ **Hub 的 `PWRENn#` 与开关的 `EN#` 同为低有效，直接相连不需要反相** ——
> [USB_4USB](../../USB_4USB.md) 网表里 `PWREN2 → U5-4`、`OVCUR2 → U5-3` 这种直连**是对的**。
>
> ⚠️ 上一轮本页把这条列为「极性待确认」并提示「若极性相反则端口常关」。
> 现在按手册 p5/p6 定案：**不存在反相问题**；`p4` 里那句「电源控制 PWREN 为高电平有效」指的是 **CH334X**，不是 CH335。

## 4. 本库用法（网表实测，27 脚落地）

[USB_4USB](../../USB_4USB.md) 的 U1 = `CH335F`，QFN-28：

| 类别 | 引脚 → 网络 |
|---|---|
| 供电 | 26 = `+5V`（V5）· 28 = `+3.3V`（VDD33）· 27 + 29(EP) = `GND` |
| 上行 | 20 = `USBDN` · 21 = `USBDP` → Type-C 座 |
| 下行数据 | 6/7 = `DN1`/`DP1` · 8/9 = `DN2`/`DP2` · 13/14 = `DN3`/`DP3` · 15/16 = `DN4`/`DP4` |
| 端口电源使能 | 2 = `PWREN2` · 10 = `PWREN3` · 5 = `PWREN4` |
| 端口过流 | 23 = `OVCUR2` · 19 = `OVCUR3` · 18 = `OVCUR4` |
| 状态指示 | 1 = `LED1` · 3 = `LED2` · 22 = `LED3` · 25 = `LED4` |
| 复位 | 17 = `RES` → **R7 = 4.7 kΩ（标注 NC，未贴）** —— 与手册「不复位时建议完全悬空」一致 |
| 时钟 | 11 / 12 = 局部网（XI / XO，12 MHz 晶体） |

### 4.1 1# 端口去哪了 —— 上一轮的疑问已解

`PWREN1#`(4) 与 `OVCUR1#`(24) 在网表里不存在，但 **`DN1`/`DP1` 是接了**的：

```
DP1  [2]  U2-31(CH9344L, UD+)  |  U1-7(CH335F, DP1)
DN1  [2]  U2-32(CH9344L, UD-)  |  U1-6(CH335F, DM1)
```

> [!tip] 板载的 [CH9344L](CH9344L.md) 就挂在 **1# 下行端口**上
> 所以 1# 端口**不需要**电源开关与过流检测 —— 它是**板内固定负载**，不对外供电、也不会被插拔短路。
> 这修正了上一轮「1# 端口未用 / 该板是 1 进 3 出」的说法：
> **该板 4 个下行端口全部在用 —— 1# 给板载 CH9344，2#/3#/4# 走 [CH217K](../电源管理/CH217K.md) 限流后引出**。

### 4.2 与沁恒参考应用图的逐脚互证

[CH217K](../电源管理/CH217K.md) 手册 `p4` 的参考应用图画的正是 **CH335F + 4×CH217A**，其 Hub 引脚定义为
`1=LED1/PSELF · 2=PWREN2# · 3=LED2/PGANG · 5=PWREN4#/SUSP · 6=DM1 · 7=DP1 · 8=DM2 · 9=DP2 · 10=PWREN3# ·
11=XI · 12=XO · 13=DM3 · 14=DP3 · 15=DM4 · 16=DP4 · 17=RESET#/CDP · 18=OVCUR4# · 19=OVCUR3# · 20=DMU ·
21=DPU · 22=LED3/SCL · 23=OVCUR2# · 24=OVCUR1# · 25=LED4/SDA · 26=V5 · 27=GND · 28=VDD33`

与上表网表实测**逐脚一致**（另一处独立来源），这张引脚表可放心使用。
