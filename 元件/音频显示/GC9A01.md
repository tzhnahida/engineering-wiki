# GC9A01

> 圆形 TFT 驱动 IC **GC9A01A** · 240RGB×240 · 360 source / 32 gate 输出 · 内置全显示 RAM 与 DC/DC
> [kig眼](../../kig眼.md) 的显示器件（板上是 12 脚**模组**），由 STM32F103TBU6 直驱。

**手册**：`F:\Projects\PCB\Library\Datasheet\Chip_Display_GC9A01A.PDF`
GalaxyCore **GC9A01 Datasheet V1.0 Preliminary**（文档号 LCD-DST-3014，2019-07-02），192 页。

> [!warning] 手册是**驱动 IC** 的，板上装的是**模组**
> 本手册描述的是 GC9A01A **裸驱动 IC**（COG 绑定，无引脚号概念）。
> [kig眼](../../kig眼.md) 上 U13 的封装名虽写 `GC9A01`，但实际是 **12 脚模组**（含背光 `LEDK`）。
> 因此**模组的 12 脚定义不来自这份手册**，仍需模组厂规格书 —— 见 §4。

## 1. 身份与特性（`p7` Features）

| 项目 | 值 |
|---|---|
| 型号 | GC9A01A |
| 类型 | a-Si TFT LCD 单芯片驱动（Single Chip Driver） |
| **分辨率** | **[240RGB] (H) × 240 (V)** ← 旧页「常见 240×240，未核实」现已确认 |
| 输出 | **360 个 source 输出** + **32 个 gate 输出** |
| 分辨率映射 | 240×240 → S1–S360；另支持 80×160、120×120/120×240、128×128、160×160 等裁剪 |
| 显示 RAM | **片内全显示 RAM，129,600 字节** |
| 显示模式 | 全色模式（Idle OFF）**262K 色**；精简色模式（Idle ON）8 色 |
| 片内功能 | 时序发生器 · **振荡器** · **DC/DC 变换器** · 点/列反转 |
| 外部元件 | **无需外部电子元件**（No need for external electronic component） |
| 存储电容 | a-Si TFT，Cst on Common 结构 |
| 省电 | Sleep 模式 |

## 2. 接口与电源

`p7` 系统接口：

| 类型 | 支持格式 |
|---|---|

| RGB 接口（配图形控制器） | 6 / 12 / 16 / 18 bit |
| **串行外设接口 SPI** | **8 / 9 bit**，以及 **2 data lane SPI（24 bit）** |

`p7` 供电：

| 域 | 范围 | 说明 |
|---|---|---|
| **IOVCC** | **1.65 ~ 3.3 V** | 逻辑电源 |
| **VCI** | **2.5 ~ 3.3 V** | 模拟电源 |
| GVDD − GVCL | 6.4 ~ −4.6 V | Source/Gamma 电源 |
| VGH − GND | 12.0 ~ 13.0 V | Gate 驱动输出 |
| VGL − GND | −11.0 ~ −8.0 V | Gate 驱动输出 |
| VGH − VGL | ≤ 27 V | — |
| VCOM | 接 GND | — |
| 工作温度 | **−40 ~ +80 °C** | — |

> [!note] 板上给模组的 `+3.3V` 同时落在 IOVCC 与 VCI 的允许范围内
> [kig眼](../../kig眼.md) 的模组 pin 3/4 都接 `+3.3V`（网表实测）。
> 3.3 V 处于 IOVCC 上限与 VCI 上限 —— **在规格内但没有裕量**，若 3.3 V 轨有上冲需注意。

| 项目 | 符号 | 额定值 | 单位 |
|---|---|---|---|
| 模拟电源电压 | VCI | −0.3 ~ +4.6 | V |
| 逻辑电源电压 | IOVCC | −0.3 ~ +4.6 | V |
| 数字电源电压 | DVDD | −0.3 ~ **+2.0** | V |
| 驱动电源电压 | VGH − VGL | −0.3 ~ +27.0 | V |
| 逻辑输入电压 | VIN | −0.3 ~ IOVCC + 0.3 | V |
| 逻辑输出电压 | VO | −0.3 ~ IOVCC + 0.3 | V |
| 工作温度 | Topr | **−40 ~ +80** | °C |
| 存储温度 | Tstg | −40 ~ +80 | °C |

> [!warning] DVDD 上限只有 **2.0 V**，远低于 VCI/IOVCC 的 4.6 V
> 内部数字域电源最脆弱。手册在 p182 强调：**任一参数即使瞬时超限，也可能导致品质下降甚至物理损坏**。

## 4. [kig眼](../../kig眼.md) 上的实际接法（12 脚模组，网表实测）

| 模组脚 | 网络 | 判定 |
|---:|---|---|
| 1 | `GND` | 地 |
| 2 | **`LEDK`** | 背光负极（LED Cathode） |
| 3 | `+3.3V` | 逻辑/模拟供电 |
| 4 | `+3.3V` | 同上（双引脚并联） |
| 5 | `GND` | 地 |
| 6 | `GND` | 地 |
| 7 | **`PB1`** | → MCU |
| 8 | **`PB3`** | → MCU |
| 9 | **`PA5`** | → MCU |
| 10 | **`PA7`** | → MCU |
| 11 | **`PB0`** | → MCU |
| 12 | `GND` | 地 |

5 根信号线（pin 7–11）全部直连 MCU，中间无器件。

### 4.1 同类模组查证：微雪 1.28inch LCD Module

市面同类圆屏模组中，与本板特征最接近的是 **微雪 1.28inch LCD Module（SKU 19192）**：

| 参数 | 规格 |
|---|---|
| 显示芯片 | **GC9A01** ✓ 与本板一致 |
| 分辨率 | **240 × 240** ✓ |
| 通信接口 | **4-wire SPI** |
| 显示面板 | IPS |
| 工作电压 / 工作电流 | 3.3 V 或 5 V / **31.2 mA** |
| 显示尺寸 / 像素 | Φ32.4 mm / 0.135 × 0.135 mm |
| 产品尺寸 | 40.4 × 37.5 mm |
| 通信时序 | **SPI Mode 0**（CPOL = 0，CPHA = 0），高位在前 |
| 模组引出脚 | VCC · GND · **DIN**(MOSI) · **CLK**(SCLK) · **CS** · **DC** · **RST** · **BL** |

该模组的 STM32 参考接线为 `DIN = PA7`、`CLK = PA5`、`CS = PB6`、`DC = PA8`、`RST = PA9`、`BL = PC7`。

> [!note] 两个直接可用的参数
> **工作电流 31.2 mA** 与 **SPI Mode 0 / MSB first** —— 前者用于电源预算，后者是驱动初始化的必要配置。
> ⚠️ 但它们属于**同类模组**（微雪 SKU 19192）的规格，**本板装的是 12 脚模组、不是微雪的 8 脚引出板**，
> 故这两个值**只能作为量级参考，不能当作本模组的规格**。

### 4.2 5 根信号线：能确定 2 根，仍剩 3 根

| 模组脚 | 网络 | 判定 | 依据 |
|---:|---|---|---|
| 9 | **`PA5`** | **CLK（SCLK）** —— 高置信 | STM32F103 的 **SPI1_SCK 就是 PA5**（硬件固定映射） |
| 10 | **`PA7`** | **DIN（MOSI）** —— 高置信 | STM32F103 的 **SPI1_MOSI 就是 PA7** |
| 7 | `PB1` | CS / DC / RST 之一 | 无依据区分 |
| 8 | `PB3` | CS / DC / RST 之一 | 无依据区分 |
| 11 | `PB0` | CS / DC / RST 之一 | 无依据区分 |

> [!warning] 上一轮把「与微雪参考接线一致」当成线索，其实那个一致性另有解释
> 微雪的参考接线也是 `DIN = PA7 / CLK = PA5`。但这**不能推出本板照抄了微雪** ——
> 更简单的原因是两个设计者都直接用 STM32F103 **SPI1 的硬件固定引脚**（PA5 = SCK、PA7 = MOSI），
> 这样能用硬件 SPI 而不必软件模拟。
> 所以这条只能支撑「PA5/PA7 是 SCK/MOSI」，**推不出模组型号，也推不出剩下三根线谁是谁**。
> （注意 `PB3` 恰好是 SPI1_SCK 的**重映射**脚，但它没被用作 SCK —— 否则 SPI1 的引脚分配就不自洽了。）
>
> 要定案仍需**本模组的规格书**：需要的是 **12 脚 FPC 的脚位定义**，本页手上的 192 页 IC 手册给不了。
> 另一条可行路径：**从固件的 SPI 初始化代码反查**（哪个 GPIO 被配成 CS/DC/RST），比找手册更快。

## 5. 背光

`LEDK`（pin 2）接背光负极。[kig眼](../../kig眼.md) 上有一颗 `S8050_SOT_NPN`（Q1）—— ⚠️ 是否用于背光开关仍未确认（网表不含语义）。

> [!note] 本页的收获与边界
> **收获**：分辨率 240×240 确认、供电域与极限值齐全、接口能力明确、
> **PA5/PA7 = SPI1 的 SCK/MOSI 可以定案**（依据是 STM32F103 的硬件固定映射，不是模组）。
> **边界**：模组脚位这份 IC 手册解决不了 —— 也说明「有手册」不等于「所有问题都能答」。
> 剩下 3 根线的**最快解法不是找手册，是读固件**的 SPI 初始化代码。
