# QCA6410

Qualcomm Atheros HomePlug AV / IEEE 1901 MAC/PHY SoC 收发器。电力线通信 (PLC) 单芯片解决方案，集成 AFE、线路驱动、Ethernet PHY、ARM926 CPU。

## 规格

| 参数 | 数值 |
|------|------|
| 芯片 | Qualcomm Atheros QCA6410 |
| 功能 | HomePlug AV MAC/PHY Transceiver |
| 标准 | IEEE 1901, HomePlug AV, HomePlug Green PHY 互操作 |
| CPU | ARM926 (嵌入式) |
| PHY 速率 | 最高 200 Mbps |
| Ethernet | 集成 10/100 802.3az PHY |
| 模拟前端 | 集成 ADC/DAC、RX 放大器、TX 放大器、线路驱动 |
| 开关稳压器 | 集成 1.2V，仅需外部电感和电容 |
| 封装 | 68-pin QFN 8×8 mm |
| 供电 | 单 3.3V 轨（内部产生 1.2V、2.5V、2.0V） |
| 启动 | SPI Master Flash 或 Ethernet 主机下载 FW |
| 工作温度 | 0°C ~ +70°C（外壳温度 ≤115°C） |
| 订购编号 | QCA6410-AL3C |

## 电源管理

| 模式 | 功耗 | 唤醒源 | 说明 |
|------|------|--------|------|
| **Active** | ~2100mW TX / ~1100mW RX | — | 全功能，最大带宽 |
| **Standby** | >75% 省电 | Magic Packet、PLC 消息、GPIO、定时器 | PHY/MAC 间歇工作，响应时间受占空比影响 |
| **Sleep** | 低功耗 | 定时器、GPIO 输入跳变 | 时钟门控，SRAM 保持，PHY 关 |
| **Deep Sleep** | 最低功耗 | 定时器、GPIO 输入跳变 | 电源门控，仅 PMU+SRAM+部分 I/O 保持 |

> 1 秒内可从 Active 切换到 Standby/Idle。

## 启动方式

| 方式 | 条件 | 说明 |
|------|------|------|
| **SPI Flash 启动** | GPIO_0=高，NVM 存在 | RESET_L 释放后自动从 SPI Master 加载 FW |
| **Ethernet 主机下载** | SPI Flash 为空时自动 fallback | 通过集成 Ethernet 口接收 MME 命令包下载 FW |

## 应用电路要点

### 核心供电

- 内部 1.2V 开关稳压器仅需外部电感和电容组成 π 型滤波器
- 核心电压走线需 ≥4 个过孔（通流能力）
- 参考 PL22 参考设计 (60005310) 取值和布局

### 晶振电路

- 25MHz 晶振接 XTAL_IN/XTAL_OUT
- 微调电容标称 4.7pF，需根据实际 PCB 布局测量调整
- 外部时钟输入时 XTAL_IN 通过 0Ω 到 GND（关闭内部振荡器）

### 上电配置 Strap

| Strap | Pin | 功能 |
|-------|-----|------|
| Boot from NVM | GPIO_0 (60) | 高=从 SPI Flash 启动 |
| 用户 I/O | GPIO_1 (61) | 可用作 TX/RX 控制线 |
| 用户 I/O | GPIO_2/GPIO_3 (62/63) | 通用 |

> 建议所有 strap 引脚用 3K–10KΩ 电阻上拉/下拉，便于测试和调试。
