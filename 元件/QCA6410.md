# QCA6410

Qualcomm Atheros HomePlug AV / IEEE 1901 MAC/PHY SoC 收发器。电力线通信 (PLC) 单芯片解决方案，集成 AFE、线路驱动、Ethernet PHY、ARM926 CPU。

## 规格

| 参数 | 数值 |
|------|------|
| 芯片 | Qualcomm Atheros QCA6410 |
| 功能 | HomePlug AV MAC/PHY Transceiver |
| 标准 | IEEE 1901, HomePlug AV, HomePlug Green PHY 互操作 |
| CPU | ARM926 (嵌入式) |
| PHY 速率 | 最高 200 Mbps |
| Ethernet | 集成 10/100 802.3az PHY |
| 模拟前端 | 集成 ADC/DAC、RX 放大器、TX 放大器、线路驱动 |
| 开关稳压器 | 集成 1.2V，仅需外部电感和电容 |
| 封装 | 68-pin QFN 8×8 mm |
| 供电 | 单 3.3V 轨（内部产生 1.2V、2.5V、2.0V） |
| 启动 | SPI Master Flash 或 Ethernet 主机下载 FW |
| 工作温度 | 0°C ~ +70°C（外壳温度 ≤115°C） |
| 订购编号 | QCA6410-AL3C |

## 电源管理

| 模式 | 唤醒源 | 说明 |
|------|--------|------|
| **Active** | — | 全功能，TX 2100mW / RX 1100mW |
| **Standby** | Magic Packet、PLC 消息、GPIO、定时器 | >75% 省电 |
| **Sleep** | 定时器、GPIO | 时钟门控，SRAM 保持 |
| **Deep Sleep** | 定时器、GPIO | 电源门控，仅 PMU+SRAM 保持 |

## 启动方式

| 方式 | 条件 | 说明 |
|------|------|------|
| **SPI Flash 启动** | GPIO_0=高，NVM 存在 | RESET_L 释放后自动加载 FW |
| **Ethernet 主机下载** | SPI Flash 为空 | MME 命令包下载 FW |
