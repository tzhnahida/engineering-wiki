# STM32F103C8T6

> STMicroelectronics · Arm Cortex-M3 72 MHz · LQFP-48 · 64 KB Flash / 20 KB SRAM
> 低成本从节点主控；本库中另有 3 个老工程把它当作小系统主控。

**手册**：`F:\Projects\PCB\Library\Datasheet\Chip_Microcontroller_STM32F103x8xB.PDF`
ST **DS5319 Rev 20**（2025-07），114 页，覆盖 STM32F103x8（64 KB）/ xB（128 KB）。

> [!note] 页码约定
> 本页 `p.N` 一律指 **PDF 页码**，与手册印刷页码一致（PDF 第 1 页标注 `1/114`，部分页标注分母 115）。

## 1. 身份选型

订购型号解码（p104 Ordering information scheme）：

| 段 | 值 | 含义 |
|---|---|---|
| STM32 F 103 | — | Arm 32 位 / 通用型 / 性能线 |
| **C** | 48 pins | 引脚数（T=36 / C=48 / R=64 / V=100） |
| **8** | 64 KB | Flash（8=64KB / B=128KB。**CBT6 即 128 KB 版本**） |
| **T** | LQFP | 封装（T=LQFP / H=BGA / U=VFQFPN 或 UFQFPN） |
| **6** | −40 ~ +85 °C | 工业温度档（7 = −40 ~ +105 °C） |

`p10` Table 2（Cx 列）关键规格：

| 项目 | 值 |
|---|---|
| Flash / SRAM | 64 或 128 KB Flash；**20 KB SRAM** |
| GPIO | **37**（Tx / Cx / Rx / Vx = 26 / 37 / 51 / 80） |
| 12-bit ADC | 2 个，**10 通道** |
| 定时器 | 3 通用 + 1 高级 |
| SPI / I²C / USART | 2 / 2 / 3 |
| USB / CAN | 各 1 |
| CPU 频率 / 供电 | 72 MHz / 2.0 ~ 3.6 V |
| 工作温度 | 环境 −40 ~ +85 °C（6 档）/ −40 ~ +105 °C（7 档）；结温 −40 ~ +125 °C |
| 封装 | LQFP48 / UFQFPN48 |

`p1` 其他特性：ARM Cortex-M3 1.25 DMIPS/MHz（0 等待周期）、POR/PDR/PVD、4~16 MHz 晶振、内部 8 MHz RC、
内部 40 kHz RC、RTC 32 kHz 振荡器、Sleep/Stop/Standby 三种低功耗模式、7 通道 DMA、SWD + JTAG。

> [!warning] 与 [STM32F103RCT6](STM32F103RCT6.md) / [STM32F103ZET6](STM32F103ZET6.md) 的关键差别
> - **无 FSMC**（中容量系列，p1 特性表里根本没有这一项）
> - **无 DAC**
> - SRAM 只有 20 KB（RCT6 = 48 KB，ZET6 = 64 KB）
> - GPIO 37（RCT6 = 51，ZET6 = 112）
> - **pin 12 是 PA2**，而 LQFP-64 的 RCT6 在同一个位置是 VSSA —— 换封装必须重排引脚

|---|---|---|---|

`p41` Table 13 —— Run 模式**最大**值：72 MHz 全外设开启 **50.0 mA**（TA = 85 °C）/ 50.3 mA（TA = 105 °C）。

> [!warning] 本页旧版本的两处数值已更正
> - 旧写「**Sleep ~2mA**」——2.1 mA 是 **8 MHz** 下的值；72 MHz 全外设开启时是 **14.4 mA**（p48）。
>   跨频率套用同一数字会低估一个数量级。
> - 旧写「**Stop ~14µA**」——手册里 Stop 模式电流**只以曲线图给出**（p45 Figure 19 / Figure 20），
>   没有可引用的文本数值。该值已在正文移除，标为 ⚠️ 图片读取，见 §7。

## 7. 项目用途

### 7.1 动捕 CAN 集群从节点（既有）

| 位置 | 数量 | 职责 |
|---|---:|---|
| CAN 从节点 | 10 | SPI 读 ICM-42688-P + I²C 读 QMC5883P → CAN 上报主节点 |

每颗作为 CAN 集群从节点，仅做传感器采集和 CAN 上报，不跑姿态解算（Madgwick 由 ESP32-S3 主节点完成）。
典型连线：SPI1 = PA5/PA6/PA7，I²C1 = PB6/PB7，CAN = PA11/PA12，SWD = PA13/PA14（p10 Table 2 确认 Cx 档含 CAN 与 USB）。

### 7.2 嘉立创EDA 老工程（2026-09-30 补录）

| 工程 | 位号 | 用途 |
|---|---|---|
| [电机板](../../电机板.md) | U1 | L298N 双全桥电机驱动板主控 |
| Jlink-ob（未建档） | U1 | J-Link OB 调试器 |
| DAPlink_FPC（未建档） | U1 | DAPLink 调试器（Manufacturer Part 记为 **CBT6**，即 128 KB 版本） |

三块板共用同一套最小系统：AMS1117-3.3 + 8 MHz（或 12 MHz）晶振 + 1 M 起振电阻 + 20 p 负载电容 + 复位网络。
⚠️ 这是**图纸模板复用**，不代表三者是同一设计（连线与固件均不同）。
