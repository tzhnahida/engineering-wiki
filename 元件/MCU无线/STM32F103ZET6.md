# STM32F103ZET6

> STMicroelectronics · Arm Cortex-M3 72 MHz · LQFP-144 · 512 KB Flash / 64 KB SRAM · **带 FSMC**
> 本库中的**大容量主控**：2 个工程使用，一块外挂 SRAM，一块驱动 4 路电机接口。

**手册**：`F:\Projects\PCB\Library\Datasheet\Chip_Microcontroller_STM32F103xCDE.PDF`
ST **DS5792 Rev 13**（2018-07），143 页，覆盖 STM32F103xC / xD / xE（与 [STM32F103RCT6](STM32F103RCT6.md) 同一份）。

> [!note] 页码约定
> 本页 `p.N` 一律指 **PDF 页码**，与手册印刷页码一致（PDF 第 1 页标注 `1/143`）。

---

## 1. 身份选型

订购型号解码（p135, Table 75）：

| 段 | 值 | 含义 |
|---|---|---|
| STM32 F 103 | — | Arm 32 位 / 通用型 / 性能线 |
| **Z** | 144 pins | 引脚数（R=64 / V=100 / Z=144） |
| **E** | 512 KB | Flash 容量（C=256KB / D=384KB / E=512KB） |
| **T** | LQFP | 封装（T=LQFP / H=BGA / Y=WLCSP64） |
| **6** | −40 ~ +85 °C | 工业温度档（7 = −40 ~ +105 °C） |

`p11` Table 2（Zx 列）关键规格：

| 项目 | 值 |
|---|---|
| Flash / SRAM | 256 / 384 / **512** KB Flash；**48 KB（xC）/ 64 KB（xD、xE）SRAM** |
| **FSMC** | **Yes**（Rx = No，Vx = Yes） |
| GPIO | **112**（Rx / Vx / Zx = 51 / 80 / 112） |
| 12-bit ADC | 3 个，**21 通道** |
| 12-bit DAC | 2 通道 |
| 通用 / 高级 / 基本定时器 | 4 / 2 / 2 |
| SPI（可作 I2S） / I²C / USART | 3 / 2 / 5 |
| USB / CAN / SDIO | 各 1 |
| CPU 频率 / 供电 | 72 MHz / 2.0 ~ 3.6 V |
| 工作温度 | −40 ~ +85 °C（6 档）/ −40 ~ +105 °C（7 档） |

> [!tip] `E` 档才同时拿到「512 KB Flash + 64 KB SRAM + FSMC + 112 GPIO」
> 这是本库选它做 [通讯处理板](../../通讯处理板.md) 主控的原因 —— [STM32F103RCT6](STM32F103RCT6.md) 的 R 封装**没有 FSMC**，挂不了并行 SRAM。

## 7. 项目用量与用法（网表）

| 工程 | 位号 | 该板规模 | 特殊外设 |
|---|---|---|---|
| [通讯处理板](../../通讯处理板.md) | U1 | 113 元件 / 146 网络 | **IS62WV51216BLL 512K×16 SRAM**（接 FSMC） |

两块板的引脚分配**逐条一致**：

| 引脚 | 网络 | 外围 | 说明 |
|---|---|---|---|
| 23 | `OSC_IN` | 8 MHz X1 + R1 + C9/C10 | 主晶振 |
| 24 | `OSC_OUT` | 同上 | |
| 25 | `NRST` | R2 上拉 + C11 + KEY2 | 复位 |
| 6 | `VBAT` | C35 + BAT54C(D2) | 后备域（**经肖特基从主 3.3V 取电**） |
| 47 | `PB1` | KEY1 + R4 | 用户按键 |
| 41 / 42 / 43 | `PA5` / `PA6` / `PA7` | 多路端口复用 | |
| 74 / 75 / 76 | `PB13` / `PB14` / `PB15` | 多路端口复用 | |
| 133 / 134 / 135 | `PB3` / `PB4` / `PB5` | 多路端口复用 | |

> [!note] `VBAT` 用 BAT54C 肖特基从主电源取电
> 两块板一致：`VBAT: C35-x, D2-3(BAT54C), U1-6`。
> 这是「主电在时由 3.3V 经肖特基给 VBAT 供电」的经典写法 —— 手册 p44 给出 VBAT 工作范围 **1.8 ~ 3.6 V**，
> 3.3 V 经肖特基压降后仍在范围内。
> 对照：[电机板](../../电机板.md) 的 STM32F103C8T6 在网络表里 **VBAT 引脚完全未连接**（见 [电机板](../../电机板.md) §设计状态）。

### 7.1 端口复用拓扑（两块板同源）

同一条三线信号挂多个并联端口：

| 工程 | 信号组 | 每组挂载端口数 | 组数 |
|---|---|---|---:|---:|
| [通讯处理板](../../通讯处理板.md) | `PA5/6/7`、`PB13/14/15` | 6 个 8P 座 | 2 |
| [通讯处理板](../../通讯处理板.md) | `PB3/4/5` | 3 个 8P 座 | 1 |
| [电机控制板](../../电机控制板.md) | `PA5/6/7`、`PB13/14/15`、`PB3/4/5` | 3 个 8P 座 | 3 |

> ⚠️ 「三线 = 编码器 / 霍尔 / 分时选通」是**推测**。网表中这三个信号各自扇出到多个连接器，
> 但**没有发现独立的片选或使能网络**，选通机制需回原理图确认。

### 7.2 FSMC 外部总线（仅 [通讯处理板](../../通讯处理板.md)）

该板挂了一颗 `IS62WV51216BLL-55TLI-TR`（TSOP-II-44，512K×16 = 1 MB 异步 SRAM），
与主控之间有大量并行连线（该板 146 条网络，自动命名 25 条）。

- ✅ **本型号 FSMC 可用**（p11 Table 2：Zx = Yes）
- ⚠️ IS62WV51216 时序参数本地无手册，未写
- ⚠️ 具体地址/数据线映射需回原理图确认
