# 2026-07-26 - cJSON 源码分析

> **仓库**: https://github.com/DaveGamble/cJSON
> **本地**: `_llm/raw/repos/cJSON/`
> **协议**: MIT | **版本**: 1.7.19

## 概述

cJSON 是 Dave Gamble 开发的超轻量 JSON 解析/渲染库，ANSI C (C89)，仅两个文件（`cJSON.h` + `cJSON.c`，~3200 行）。零外部依赖。

## 核心设计

- **树形结构**：cJSON 节点通过 `child`/`next`/`prev` 构成双向链表树，对应 JSON 的嵌套结构
- **递归下降解析**：`parse_value()` 根据首字符分发到 `parse_string/number/array/object`
- **位掩码类型**：类型常量是位掩码（`cJSON_Number=8`, `cJSON_String=16`），可与标志位组合（`cJSON_IsReference=256`, `cJSON_StringIsConst=512`）
- **借用 vs 拥有**：支持引用字符串（不拷贝，不释放）和常量 key，节省内存拷贝

## 嵌入式适用性
