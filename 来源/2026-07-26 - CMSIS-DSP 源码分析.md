# 2026-07-26 - CMSIS-DSP 源码分析

> **仓库**: https://github.com/ARM-software/CMSIS-DSP
> **本地**: `_llm/raw/repos/CMSIS-DSP/`
> **协议**: Apache 2.0 | **版本**: V1.10.1 | **开发**: Arm Limited

## 概述

CMSIS-DSP 是 Arm 官方优化的嵌入式计算库。覆盖 17 个函数类别，支持 f64/f32/f16/q31/q15/q7 七种数据类型，Cortex-M4/M7 SIMD + Cortex-M55/M85 Helium + Cortex-A Neon 三级加速。

## 函数类别总览

| 类别 | 主要内容 | 姿态解算相关 |
|------|---------|-------------|
| Basic Math | 向量加减乘除、点积、绝对值 | ✅ |
| Fast Math | sin/cos/sqrt/atan2 快速近似 | ✅ 核心 |
| Complex Math | 复向量运算、幅值、共轭 | ✅ FFT 前处理 |
| Filtering | FIR/IIR/双二阶/LMS/卷积/相关 | — |
| Matrix | 乘加逆/Cholesky/QR/LU/转置 | ✅ EKF |
| Transform | CFFT/RFFT/DCT/MFCC | ✅ 频域分析 |
| Statistics | 均值/方差/RMS/功率/熵/最大最小值 | — |
| Controller | PID + Clarke/Park 变换 | ✅ 电机控制 |
| Quaternion | 四元数乘法/归一化/旋转矩阵转换 | ✅ **核心！** |
| Distance | 欧几里得/余弦/DTW/布尔距离等 | — |
| SVM/Bayes | 二分类 SVM + 朴素贝叶斯 | — |
| Window | 22 种窗函数生成 (Hanning→HFT248dB) | ✅ FFT 预处理 |
| Interpolation | 线性/双线性/三次样条 | — |
