## 文档概述

MQTT (Message Queuing Telemetry Transport) 是 OASIS 标准化的轻量级发布/订阅消息传输协议，专为受限设备和低带宽、高延迟或不可靠网络设计。3.1.1 是应用最广泛的版本；5.0 引入了会话过期、共享订阅、消息过期、原因码等增强特性。

## 关键知识点

### MQTT 3.1.1
- 发布/订阅模型：Broker 中介，Topic 路由，QoS 0/1/2 三级
- 保活机制 (Keep Alive)，遗嘱消息 (Last Will & Testament)
- CONNECT/CONNACK → PUBLISH/PUBACK/PUBREC/PUBREL/PUBCOMP → SUBSCRIBE/SUBACK → UNSUBSCRIBE/UNSUBACK → PINGREQ/PINGRESP → DISCONNECT
- QoS 2 四步握手确保 exactly-once 送达
- MQTT 控制报文编码：Fixed Header + Variable Header + Payload

### MQTT 5.0 新增
- **会话过期** (Session Expiry Interval)：替代 Clean Session 布尔值
- **消息过期** (Message Expiry Interval)：发布者可设消息 TTL
- **共享订阅** (Shared Subscriptions)：`$share/{group}/{topic}` 负载均衡
- **原因码** (Reason Code)：所有 ACK 报文中返回操作结果
- **用户属性** (User Properties)：任意 key-value 元数据
- **载荷格式指示** (Payload Format Indicator)：区分二进制与 UTF-8
- **请求/响应** (Request/Response)：Response Topic + Correlation Data
- **AUTH 报文**：增强认证支持 (SCRAM-SHA-256 等)
