# mbedTLS 源码分析

## 基本信息

| 项目 | 内容 |
|------|------|
| **名称** | Mbed TLS |
| **仓库** | `Mbed-TLS/mbedtls` (GitHub) |
| **分支** | `development` (4.x 预发布) |
| **语言** | C99 |
| **许可** | Apache 2.0 / GPL 2.0 双许可 |
| **定位** | 嵌入式 TLS/DTLS 协议栈 + X.509 证书管理 + PSA 密码学 API |

## 架构概览

mbedTLS 4.x 构建为三个独立库：

| 库 | 目录 | 文件数 | 职责 |
|----|------|--------|------|
| `libtfpsacrypto` | `tf-psa-crypto/` (子模块) | 45 .c + ~60 .h | PSA Crypto API 实现：AES/SHA/RSA/ECC/ChaCha20/GCM 等全系列密码学原语 |
| `libmbedx509` | `library/x509*.c` | 10 .c | X.509 证书解析/创建/CSR/CRL/信任链验证 |
| `libmbedtls` | `library/ssl*.c` | 20 .c | TLS 1.2/1.3、DTLS、记录层、握手状态机 |

**链接顺序**：`-lmbedtls -lmbedx509 -ltfpsacrypto`（GNU ld 需要此顺序）。

核心源码 ~38K 行（不含测试和框架）。

## 编译配置

所有配置通过 `include/mbedtls/mbedtls_config.h`（TLS/X.509）和 `tf-psa-crypto/include/psa/crypto_config.h`（密码学）控制。配置脚本 `scripts/config.py` 支持程序化修改。

预设配置在 `configs/` 目录，如 `config-thread.h`、`config-ccm-psk-tls1_2.h` 等极小化配置。

## 分析方法

1. 通过 `gh repo clone Mbed-TLS/mbedtls -- --depth 1` 获取源码（含 `--recurse-submodules`）
2. 逐头文件分析 API 接口设计
3. 关键实现文件（ssl_tls.c、psa_crypto.c、aes.c 等）逐模块阅读
4. 与 LWIP/FreeRTOS 风格对比嵌入式 C 设计模式
