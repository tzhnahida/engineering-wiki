## 文档概述

2026 年嵌入式工程师的 8 大核心技术领域全景：硬件与电子基础、MCU 与外设、有线/无线通信协议、编程语言与 OS（C/C++/Rust → RTOS/Linux）、软件架构与设计模式（HSM/事件驱动/HAL）、工具链与 DevOps（CMake/Docker/CI-CD/HIL）、安全与功能安全标准（ISO 26262/IEC 62304/MISRA）、新兴领域（Edge AI/TinyML/FOC/RISC-V）。

## 关键知识点

- "Hardware Fluent" — 嵌入式软件工程师必须能阅读原理图和理解信号完整性
- 从 IDE "Play" 到 CMake + Ninja + Docker + CI/CD 的工程化转型
- 安全不再是可选 — Secure Boot + OTA anti-rollback + 行业合规是法律要求
- 顶级薪资方向: Edge AI (TinyML) + FOC 电机控制 + 传感器融合 (Kalman)
- C 仍是主导但 Rust 在安全关键领域快速增长; Zephyr 正在取代 FreeRTOS 成为工业 RTOS 首选
