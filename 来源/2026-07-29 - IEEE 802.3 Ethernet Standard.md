## 文档概述

IEEE 802.3 是 Ethernet 局域网的国际标准，定义了 OSI 模型中物理层 (PHY) 和数据链路层 (MAC) 的完整规范。802.3-2022 是当前基础版本，涵盖 1 Mb/s 至 400 Gb/s 的所有 Ethernet 速率和介质类型（同轴、双绞线、光纤、背板），以及 PoE (Power over Ethernet)。

## 关键知识点

- **MAC 层**：CSMA/CD (半双工)、全双工操作、MAC 帧格式 (DA/SA/EtherType/Payload/FCS)
- **PHY 层**：MII/GMII/XGMII 接口、PCS/PMA/PMD 子层、自协商 (Auto-Negotiation)
- **帧结构**：Preamble (7B) + SFD (1B) + DA (6B) + SA (6B) + EtherType/Length (2B) + Payload (46-1500B) + FCS (4B)
- **速率演进**：10M → 100M → 1G → 10G → 25G → 40G → 100G → 200G → 400G
- **PoE**：802.3af (15.4W) → 802.3at (30W) → 802.3bt (60W/100W)
- **介质类型**：10BASE-T/100BASE-TX/1000BASE-T (双绞线)、1000BASE-SX/LX (光纤)、10GBASE-KR (背板)
