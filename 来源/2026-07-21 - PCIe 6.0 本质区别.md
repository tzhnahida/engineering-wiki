# PCIe 6.0 与 PCIe 5.0 的本质区别

> 来源：微信公众号「Vector 信号完整性和电源完整性」，2026-07-21 抓取

## 概述

PCIe 6.0（64 GT/s）不只是 PCIe 5.0（32 GT/s）的速度翻倍。真正的本质变化是从传统 NRZ 高速串行链路进入了 **PAM4 + FLIT + FEC** 的新体系——连"道路规则、信号灯、纠错机制和测试方法"都一起换了。

## 核心洞见

**PCIe 5.0 仍是"尽量让模拟波形足够干净"的时代；PCIe 6.0 进入"波形天然更脆弱，但用编码和纠错把系统拉回来"的时代。**

## NRZ vs PAM4

| | NRZ（PCIe 5.0） | PAM4（PCIe 6.0） |
|---|---|---|
| 电平数 | 2（高/低） | 4（00/01/10/11） |
| 每符号比特 | 1 bit | 2 bit |
| 噪声裕量 | 大 | 小（3 个小眼睛） |
| 判决复杂度 | 简单 | 高（需区分四个电平） |

**比喻**：NRZ 是两层楼，站在哪层很清楚；PAM4 是四层楼，楼间距更近，地板一晃就容易认错。

## FEC + CRC + FLIT

- **FEC（前向纠错）**：在数据层加冗余，接收端发现有限错误时自行修正，不必立刻请求重传
- **CRC**：兜底检测——FEC 修小错，CRC 发现修不了的大错
- **FLIT**：固定大小传输单元，让 FEC/CRC 在规则数据块上高效运行

## 对 SI/PI 测试的影响

1. **眼图不能只看传统方式**——PAM4 有三个眼，还要看 RLM、SNDR、电平线性度
2. **BER 不再直接反映物理层干净程度**——FEC 在中间隔了一层
3. **Debug 指标扩展到系统级**——FLIT 错误、FEC correction count、uncorrectable error、重训练行为
4. **PI 更敏感**——PAM4 电平间距小，电源噪声更容易压缩判决窗口
