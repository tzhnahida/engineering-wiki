## 概述

LittleFS 是 ARM Mbed 团队为 NOR Flash 设计的现代嵌入式文件系统。核心特性：断电安全（任何时刻断电不损坏）、内置磨损均衡、有界 RAM（不随存储容量增长）。

## 核心设计

| 特性 | 描述 |
|------|------|
| **元数据对** | 每个目录由两个 Flash 块组成，通过修订号 + CRC 实现原子提交 |
| **CTZ skip-list** | 文件数据用 Copy-on-Write Tail-Zip skip-list 存储，O(log n) 随机访问 |
| **CObW** | 有界写时复制 — COW 连锁最多影响一个元数据对 |
| **前瞻缓冲区** | 固定大小位图跟踪空闲块 — O(1) 空间，O(n) 扫描 |

## 与 FatFS 对比

| 维度 | LittleFS | FatFS |
|------|----------|-------|
| 目标介质 | NOR Flash | 块设备 (SD/eMMC) |
| 断电安全 | 是（原生） | 否（需外部日志） |
| 磨损均衡 | 内置动态 | 需外部层 |
| PC 兼容 | 否 | 是 (FAT) |
| RAM 消耗 | ~400+ 字节 | ~4+ KB |
