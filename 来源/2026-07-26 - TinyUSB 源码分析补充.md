# TinyUSB 源码分析

## 基本信息

| 项目 | 内容 |
|------|------|
| **名称** | TinyUSB |
| **仓库** | `hathach/tinyusb` (GitHub) |
| **语言** | C99 |
| **许可** | MIT |
| **定位** | 跨平台嵌入式 USB Host/Device 双栈，零动态分配，线程安全 |

## 源码组织

```
src/
├── tusb.c/h              # 核心入口（551 行）
│   ├── #if CFG_TUD_ENABLED → 包含 device/usbd.h + class drivers
│   └── #if CFG_TUH_ENABLED → 包含 host/usbh.h + host class drivers
├── device/
│   ├── usbd.c            # USBD 设备核心（1,762 行）
│   ├── usbd.h            # 公共 API（tud_* 函数族）
│   └── dcd.h             # DCD 设备控制器驱动接口
├── host/
│   └── usbh.c/h          # USBH 主机核心
├── class/                # USB 类驱动（设备+主机）
│   ├── cdc/cdc_device.c  # CDC ACM（515 行）
│   ├── hid/hid_device.c  # HID
│   ├── msc/msc_device.c  # MSC 大容量存储
│   ├── dfu/dfu_device.c  # DFU 固件升级
│   ├── audio/            # USB Audio
│   ├── midi/             # MIDI
│   ├── net/              # RNDIS/ECM
│   └── video/            # UVC
├── portable/             # DCD/HCD 控制器驱动（~20 MCU 平台）
│   ├── synopsys/dwc2/    # STM32, RP2040, ESP32-S2/S3
│   ├── nxp/              # NXP LPC, i.MX RT
│   ├── microchip/        # SAMD, SAME
│   ├── raspberrypi/      # RP2040 PIO
│   ├── st/               # STM32F1/F4
│   └── ... 15+ 其他平台
├── common/               # 共享工具（FIFO, 描述符解析）
├── osal/                 # OS 抽象层（裸机/FreeRTOS/RT-Thread/Mynewt）
└── typec/                # USB Type-C PD 栈
```

## 架构关键设计

1. **条件编译头聚合**：`tusb.h` 是整个栈的唯一入口——根据 `CFG_TUD_*`/`CFG_TUH_*` 配置选择包含设备/主机/类驱动头文件
2. **DCD 抽象**：`dcd.h` 定义统一接口（`dcd_init`, `dcd_edpt_open`, `dcd_edpt_xfer` 等），各 MCU 的 `portable/` 目录实现具体驱动
3. **OSAL 层**：`osal/osal.h` 提供互斥锁、信号量、队列的跨 RTOS 抽象
4. **弱回调链**：`tud_mount_cb()`, `tud_umount_cb()`, `tud_suspend_cb()` 等使用 `TU_ATTR_WEAK`，用户选择性覆盖
