## 概述

TinyUSB 是面向嵌入式系统的开源跨平台 USB 协议栈，同时支持设备模式（Device）和主机模式（Host）。架构清晰分层：DCD/HCD → USBD/USBH → Class Drivers → Application。

## 核心模块

| 模块 | 路径 | 功能 |
|------|------|------|
| DCD (设备控制器驱动) | `src/portable/*/dcd_*.c` | 硬件 USB 外设抽象 |
| USBD (设备核心) | `src/device/usbd.c` | USB Ch.9 设备框架 + 控制传输 |
| Class Drivers | `src/class/*/` | CDC/MSC/HID/DFU/Audio/MIDI 类驱动 |
| OSAL | `src/osal/` | FreeRTOS/RT-Thread/none 操作系统抽象 |

## 关键设计模式

1. **编译时描述符**：`TUD_CONFIG_DESCRIPTOR` 宏在编译时构造完整 USB 描述符 — 零运行时开销
2. **延迟中断模型**：ISR 仅捕获事件 → 队列 → `tud_task()` 上下文处理
3. **`usbd_class_driver_t` 统一接口**：所有类驱动通过同一个虚函数表注册
4. **端点 FIFO 管理**：通过端点编号方案抽象不同 MCU 的硬件端点
