# 2026-07-26 - FlashDB 源码分析

> **仓库**: https://github.com/armink/FlashDB
> **本地**: `_llm/raw/repos/FlashDB/`
> **协议**: Apache 2.0 | **版本**: 2.2.99 | **作者**: armink

## 概述

FlashDB 是超轻量嵌入式数据库，提供两种模式：**KVDB**（键值数据库）用于配置参数，**TSDB**（时序数据库）用于传感器日志。依赖 FAL（Flash Abstraction Layer）或文件模式。

资源占用：~6.4KB ROM + ~1.8KB RO Data + 2 bytes RW。

## 核心设计

1. **扇区管理**：数据以固定扇区为单位，每个扇区带状态表头部（magic `FDB0`/`TSL0`）
2. **状态表递增写入**：通过逐位/逐字节写入实现状态转换（UNUSED→EMPTY→USING→FULL），天然支持掉电恢复
3. **CRC32 完整性**：每个 KV 节点携带 CRC32
4. **扇区 GC**：KVDB 在空闲扇区不足时，移动存活 KV 并擦除脏扇区
5. **双向布局（TSDB）**：索引从扇区顶向下增长，数据从底向上增长

## 掉电保护机制

- 状态表逐位写入 → 中断后读到中间状态，可恢复
- KV 两阶段删除：PRE_DELETE → DELETED
- KV 两阶段写入：PRE_WRITE → WRITE
- TSDB 双 end_info 冗余
