# FreeRTOS 内核全景概述

> 来源：微信公众号「杨工的碎碎念」，2026-07-23 抓取

## 概述

本文是 FreeRTOS Kernel V10.4.6 的全景架构概述，覆盖任务、调度器、队列、信号量、互斥锁、任务通知、事件组、软件定时器、流缓冲区、消息缓冲区、内存管理、Tick 与上下文切换。适合作为 FreeRTOS 系统学习的入口地图。

## 核心框架

> 任务承载业务，调度器分配 CPU，内核对象管理任务之间的数据、事件和资源，移植层连接具体处理器，内存管理为所有对象提供空间。

### 内核组件全景
- **任务管理**：任务函数、独立栈、TCB、优先级、状态
- **调度器**：基于优先级的抢占式调度 + 同优先级时间片轮转
- **Tick**：周期性硬件定时器中断，时间基准 + 延时到期检查
- **队列**：任务间/中断与任务间传递固定大小数据，附带阻塞与唤醒
- **信号量**：二值（事件通知）、计数（资源累计）
- **互斥锁**：共享资源保护，含优先级继承
- **任务通知**：任务自带的轻量级信号/邮箱，比队列更快更省 RAM
- **事件组**：多位条件等待（任意/全部）
- **软件定时器**：单次/周期回调，在定时器服务任务中执行
- **流缓冲区/消息缓冲区**：连续字节流 vs 保留消息边界
- **内存管理**：动态（heap_1~5）vs 静态创建

### 四种任务状态
```
运行态 → 就绪态 → 阻塞态（等待条件，自动恢复）
                 → 挂起态（需显式恢复）
```

### 内核对象的统一原理
> 所有内核对象都在做同一件事：条件不满足时让任务阻塞，条件满足后唤醒合适的任务。FreeRTOS 用链表统一管理就绪/延时/等待/挂起任务。

### 选型速查
| 需求 | 优先考虑 |
|------|----------|
| 传递固定大小数据 | 队列 |
| ISR 唤醒单个任务 | 任务通知或二值信号量 |
| 累计事件次数 | 计数信号量 |
| 保护共享资源 | 互斥锁 |
| 等待多个状态位 | 事件组 |
| 延时执行低频动作 | 软件定时器 |
| 连续字节流 | 流缓冲区 |
| 变长消息 | 消息缓冲区 |
