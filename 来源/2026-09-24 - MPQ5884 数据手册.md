## 熔断保护公式（A 级）

| 式号 | 内容 | 页码 |
|------|------|------|
| (2) | $V_{CS} = I_{CS} \times R_{CS} = K_{CS} \times I_{OUT} \times R_{CS}$ | p.17 |
| (3) | $I_{FUSE\_CL}(A) = \dfrac{V_{ILIM}}{K_{CS} \times R_{CS}(\Omega)}$ | p.17 |
| (4) | $\Delta I_{OUT} = I_{OUT} - I_{FUSE\_CL}$ | p.17 |
| (5) | $t_{FUSE}(s) = C_{FUSE}(nF) \times (0.2 - \Delta I_{OUT}(A) \times 0.128)$，$\Delta I_{OUT} < 1.5A$ | p.18 |
| (6) | $t_{FUSE}(s) = C_{FUSE}(nF) \times 0.067 \times \Delta I_{OUT}(A)^{-3.2}$，$1.5A < \Delta I_{OUT} < 8A$ | p.18 |
| (7) | $I_{FUSE-}(\mu A) = 64.7 \times (1 - I_{OUT}/I_{FUSE\_CL})(A) + 9\mu A$，**最大 40 μA** | p.18 |

**手册自述的端点值（可作独立校核）**：$C_{FUSE} = 100nF$、熔断限流 15A 时，**最长关断时间约 15s，最短约 10ms**（p.18，配图 Figure 4）。

> [!note] 用端点值反查式(6) —— 自洽
> $100nF$、$\Delta I_{OUT} = 8A$ 代入式(6)：$100 \times 0.067 \times 8^{-3.2} = 8.6\,ms$，与手册自述「最短约 10ms」吻合。

## 保护与诊断功能

| 功能 | 说明 | 页码 |
|------|------|------|
| 熔断式过流保护（OCP） | 可配置，模拟传统熔断器反时限特性；**触发后不立即关断**，电流越大关断越快 | p.17 |
| 快速关断短路保护（SCP） | 独立于熔断计时通道 | p.17 |
| 计数器机制 | $V_{FUSE}$ 在上下跳变阈值间充放电，每完成一次计数 +1；**累计 32 次则关断并拉低 FLT#** | p.18 |
| 计数器回退 | $I_{OUT}$ 回落到 $I_{FUSE\_CL}$ 以下时计数 −1，直至 0 | p.18 |
| 开路负载检测（OLD） | EN 为低、OLD 拉高时检测；输出超过 $V_{OLD\_TH}$ 则 FLT# 拉低 | p.17 |
| 电流监测（CS） | 正常模式下使能 | p.17 |
| 低 IQ 模式 / 关断模式 | 见 Figure 3；低 IQ 需 EN 与 OLD 协同 | p.17 |
| 反向电池 / 反向负载保护 | MOSFET 在反向 VIN 下导通，获得与正向相同的通流能力 | p.1 |
| 瞬态耐受 | 配双向 TVS 可通过 ISO 7637-2、ISO 16750-2、ISO 21780；符合 AEC-Q100-012 Test Grade A | p.1 |
| 功能安全 | MPSafe™ 支持文档可用 | p.1 |
