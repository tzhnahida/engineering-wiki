## 文档概述

一篇面向 MCU 工程师的 Embassy 框架介绍文。以「RTOS 任务栈拍脑袋——给大了 RAM 吃紧、给小了 HardFault 还不复现」的痛点为引，介绍 Rust async 嵌入式框架 Embassy（EMBedded ASYnc，2020 年开源，MIT/Apache-2.0 双许可）：任务在编译期变成状态机、运行时单栈、无内核调度。涵盖：生态版图（embassy-stm32/nrf/rp、TI MSPM0、NXP MCX-A、esp-rs、CH32/PY32 社区 HAL、embassy-net/usb/boot/time、trouble BLE）、与 FreeRTOS 的 F446 实测对比（Tweede golf 2022）、三步上手（probe-rs）、适用边界（C 资产/认证/硬实时/团队）、FAQ（学多少 Rust、FFI 混 C、调试、商用）。

## 关键知识点

- **定位** — 不是跑在 RTOS 上的库，而是顶掉 RTOS 的位置：调度交给 async executor，外设走自家 HAL；GitHub 9.7k+ Star（2026-08），主仓 1.6 万+ 提交
- **编译期状态机** — Rust async 函数被编译器编成状态机：每个 await 是一次状态转移；executor 只 poll 被中断唤醒的任务；任务静态分配、无需堆、无 malloc 碎片
- **单栈 vs 每任务栈** — RTOS 每任务一条私有栈，切换保存/恢复整套寄存器；Embassy 任务只保存「跨 await 存活的变量」，所有任务共用一条主栈；「任务栈溢出」从根上消失
- **低功耗白送** — executor 没活干时核心进 WFI，中断来才醒，不做空转轮询
- **F446 实测（2022 Tweede golf，按键+串口 demo，180MHz）**：
  - 中断处理耗时 2.96→1.45μs（快 51%）；中断延迟 4.97→3.74μs（低 25%）
  - .text 20.7→14.3KB（小 31%）；静态 RAM .data+.bss 5480→872B（省 84%）
  - **但**：单看上下文切换，FreeRTOS 反而更快（2.01 vs 2.29μs）；demo 级测试，只当方向参考
- **协作式语义** — 同一 executor 内一个任务闷头算 10ms 不 await，其他任务干等 10ms；要抢占需多个 executor 挂不同中断优先级（官方 multiprio 例子）
- **上手** — probe-rs（ST-Link/J-Link/DAPLink 全认）+ cargo run；保证最新 stable Rust 编译（「必须 nightly」是老黄历）；Cargo.toml 芯片 feature 必须改成具体型号
- **调试** — probe-rs + defmt，走 RTT 打日志，无 Keil 式全家桶
- **适用边界** — C 资产厚（FFI 成本不低）、功能安全认证（车规/医疗无成熟认证路径）、硬实时卡死、团队不会 Rust 且临近交付、芯片无官方 HAL
- **FAQ** — 先学所有权/借用/async 三件套，建议电脑上练一两周；FFI 调 C 库是常规操作（unsafe 边界自守）；MIT/Apache-2.0 免费商用，改了不强制开源

## 源码核对（2026-09-11）

对 embassy 仓库（浅克隆 HEAD `bd35bd7`）核对文章机制性声明：

- ✅ 任务静态分配：`#[embassy_executor::task]` → `static POOL: TaskPool`（task.rs:211）；`TaskStorage` 内 `future: UninitCell<F>` 只存编译出的状态机（raw/mod.rs:221-224）
- ✅ 单栈主循环：线程 executor 是普通 `loop { poll; wfe }`（cortex_m.rs:107-117），无栈切换
- ✅ Waker = 任务指针，`wake` 直通 `wake_task`（waker.rs:5-21）
- ✅ Timer 登记全局 time driver：`schedule_wake(ticks, waker)`（timer.rs:306-310），任务不占硬件定时器
- ✅ multiprio 抢占设计：InterruptExecutor 文档（cortex_m.rs:134-147）与官方 multiprio 例子头注释完全一致
- ⚠️ 一处不精确：文章「核心进 WFI 睡觉」——Cortex-M 平台实际用 **WFE+SEV**（pender 发 `sev`），RISC-V 平台才是 `wfi`（riscv.rs:82）；功能等价
- 另见源码注释细节：TaskStorage 的 poll_fn 惰性初始化使静态任务落在 .bss（raw/mod.rs:240-241），佐证静态 RAM 实测仅 872B
