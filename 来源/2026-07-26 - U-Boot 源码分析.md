## 概述

U-Boot 是嵌入式 Linux 系统的标准引导加载器。从 SoC ROM 代码到 Linux 内核之间，经历 SPL → U-Boot proper → Kernel 三个阶段。核心机制包括代码重定位、Driver Model、设备树修复、Falcon 快速启动。

## 核心模块

| 模块 | 文件 | 功能 |
|------|------|------|
| SPL | `common/spl/` | 最小化一级加载器，DDR 训练 |
| 初始化序列 | `common/board_f.c` + `board_r.c` | 前/后重定位初始化 |
| Driver Model | `drivers/core/` | udevice/driver/uclass 三元组 |
| 命令框架 | `cmd/` | `U_BOOT_CMD` 链接器段注册 |
| 网络子系统 | `net/` | 单线程轮询，TFTP/DHCP/NFS |
| 文件系统 | `fs/` | FAT/ext4/SquashFS/UBIFS |

## 关键设计模式

1. **代码重定位**：U-Boot 将自己从 Flash 拷贝到 RAM，通过 ELF 重定位表修正 GOT
2. **链接器段注册**：命令/驱动通过 `__attribute__((section(".u_boot_list")))` 自动聚合
3. **gd_t 全局上下文**：ARM 上通过 r9/r18 寄存器保持，无需内存加载
4. **SPL 条件编译**：同一源文件 `#ifdef CONFIG_SPL_BUILD` 产生两个不同二进制
