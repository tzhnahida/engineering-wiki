## 文档概述

USB 2.0 是通用串行总线的第二代规范，定义了三档速率 (LS/FS/HS)、四种传输类型、设备枚举流程、描述符体系、集线器架构和电气规范。是嵌入式开发中最常用的 USB 版本。随附包还包含 OTG 补充规范、Micro-USB ECN、HSIC 互连芯片标准、Link Power Management 等数十个工程变更通知 (ECN)。

## 关键知识点

- **三层速率**：Low Speed (1.5 Mbps)、Full Speed (12 Mbps)、High Speed (480 Mbps)
- **拓扑结构**：Tiered Star — Host → Hub → Device，最多 7 层、127 设备
- **四种传输类型**：Control (枚举/配置)、Bulk (大量数据)、Interrupt (定时轮询)、Isochronous (实时流)
- **设备枚举流程**：Reset → Address Assignment → Get Descriptors → Set Configuration
- **描述符层级**：Device → Configuration → Interface → Endpoint
- **端点数**：双向 16 个端点 (EP0 双向控制 + EP1-15 IN/OUT 单向)
- **帧结构**：1ms 帧 (FS/LS) / 125µs 微帧 (HS)，SOF 同步
- **NRZI 编码 + Bit Stuffing**：物理层编码
- **OTG (On-The-Go)**：双角色设备，Host Negotiation Protocol (HNP), Session Request Protocol (SRP)
- **LPM (Link Power Management)**：细粒度链路功耗管理
