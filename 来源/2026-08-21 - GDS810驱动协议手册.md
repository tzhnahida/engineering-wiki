# 2026-08-21 - GDS810 驱动协议手册

江西伺泰威自动化设备有限公司(SteadyWin®)GIM 系列电驱接口协议手册 rev2.2(中/英),含 SDC10X/SDC103 变体手册与官方 SDK(motctrl_arduino / CAN_Loop / STM32_CAN_Example)。

## 关键协议要点

- **CAN 硬件参数**:波特率 ≤ 1 Mbps、标准帧、DLC 8 字节、LSB(手册表 1/表 2)
- **命令字**(表 4):`0x91` 启动 / `0x92` 停止电机 / `0x93` 力矩 / `0x94` 速度(RPM float32 + duration uint24)/ `0x95` 位置 / `0x97` 中止控制 / `0xB1` 版本 / `0xB2` 获取异常 / `0xB3` 消除异常 / `0xB4` 获取指标
- **配置项**(表 7):`0x12` CAN ID、**`0x13` 上位机 CAN ID(回帧的目的 ID,默认 0x000)**、`0x18` CAN 波特率、`0x1C` CAN 协议(0 = SteadyWin GIM / 1 = MIT)
- **回帧格式**:BYTE0 = 命令回显,BYTE1 = RES(0x00 成功;0x01 失败;0x03 未知 ID);0x93/0x94/0x95 回帧还带 Temp/Pos/ST 反馈(3.2.7~3.2.9)
- **异常锁死**:`异常未消除时电机会拒绝响应一切指令`(3.2.16),异常码 0x02 过压 / 0x04 欠压 / 0x08 过温 / 0x10 启动失败 / 0x40 过流 / 0x80 软件异常(表 9)
- **速度控制时长语义**:duration 为执行时长,到期后电机不自动停机,需 `0x97`+`0x92` 显式停止(工程实测确认)
