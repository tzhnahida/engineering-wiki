# 把 CPU 和 FPGA 放进同一颗芯片

> 来源：微信公众号「软硬件之间」第 02 篇，2026-07-22 抓取

## 概述

本文介绍 SoC FPGA 的系统架构设计思想——不是简单的"CPU+FPGA 封装在一起"，而是通过片上桥实现处理器系统（HPS）与可编程逻辑（FPGA Fabric）的深度融合。核心方法论：用**控制面**和**数据面**理解软硬件分工，设计前先画出两条线。

## 核心要点

### HPS 不是软核 CPU
- **软核**：用 FPGA 逻辑资源实现的处理器——灵活但占资源、频率低
- **HPS（硬处理器系统）**：固化在硅片中的完整处理器平台——含 CPU 核、存储控制器、中断控制器、定时器、串口/网口/USB 等外设，能跑 Linux

### 片上桥：连接两个世界
- 处理器通过内部总线访问 FPGA 中的寄存器/存储区域
- "存储器映射硬件"——FPGA 中的寄存器对软件来说就是一组特殊内存地址
- 写地址 = 改变 FPGA 中触发器的状态

### 控制面 vs 数据面
| | 控制面 | 数据面 |
|------|--------|------|
| 做什么 | 决定系统行为（参数/模式/命令） | 持续处理业务数据 |
| 路径 | 应用→驱动→片上桥→FPGA 寄存器 | 接口→缓冲→处理流水线→输出 |
| 特点 | 灵活、低频、需维护 | 高吞吐、确定时序 |
| 例子 | 调音量、选滤波模式 | ADC 采样→FFT 流水线→DAC 输出 |

### 片上集成的三个理由
1. 缩短物理距离——通信不经过板级接口
2. 软硬件边界可重划分——先用软件验证，性能瓶颈再迁移到 FPGA
3. 控制+加速在同一系统——处理器管网络/文件系统/UI，FPGA 管专用接口/数据通路

### 四个边界问题
1. **时钟域不同**——处理器总线和 FPGA 数据通路工作在不同时钟
2. **启动顺序**——处理器可能已运行而 FPGA 未配置完成
3. **带宽有限**——片上桥和存储器仍有容量限制
4. **调试跨多层**——错误可能来自应用/驱动/总线/寄存器/时钟域/外部接口
