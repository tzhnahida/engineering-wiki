## 概述

lwIP 是瑞典计算机科学研究所 (SICS) Adam Dunkels 开发的轻量级 TCP/IP 协议栈，专为嵌入式系统设计。核心设计目标：最小化 RAM 占用、零拷贝数据通路、可无 OS 运行。

## 核心模块

| 模块 | 文件 | 功能 |
|------|------|------|
| pbuf | `core/pbuf.c` | 数据包缓冲区抽象，引用计数 + 链式结构 |
| 内存管理 | `core/mem.c` + `core/memp.c` | 动态堆 + 固定大小池双轨分配 |
| IPv4 | `core/ipv4/` | IP 层输入/输出、分片与重组 |
| TCP | `core/tcp.c` + `tcp_in.c` + `tcp_out.c` | 完整 TCP 状态机、拥塞控制、重传 |
| UDP | `core/udp.c` | 无连接传输，PCB 匹配 |
| netif | `core/netif.c` | 网络接口抽象 + 输出链 |
| API | `api/` | Raw → Netconn → Socket 三层 API |
| 系统抽象 | `core/sys.c` + `core/timeouts.c` | OS 移植层 + 定时器管理 |

## 关键设计模式

1. **PCB 模式**：每个协议用协议控制块管理连接状态
2. **零拷贝 pbuf 链**：数据在各层间以指针传递，无需复制
3. **X-Macro 表**：`memp_std.h` 通过多次 `#include` 生成枚举/声明/数组
4. **按状态分区**：TCP PCB 按连接状态分四个链表，加速查找
5. **消息传递 IPC**：多线程模式下 API 调用 → 消息 → TCP/IP 线程 → 信号量同步

## 与 FreeRTOS 的关系

| lwIP 机制 | FreeRTOS 对应 |

| `sys_mbox_t` | `QueueHandle_t` |
| `sys_sem_t` | `SemaphoreHandle_t` |

| `sys_thread_new` | `xTaskCreate` |
| Raw API 回调 | 任务通知 |
| memp 池 | — (FreeRTOS 无内置对象池) |
