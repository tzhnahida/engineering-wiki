# 2026-07-26 - Unity 测试框架源码分析

> **仓库**: https://github.com/ThrowTheSwitch/Unity
> **本地**: `_llm/raw/repos/Unity/`
> **协议**: MIT | **版本**: 2.7.1

## 概述

Unity 是 ThrowTheSwitch 维护的纯 C 单元测试框架，专为嵌入式设计。仅三个文件（`unity.h` + `unity_internals.h` + `unity.c`，~300KB 源码）。零动态内存分配，全部状态一个全局结构体。

## 核心设计

- **单全局状态**：`struct UNITY_STORAGE_T Unity` 持有所有测试计数、失败标志、测试名、`jmp_buf`
- **双层 setjmp 保护**：第一个 `PROTECT` 包 `setUp + test`，第二个包 `tearDown`——测试断言失败也能保证 tearDown 执行
- **宏分层**：`TEST_ASSERT_xxx` → `UNITY_TEST_ASSERT_xxx` → `UnityAssertXxx()`，严格 API-宏-实现三层分离
- **单字符输出**：`UNITY_OUTPUT_CHAR(a)` 是唯一输出抽象，默认 `putchar()`，嵌入式可替换为 UART/ITM/RTT

## 断言家族

覆盖整数全尺寸（INT8/16/32/64、UINT、HEX、BITS、RANGE）、浮点/双精度、字符串/内存、数组、指针、NULL/EMPTY。每种断言都有 `_MESSAGE` 变体附加自定义消息。

## 嵌入式适用性

| 指标 | 数值 |
|------|------|
| 核心文件数 | 3 |
| 全局状态大小 | ~40-80 bytes |
| 堆内存使用 | 0 (零 malloc) |
| 输出抽象 | `UNITY_OUTPUT_CHAR(a)` 一个宏 |
| ROM 可剔除 | float/double/64bit 可编译排除 |
