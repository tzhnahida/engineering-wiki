# 2026-07-24 - Linux 内核抢占机制

- **来源**: 微信公众号文章
- **格式**: Web 图文教程
- **链接**: `https://mp.weixin.qq.com/s/zRVmfeIP77u-FzlDc1cbkg`
- **主题**: Linux 内核抢占（Kernel Preemption）机制的原理、配置与实际控制

## 内容概述

从非抢占内核的"霸道总裁"比喻出发，讲解用户态/内核态的区别、非抢占 vs 抢占式内核的行为差异、自旋锁和 `preempt_disable()` 如何禁止抢占、四个内核配置选项（PREEMPT_NONE / VOLUNTARY / PREEMPT / PREEMPT_RT）的适用场景与代价，以及抢占机制在实时系统中的应用。

## 关键知识点

1. **非抢占内核**: 进入内核态后不可被中断打断，必须主动让出 CPU — 响应延迟高，但实现简单
2. **抢占式内核**: 中断返回内核态时检查是否有更高优先级任务，可立即切换 — 桌面/移动端默认
3. **抢占禁止条件**: 持有自旋锁（spinlock）的临界区、显式调用 `preempt_disable()` 期间
4. **内核 API**: `preempt_disable()` / `preempt_enable()` / `preempt_count()` / `might_sleep()`
5. **配置选项**: PREEMPT_NONE（服务器）→ PREEMPT_VOLUNTARY（桌面温和）→ PREEMPT（桌面激进）→ PREEMPT_RT（工业硬实时，μs 级延迟）
6. **代价**: 频繁上下文切换降低吞吐量；并发复杂度提升，需要更小心的锁管理
