## 文档概述

CAN 2.0 是控制器局域网总线 (Controller Area Network) 的原始规范，由 Bosch 于 1991 年发布。定义了 CAN 数据链路层和物理层的核心协议规则：总线仲裁、帧格式、错误检测与处理、位时序和同步机制。Part A 涵盖 11-bit 标准标识符，Part B 新增 29-bit 扩展标识符，两者在同一总线上共存。

## 关键知识点

- **多主总线**：任意节点可主动发送，基于消息 ID 的逐位仲裁 (CSMA/CA + NRZ)
- **两种帧格式**：Standard (11-bit ID) 和 Extended (29-bit ID)，通过 IDE 位区分
- **四种帧类型**：Data Frame (数据传输)、Remote Frame (请求数据)、Error Frame (错误报告)、Overload Frame (延迟请求)
- **逐位仲裁**：显性 (dominant, 0) 覆盖隐性 (recessive, 1)，ID 越小 → 优先级越高
- **错误检测五重机制**：Cyclic Redundancy Check (CRC15)、Acknowledgment Check、Bit Monitoring、Stuff Rule Check、Frame Check
- **错误状态机**：Error Active → Error Passive → Bus Off（TEC/REC 计数阈值）
- **位时序**：Sync_Seg + Prop_Seg + Phase_Seg1 + Phase_Seg2，SJW (Synchronization Jump Width)
- **Stuff Bit 插入**：连续 5 个相同极性后插入反向位（避免 DC 偏移 + 同步机会）

## 注意

此文档是 CAN 2.0 原始规范，定义 MAC 层和 LLC 层。物理层规范（如高速 CAN 的 ISO 11898-2）需另外参考 ISO 标准。CAN FD (Flexible Data-rate) 和 CAN XL 也不在此规范的范围内。
