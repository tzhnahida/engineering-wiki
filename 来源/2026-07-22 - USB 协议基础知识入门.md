# USB 协议基础知识入门

> 来源：微信公众号，2026-07-22 抓取

## 概述

本文是 USB 协议的入门教程，从 Host/Device 角色、枚举流程、描述符体系、四种传输类型、到 CDC ACM 虚拟串口实战拆解，覆盖 USB Device 开发所需的核心概念骨架。适合以 STM32F103 + CherryUSB 为例的 MCU USB 开发入门。

## 核心要点

### USB 基本角色
- **Host（主机）**：总线管理者，供电、检测插入、发起通信、分配地址、加载驱动
- **Device（设备）**：被管理的外设，按协议回答主机询问

### 枚举 10 步
```
检测上拉 → 复位总线 → 地址 0 → 读设备描述符前 8 字节
→ 分配新地址 → 读完整设备描述符 → 读配置描述符
→ 读接口/端点/字符串描述符 → 加载驱动 → 设配置 → 可用状态
```

### 描述符层级
```
Device Descriptor（设备：VID/PID/版本）
  └── Configuration Descriptor（配置：电流/接口数）
        └── Interface Descriptor（接口：功能单元/USB Class）
              └── Endpoint Descriptor（端点：方向/类型/包长）
```

### 四种传输类型
| 类型 | 特点 | 典型用途 |
|------|------|----------|
| Control | 可靠，有请求-数据-状态三阶段 | 枚举、管理 |
| Bulk | 可靠，无固定延时 | U盘、CDC数据 |
| Interrupt | 小数据量、低延迟、周期性 | 键盘、鼠标、CDC通知 |
| Isochronous | 实时、固定带宽、弱重传 | 音频、视频 |

### CDC ACM 结构（最常见的 MCU USB 应用）
- 2 个接口：通信控制接口 + 数据接口
- 3 个端点：中断 IN（通知）、Bulk OUT（主机→设备）、Bulk IN（设备→主机）

### IN/OUT 方向
**以主机为视角**：IN = 主机读取（设备发送），OUT = 主机写出（设备接收）

### 常见故障
- USB 时钟不是 48 MHz → 枚举失败
- D+/D- 接反 → 无法识别
- 固定上拉不复位 → 软件模拟断开（PA12 拉低 20~100ms）
- 描述符长度不匹配 → 驱动加载异常
- PMA 端点缓冲区配置错误 → 数据异常
