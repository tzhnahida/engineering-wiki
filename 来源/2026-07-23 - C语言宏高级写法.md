# C 语言宏的高级写法

> 来源：微信公众号「学嵌入式的长路」· 嵌入式知识体系第 5 期，2026-07-23 抓取

## 概述

本文深入 C 预处理器宏的四个高阶技巧：`do{}while(0)` 安全封装、`#`/`##` 字符串化与拼接、可变参数宏 `__VA_ARGS__`、X-Macro 数据驱动代码生成。最后组合所有技巧构建了一个注册表风格的设备驱动框架。

## 核心要点

### do{}while(0) — 宏的安全外套
- 解决多条语句宏的"悬空 else"问题
- `{}` 方案有分号陷阱（`if(...) MACRO(); else ...` → 编译错误）
- `do{}while(0)` 末尾分号是自然语句结束符，完美兼容 if/else

### # 与 ##
- `#x`：参数变字符串 — `TO_STRING(GPIOA)` → `"GPIOA"`
- `name##num`：拼接标识符 — `MAKE_REG(GPIO, A)` → `GPIOA`
- 实战：`REG_DUMP(USART1->SR)` 自动打印寄存器名和值

### 可变参数宏 + `##__VA_ARGS__`
- 基础：`#define LOG(fmt, ...) printf("[LOG] " fmt "\n", ##__VA_ARGS__)`
- `##__VA_ARGS__` 解决零参数时的尾部逗号问题（GCC 扩展）
- 实战：带编译时裁剪的等级日志系统（LOG_ERR/LOG_WARN/LOG_INFO）

### X-Macro — 数据驱动代码生成
- 同一份数据表（`.def` 文件或 `#define TABLE`），通过不同 `#define X` 生成枚举、字符串表、初始化函数
- 核心价值：数据集中一处，修改一次，所有派生代码自动同步
- 实战：GPIO 引脚表 → 同时生成枚举 + 名称字符串 + 初始化代码

### 终极综合：注册表风格设备驱动框架
- 结合 do{}while(0) + ## + 可变参数 + X-Macro
- 设备表 → 设备枚举 + 各设备 init 函数 + 统一初始化入口
- 改设备只需改一行表，所有代码自动更新
