# wiki-bootstrap — LLM Wiki 初始化模板包

配套:主文档《LLM Wiki 初始化手册》(与本包一起交给你的 AI)。

## 包内文件

| 文件 | 用途 |
|------|------|
| `CLAUDE.md.template` | 知识库规则文件模板(Claude Code 用)。AI 按问诊答案裁剪后,生成到知识库根目录的 `CLAUDE.md` |
| `AGENTS.md.template` | 同一套规则的通用版(Codex/OpenCode/其他 Agent 用),生成到根目录的 `AGENTS.md` |
| `skeleton.md` | 目录骨架 + 种子文件样式(主页/知识总览/log 的长什么样,直接抄结构) |
| `示例-知识页.md` | 知识页格式范例(内容为虚构演示,仅示范格式与防幻觉标注) |
| `示例-来源页.md` | 来源摘要页格式范例(同上) |

## 用法(三步)

1. 新建空目录(知识库根目录)。
2. 把本包 + 主手册交给 AI,粘贴手册 §4.3 的开场词。
3. AI 问诊 → 裁剪模板 → 生成。你负责回答与审稿。

## 注意

- 两个模板内容几乎一致:CLAUDE.md.template 面向 Claude Code(更细的指令),AGENTS.md.template 面向通用 Agent(纯规则,不含工具专属约定)。最终只生成其中一个。
- 示例页的"内容"是虚构的,用来示范**格式**。真实页面必须遵守手册 §8 防幻觉规则。
- 模板允许随实践演化——你的 AI 第一次 lint 后,可以按你的习惯改规则文件。规则文件是"你们俩的宪章",不是死文档。
