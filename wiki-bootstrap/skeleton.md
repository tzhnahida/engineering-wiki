# 目录骨架与种子文件

> 生成知识库时照此建立目录与四个种子文件。占位符 {…} 按问诊答案替换。

## 目录树

```
{库根目录}/
├── CLAUDE.md                # 或 AGENTS.md —— 规则文件(裁剪自模板)
├── 主页.md                   # 分类入口(样式见下)
├── log.md                   # 操作日志(样式见下)
├── 原始资料/                 # 只读区;按来源类型建子目录(论文/手册/剪藏)
│   └── .gitkeep
├── Clippings/               # 可选(有剪藏工具才建)
├── 来源/                     # 每份入库文档一页
│   └── .gitkeep
└── 知识/                    # 按领域分子目录
    ├── {领域1}/
    ├── {领域2}/
    └── 知识总览.md           # 索引(样式见下)
```

## 种子文件 1:主页.md

```markdown
---
type: index
created: YYYY-MM-DD
updated: YYYY-MM-DD
---

| | | |
|---|---|---|
| 📖 **知识** | [知识总览](../知识/知识总览.md) | {N} 篇知识页,{M} 个领域 |
| 📄 **来源** | 来源/ | {K} 篇来源摘要 |

## 知识分类

| 领域 | 入口 | 涵盖 |
|------|------|------|
| {领域1} | [知识总览](../知识/知识总览.md) | {一句话} |

## 活跃项目

- [{项目名}](../{项目名}.md) — {描述}
```

## 种子文件 2:知识总览.md

```markdown
---
type: index
created: YYYY-MM-DD
---

# 知识总览

> 方法论、概念和技术总结。每条知识都索引自具体的来源资料。

## {领域1}

| 页面 | 内容 | 来源 |
|------|------|------|
| [{领域1}/{页面名}](../{领域1}/{页面名}.md) | 一句话摘要 | [YYYY-MM-DD - 来源标题](../YYYY-MM-DD%20-%20来源标题.md) |
```

每 ingest 新资料后必须更新此表(新增行、改摘要)。

## 种子文件 3:log.md

```markdown
---
type: log
created: YYYY-MM-DD
updated: YYYY-MM-DD
---

## [YYYY-MM-DD] init | 知识库初始化

- 领域:{领域清单};资料形态:{形态};页面类型:{类型}
- 生成规则文件 → {规则文件名};建立目录骨架;创建 主页/知识总览/log
```

之后每次操作追加一行(最新在上)。**不用 wikilink。**

## 种子文件 4:原始资料/.gitkeep 与 来源/.gitkeep

空目录占位,保证首次 git add 时目录结构入库。

## 初始化完成判据

- [ ] CLAUDE.md/AGENTS.md 存在且防幻觉章节完整
- [ ] 目录树与上方一致(按问诊裁剪后)
- [ ] 主页/知识总览/log 三个种子文件可打开、结构完整
- [ ] git 已 init(若用户选择)+ 首次 commit
- [ ] 用户对「生成确认清单」明确点头
